# Настройка цели

Если у вас нет настроенных целей, посмотрите подробную информацию в разделе [Что такое цели. Типы целей](ru/general/goals).

Совет

Если цели настроены, но вы считаете, что они работают некорректно, воспользуйтесь [специальной инструкцией по решению проблем](ru/troubleshooting/goals-dys).

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.
