# Аналитика форм

Для корректной работы Аналитики форм необходимо, чтобы данные отправлялись на сервер в событии `submit`. В отчет не попадают страницы, на которых отправка формы происходит при помощи других JavaScript-событий.

[Аналитика форм](ru/behavior/web-forms)

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.
