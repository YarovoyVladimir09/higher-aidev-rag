# Доступ к счетчику по PIN-коду

Когда вы обращаетесь в службу поддержки, для решения вопроса специалисту нужен доступ к вашему счетчику. При обращении по телефону специалист может попросить вас продиктовать PIN-код.

PIN-код виден только владельцу счетчика или пользователю с доступом к статистике. Это необходимо для безопасности доступа к данным.

Чтобы найти PIN-код, в правом верхнем углу страницы нажмите на портрет и выберите **Получить PIN-код**. В целях безопасности срок действия PIN-кода ограничен.

После того, как вы сообщили PIN-код, специалист получит доступ к счетчику до момента, когда ваш вопрос будет решен. После завершения обработки обращения доступ к счетчику пропадет.
