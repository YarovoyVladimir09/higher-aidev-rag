# Переход на «Альтернативный CDN»

С 31 мая 2020 года Яндекс Метрика перестала поддерживать альтернативную версию кода счетчика, расположенную по адресу [https://d31j93rd8oukbv.cloudfront.net/metrika/watch_ua.js](https://d31j93rd8oukbv.cloudfront.net/metrika/watch_ua.js). Эта версия помогала использовать Метрику в регионах, где ограничен доступ к ресурсам Яндекса.

Обновите код счетчика на всех страницах сайта:

Чтобы данные вашего сайта продолжили корректно собираться в регионах с ограничениями, подключите опцию [Альтернативный CDN](ru/general/counter-general#cdn):

1. Перейдите в Метрику на страницу настройки счетчика.
2. В блоке **Дополнительные настройки** включите опцию **Альтернативный CDN** и сохраните изменения.
3. В блоке **Код счетчика** скопируйте код и обновите его на всех страницах вашего сайта.
