# Передача событий

- [Отправка и обработка данных](ru/data/visit-params-data#proc)

Важно

Для работы с JavaScript API необходимы навыки работы с HTML и JavaScript. Если вы не обладаете такими навыками, обратитесь к разработчику или вебмастеру вашего сайта.

Большинство данных о посещениях [собирается счетчиком](ru/general/how-it-works#data_extract_pull) Яндекс Метрики автоматически. Однако, часто возникает необходимость дополнения собранных данных собственными. Например, интерес может представлять статистика по заказам определенных товаров или информация о действиях авторизованных пользователей.

Яндекс Метрика позволяет связать с визитом произвольный набор данных, называемых *параметрами события*. Эти данные могут быть отображены в отчетах, а также использоваться в условиях группировки и сегментации.

Параметры событий передаются в хранилище счетчика с помощью JavaScript API. Отправка данных может производиться либо во время инициализации счетчика, либо в произвольный момент времени до истечения [тайм-аута визита](ru/general/counter-general#time-out).

При инициализации счетчика параметры событий указываются в параметре [params](ru/code/counter-initialize#param-params).

Для передачи параметров событий во время просмотра посетителем сайта используется метод [params](ru/objects/params-method) либо необязательный аргумент методов [extLink](ru/objects/extlink), [file](ru/objects/file), [hit](ru/objects/hit), [reachGoal](ru/objects/reachgoal).

Параметры событий передаются в виде объектов или массивов объектов.

## ru/data/visit-params-data#procОтправка и обработка данных

Данные передаются Яндекс Метрике в виде JavaScript-объектов.

Запрос данных, отправляемых в Метрику может содержать не более 8 КБ (8 192 символов). При [передаче иерархической структуры данных](ru/data/visit-params-example#level) в отчетах Яндекс Метрики отобразится до 10 уровней вложенности. Если в рамках одного визита был отправлен один параметр с разными значениями, то в Метрике отобразятся все значения. При этом стоит учитывать, что в одном визите можно передать до 512 параметров.

[Ограничения на передачу данных](ru/general/limits)

Значение поля обрабатывается следующим образом в зависимости от своего типа:

- **объект** — для каждого ключа объекта создается ветвь дерева, и для каждого значения алгоритм вызывается рекурсивно;
- **строка** — вычисляется количество случаев, когда встречается каждое различное значение строки;
- **число** — вычисляется суммарное и среднее значение всех чисел;
- **массив** — создается ветвь дерева [Параметры], вычисляется количество случаев, когда значение является массивом, и алгоритм вызывается рекурсивно для каждого элемента массива;
- **true**, **false** или **null** — вычисляется количество случаев, когда встречается каждое такое значение.

Пример передаваемых данных:

```
// Пример передачи объекта. Максимальная вложенность – 10 уровней 
ym(XXXXXXXX, "params", { 
  level1_1: {
    level2_1: {
      level3_1: "example1" ,
      level3_2: "example2",
    },
    ...
    level2_2: "example3"
  }
})
```

Где:

- XXXXXXXX — номер счетчика;
- level1_1, level1_2, level2_1 — структура параметров событий;
- example1, example2, example3 — значения для параметров.

Больше примеров — в разделе [Примеры отправки событий](ru/data/visit-params-example).

## ru/data/visit-params-data#paramОтчеты по параметрам

События передаются в Метрику как *группировки* или [цели](ru/general/glossary#goal). Показатели, которые вычисляются при обработке данных, являются *метриками*.

Чтобы смотреть статистику по переданным событиям, используйте [Отчет «Параметры события»](ru/reports/event-params) или [Отчет «Параметры визитов»](ru/reports/visit-params). Также параметры можно использовать в качестве условий при [создании сегментов](ru/general/segmentation) в других отчетах Яндекс Метрики.

Примечание

Если вы передаете параметры с аргументом метода [reachGoal](ru/objects/reachgoal), но JavaScript-цель не заведена для счетчика или заведена только внутри составной цели — данные не попадут в отчет «Параметры событий».

Создайте отдельную JavaScript-цель в интерфейсе счетчика или используйте другие методы для передачи параметров: [params](ru/objects/params-method), [extLink](ru/objects/extlink), [file](ru/objects/file) или [hit](ru/objects/hit).
