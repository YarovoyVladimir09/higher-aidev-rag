# Передача и обработка данных

- [Подготовка CSV-файла](ru/data/offline-conversion-data#make-file)
- [Загрузка файла](ru/data/offline-conversion-data#upload-file)
- [Ошибки при загрузке файла](ru/data/offline-conversion-data#error)

Передавать информацию можно с помощью:

- Веб-интерфейса Метрики.
- API Метрики. [Руководство по передаче данных](https://yandex.ru/dev/metrika/doc/api2/practice/offline-conv-docpage/)
- Сервиса автоматизации Albato. [Инструкция по подключению](https://albato.ru/yandex-offline-conversion)

Чтобы настроить передачу офлайн-конверсий в веб-интерфейсе Метрики:

1. Подготовьте [специальные идентификаторы](ru/data/offline-params#ids).
2. На странице **Цели** в левом меню создайте [цель типа JavaScript-событие](ru/general/goal-js-event). В качестве идентификатора цели укажите событие, которое нужно отслеживать (например, подтверждение заказа — «order_confirmed»). Этот идентификатор понадобится при формировании CSV-файла. Если вы хотите анализировать офлайн-конверсии отдельно от конверсий на сайте, укажите в поле **Название** наиболее понятное значение (например, «Покупка в офисе», «Офлайн-цель» или «Оплата наличными»). Так цель можно будет легко найти в общем списке.
3. [Сформируйте CSV-файл](ru/data/offline-conversion-data#make-file) с данными о конверсиях, следуя рекомендациям.
4. [Загрузите файл](ru/data/offline-conversion-data#upload-file) в Яндекс Метрику.

Примечание

Данные появятся в отчетах Метрики в течение 2 часов после их загрузки.

После загрузки проверить статус привязки каждой конверсии можно в отчете [«Офлайн-конверсии»](ru/reports/offline-conversions). В отчете видно, привязана ли конверсия к визиту, и причина, если привязка не выполнена.

## ru/data/offline-conversion-data#make-fileПодготовка CSV-файла

[Спецификация формата CSV](http://www.rfc-editor.org/rfc/rfc4180.txt)

[Описание формата СSV](https://ru.wikipedia.org/wiki/CSV)

| Название поля | Обязательно | Описание | Пример |
| --- | --- | --- | --- |
| ClientID | UserID | yclid | PurchaseId | Да * | Идентификатор посетителя сайта или кампании в Директе | 12345 |
| Target | Да | Идентификатор цели, заданный при создании цели | order_confirmed |
| DateTime | Да | Время, в которое произошла конверсия, в формате Unix Time Stamp , в секундах. Переводите в этот формат дату и время события в часовом поясе счетчика | 1481718166 |
| Price | Нет | Доход по цели | 1000 |
| Currency | Нет | Трехбуквенный код валюты по ISO 4217 . Если передается другая валюта, будут отправлены нулевые значения вместо валюты и суммы | RUB |

* Обязателен хотя бы один из идентификаторов.

## ru/data/offline-conversion-data#upload-fileЗагрузка файла

Чтобы загрузить подготовленный файл с данными, перейдите на страницу **Настройка** (вкладка **Загрузка данных**). Затем в блоке **Загрузка офлайн-конверсий** выполните следующее:

1. Нажмите кнопку **Загрузить данные**.
2. В появившемся окне выберите тип привязки в зависимости от типа идентификатора, который вы хотите загрузить.
3. Выберите файл на вашем компьютере и добавьте комментарий к загрузке, если это необходимо.
4. Нажмите кнопку **Загрузить данные**.

[Пример CSV-файла для загрузки данных](https://download.cdn.yandex.net/from/yandex.ru/support/ru/metrica/files/offline-conversions.csv)

Примечание

Размер передаваемого CSV-файла — не более 1 ГБ, кодировка — UTF-8.

## ru/data/offline-conversion-data#errorОшибки при загрузке файла

Иногда Яндекс Метрике не удается привязать офлайн-конверсии к соответствующим визитам. Ниже описаны самые распространенные причины ошибок привязки:

| Причина ошибки | Решение |
| --- | --- |
| В Яндекс Метрике не найдены указанные в файле идентификаторы целей | Убедитесь, что в файле указаны те же идентификаторы целей, что и в Яндекс Метрике. Проверить идентификатор цели можно на странице Цели в левом меню |
| В Яндекс Метрике не найдены указанные в файле идентификаторы посетителей | Проверьте , что передача идентификаторов настроена корректно. Если вы используете UserID и передача данных настроена корректно, загрузите файл позже. Вероятно, не все клиенты с указанными в файле UserID успели побывать на сайте, так что в системе еще не установлена связь между их UserID из вашей базы и их внутренними СlientID в Яндекс Метрике |
| Даты визитов не попадают в период дополнения визитов офлайн-данными. Это значит, что с даты последнего визита посетителя на сайт до начала обработки файла прошло больше 21 дня | В этом случае добавить офлайн-конверсии в Яндекс Метрику не получится Период дополнения визитов офлайн-данными |

Причины, по которым уже загруженные конверсии не привязались к визиту, смотрите в отчете [«Офлайн-конверсии»](ru/reports/offline-conversions).
