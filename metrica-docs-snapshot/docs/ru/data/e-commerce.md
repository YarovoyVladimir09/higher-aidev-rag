# Как подключить электронную коммерцию вручную

Важно

Для работы с JavaScript API необходимы навыки работы с HTML и JavaScript. Если вы не обладаете такими навыками, обратитесь к разработчику или вебмастеру вашего сайта.

Примечание

Если вы партнер Яндекс Маркета и у вас есть страница магазина, информация о взаимодействии посетителей с товарами доступна в отчетах Метрики без дополнительных настроек. [Статистика по магазину-партнеру Маркета](ru/general/market)

1. source: ru/_includes/ecommerce/enabling/id-enabling/1.md [Перейдите в Метрику](https://metrika.yandex.ru). endsource: ru/_includes/ecommerce/enabling/id-enabling/1.md
2. source: ru/_includes/ecommerce/enabling/id-enabling/2.md Выберите счетчик, к которому нужно подключить электронную коммерцию. endsource: ru/_includes/ecommerce/enabling/id-enabling/2.md
3. В настройках счетчика включите опцию **Электронная коммерция**. В код счетчика добавится контейнер для сбора данных `dataLayer`. Также вы можете инициализировать счетчик с параметром [ecommerce: true](ru/code/counter-initialize#param-ecommerce).
4. Установите или обновите код счетчика на страницах вашего сайта, которые содержат информацию о товарах и заказах (характеристики товара, кнопка «Добавить в корзину» и пр.). Для этого скопируйте код счетчика. Убедитесь, что код счетчика на сайте содержит строку: `ecommerce:"dataLayer"`. Если на сайте уже настроена разметка Google Analytics Enhanced Ecommerce или Электронная торговля (GA4), в том числе через Global Site Tag, данные начнут поступать автоматически без дополнительных настроек — Метрика имеет совместимый с Google формат передачи данных. В этом случае пропустите п. 5.
5. На вашем сайте [настройте передачу данных](ru/ecommerce/data) (о добавлении товара в корзину, покупке и т. д.) через JavaScript API. Для передачи информации нужно создать скрипт, который будет отвечать за определенное событие (например, формирование заказа) в [заданном формате](ru/ecommerce/data). Вы можете настроить передачу всех событий, чтобы получать более полные данные, или только некоторые из событий. Выполните этот шаг, если у вас нет расширенной электронной торговли от Google. Для каждого действия сформируйте ecommerce-объект и поместите его в контейнер данных (по умолчанию — `dataLayer`).
6. [Проверьте](ru/ecommerce/check), правильно ли настроена электронная коммерция.
7. source: ru/_includes/ecommerce/enabling/id-enabling/5.md Спустя несколько часов после первой передачи данных появится статистика в Метрике. Чтобы посмотреть отчеты, в Метрике откройте **Отчеты** → **Электронная коммерция**. [Отчеты по электронной коммерции](ru/data/e-commerce-reports) endsource: ru/_includes/ecommerce/enabling/id-enabling/5.md
