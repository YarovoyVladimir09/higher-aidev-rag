# Отчеты по электронной коммерции

| Отчет | Описание | Действие для корректного отображения отчета |
| --- | --- | --- |
| Источники заказов | Отчет показывает, какие источники трафика, включая рекламные, принесли наибольший доход | Покупка |
| Содержимое заказов | Отчет содержит информацию о покупках в формате «ID-покупки — заказанные товары», а также о количестве товаров в заказе и доходе |  |
| Заказанные товары | Отчет содержит информацию о заказанных товарах. Можно увидеть, сколько товаров было куплено и на какую сумму |  |
| Популярные категории и бренды | Отчет содержит данные о категориях товаров и брендах, которые пользуются наибольшим спросом у посетителей сайта | Просмотр товара, добавление товара в корзину, покупка |
| Популярные товары | Отчет содержит информацию о товарах, которые пользуются наибольшим спросом у посетителей сайта. Степень популярности оценивается по количеству просмотров страницы с информацией о товаре |  |
| Товары в корзине | Отчет содержит информацию по каждому наименованию товара, который был добавлен в корзину посетителем сайта | Добавление товара в корзину, удаление товара из корзины, покупка |
| Списки товаров | Отчет показывает просмотры, клики и долю посетителей, которые кликнули по товару в списке | Просмотр товара в списке, клик по товару из списка |
| Промокампании | Отчет показывает просмотры и клики по рекламным материалам | Просмотр внутренней рекламы, клик по внутренней рекламе |

Чтобы посмотреть статистику, перейдите в Метрику и откройте **Отчеты** → **Электронная коммерция**.
