# Яндекс Тег Менеджер

- [Возможности Яндекс Тег Менеджера](ru/tag-manager-about#why)
- [Как включить](ru/tag-manager-about#onn)

Яндекс Тег Менеджер — это бесплатный инструмент для управления тегами систем веб-аналитики: поведенческой, рекламной, финансовой, маркетинговой.

## ru/tag-manager-about#whyВозможности Яндекс Тег Менеджера

С помощью инструмента, без изменения кода сайта, прямо в Метрике,  можно:

- Добавлять, обновлять, удалять скрипты отслеживания сторонних систем аналитики.
- Создавать собственные сценарии отслеживания: от простых до сложных. Можно, к примеру, отследить клики по кнопкам с текстом «Купить» или путь посетителя от перехода на сайт и до покупки.
- Создавать шаблоны для добавления своих сервисов в Яндекс Тег Менеджер.

[Возможности Яндекс Тег Менеджера и способы его применения](https://yandex.ru/support/tag-manager/ru/)

## ru/tag-manager-about#onnКак включить

Включить Яндекс Тег Менеджер может только владелец счетчика. Узнать, кто владелец, можно на странице со [списком счетчиков](https://metrika.yandex.ru/list).

- Если счетчик Метрики уже установлен на сайт, перейдите в его настройки: **Настройки** → **Счетчик** и включите **Тег менеджер**.
- Если счетчика нет, то [установите его](ru/general/creating-counter) и тоже включите **Тег менеджер** в настройках.

Больше никаких вмешательств в код сайта не требуется.
