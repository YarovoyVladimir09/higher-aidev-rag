# Отчет «Внешние переходы»

- [Какие задачи может решать отчет](ru/content/external-links#case)
- [Структура и настройки отчета](ru/content/external-links#data)

С помощью отчета вы можете узнать, на какие сайты и сколько раз посетители переходили по ссылкам с вашего сайта.

Внешним переходом считается переход по ссылке с доменом, отличающимся от домена сайта, на котором установлен счетчик Яндекс Метрики. При этом Flash-баннер не считается внешней ссылкой.

Если при переходе по ссылке срабатывает редирект на другой адрес, Яндекс Метрика не учтет цель редиректа — адрес не отобразится в отчете.

Посмотреть отчет: **Отчеты** → **Содержание** → **Внешние переходы**.

## ru/content/external-links#caseКакие задачи может решать отчет

С помощью отчета вы можете узнать количество раз, когда посетитель перешел по ссылке с вашего сайта на другой.

## ru/content/external-links#dataСтруктура и настройки отчета

Данные в отчете сгруппированы по адресу сайта, на который ведет ссылка с детализацией до страницы.

[Как настроить отчет](ru/reports/report-general)

Обратите внимание, что в отчете нельзя использовать цели, а также ограничен набор группировок и метрик.
