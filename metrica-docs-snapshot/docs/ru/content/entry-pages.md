# Отчет «Страницы входа»

- [Какие задачи может решать отчет](ru/content/entry-pages#kakie-zadachi-mozhet-reshat-otchet)
- [Структура и настройки отчета](ru/content/entry-pages#struktura-i-nastrojki-otcheta)

Отчет содержит статистику по страницам, с которых посетители начинают просмотр вашего сайта. Данные представлены только по тем *визитам*, которые начались с указанных в отчете страниц.

Посмотреть отчет: **Отчеты** → **Содержание** → **Страницы входа**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/entrance?period=week&selected_rows=%5B%7B%22path%22%3A%5B%228120445791477781921%22%5D%2C%22name%22%3A%5B%22https%3A%2F%2Fmetrica.yandex.com%2F%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/content/entry-pages#kakie-zadachi-mozhet-reshat-otchetКакие задачи может решать отчет

Отчет покажет, какие страницы сайта посещают в первую очередь.

Сделать это можно с помощью отказов. Чем выше показатель отказов, тем меньше сайт вовлекает посетителей — они уходят в течение 15 секунд, просмотрев только одну страницу.

Чтобы получить эту информацию, [создайте цель](ru/general/goals) и [используйте ее в отчете](ru/reports/goals).

Одним из целевых показателей Метрики является *Конверсия*.

Вы можете узнать наиболее конверсионные страницы входа.

Для этого нужно изменить список группировок отчета:

1. Нажмите кнопку **Группировка** и выберите **Источник трафика**, а затем — **Источник трафика, детально**.
2. Перенесите добавленные группировки в начало списка группировок, которые используются в отчете. Для удобства оставьте в списке только несколько из них: **Источник трафика**, **Источник трафика, детально** и **Страницы входа**.
3. Выберите линейный тип отображения данных.
