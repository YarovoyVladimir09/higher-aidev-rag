# Отчет «Популярное»

- [Какие задачи может решать отчет](ru/content/popular#case)
- [Структура и настройки отчета](ru/content/popular#data)

Отчет представляет наиболее популярные страницы сайта на основе количества посетителей и просмотров.

Посмотреть отчет: **Отчеты** → **Содержание** → **Популярное**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/popular?period=week&selected_rows=%5B%7B%22path%22%3A%5B%228120445791477781921%22%5D%2C%22name%22%3A%5B%22https%3A%2F%2Fmetrica.yandex.com%2F%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/content/popular#caseКакие задачи может решать отчет

С помощью отчета вы можете узнать, какие страницы вашего сайта посещают чаще.

Для этого нажмите кнопку **Метрики** и выберите **Мобильность**.

## ru/content/popular#dataСтруктура и настройки отчета

В отчете отображена статистика по посещениям и просмотрам отдельных страниц сайта.

О том, как настроить отчет, смотрите в разделе [Настройки отчета](ru/reports/report-general#set-report).

Обратите внимание, что отчет не поддерживает:

- группировки и метрики, отличные от заданных по умолчанию;
- установку [цели](ru/general/goals);
- [атрибуцию](ru/reports/attribution-model);
- настройки [статистической достоверности](ru/reports/false-data).
