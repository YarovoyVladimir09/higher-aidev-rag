# Отчет по кнопке «Поделиться»

- [Какие задачи может решать отчет](ru/content/share-button#case)
- [Структура и настройки отчета](ru/content/share-button#data)

Отчет позволяет оценить, насколько охотно посетители делятся вашим контентом в социальных сетях. Если на сайте уже размещен **блок «Поделиться»**, то отчет появится в статистике по сайту автоматически.

Посмотреть отчет: **Отчеты** → **Содержание** → **Кнопка «Поделиться»**.

## ru/content/share-button#caseКакие задачи может решать отчет

С помощью отчета вы можете узнать, сколько раз посетитель поделился страницей вашего сайта и на каких ресурсах, а также определить наиболее популярные из них.

## ru/content/share-button#dataСтруктура и настройки отчета

Данные в отчете сгруппированы по названию социальной сети, на которую ведет кнопка **Поделиться** с детализацией до страницы сайта, на которой установлена кнопка.

[Как настроить отчет](ru/reports/report-general)

Обратите внимание, что в отчете нельзя использовать цели, а также ограничен набор группировок и метрик.
