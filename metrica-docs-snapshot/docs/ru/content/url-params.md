# Отчет «По параметрам URL»

- [Какие задачи может решать отчет](ru/content/url-params#case)
- [Структура и настройки отчета](ru/content/url-params#data)

Отчет показывает статистику по параметрам URL страниц вашего сайта.

`https://<host>/<path>?<params>#<fragment>`

- `<host>` — домен сайта.
- `<path>` — путь, который может иметь иерархическую структуру. Структура задается с помощью символа «/».
- `<params>` — блок параметров, который отделяется от пути символом «?».
- `<fragment>` — фрагмент контента страницы, отделяется от параметров или пути символом «#».

Параметр URL представляет собой пару «ключ-значение» (`param=value`). Если в URL перечислено несколько параметров, они разделяются символом «&».

Параметры могут указывать на контент страницы, например `https://example.com?product=123`. А также передавать информацию для отслеживания, например [UTM-метку](ru/general/source-tags#utm-construct).

Посмотреть отчет: **Отчеты** → **Содержание** → **По параметрам URL**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/url_param?dimension_mode=list&period=2018-12-12%3A2018-12-31&selected_rows=%5B%7B%22path%22%3A%5B%22source%22%2C%22source%3Dtableau_direct%22%5D%7D%2C%7B%22path%22%3A%5B%22from%22%2C%22from%3Ddirface14%22%5D%7D%2C%7B%22path%22%3A%5B%22status%22%2C%22status%3Dok%22%5D%7D%2C%7B%22path%22%3A%5B%22fbclid%22%2C%22fbclid%3DIwAR2i17WxvMrAx7r1cnVe9C5ndr6c8bYRdydXzzFBpJwi5oIXC4gvSBo7p9E%22%5D%7D%2C%7B%22path%22%3A%5B%22_ym_debug%22%2C%22_ym_debug%3D1%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/content/url-params#caseКакие задачи может решать отчет

С помощью отчета вы можете отслеживать статистику по дополнительным параметрам URL, например, если используете метку `utm_referrer` для более точного [определения источника трафика](ru/general/source-tags#utm-referrer).
