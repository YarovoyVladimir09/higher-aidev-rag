# Отчет «Заголовки страниц»

- [Какие задачи может решать отчет](ru/content/page-titles#kakie-zadachi-mozhet-reshat-otchet)
- [Структура и настройки отчета](ru/content/page-titles#data)

Данный отчет представляет собой рейтинг посещаемости (по количеству просмотров и посетителей) страниц с указанием их заголовков. Заголовки берутся из элемента `title`.

Посмотреть отчет: **Отчеты** → **Содержание** → **Заголовки страниц**.

## ru/content/page-titles#kakie-zadachi-mozhet-reshat-otchetКакие задачи может решать отчет

С помощью отчета вы можете узнать, какие страницы вашего сайта посещают чаще. Чтобы посмотреть заголовки страниц в соответствии с их адресами, добавьте группировку **Адрес страницы** и выберите способ отображения **Линейный список**.

Для этого нажмите кнопку **Метрики** и выберите **Мобильность**.

## ru/content/page-titles#dataСтруктура и настройки отчета

В отчете отображена статистика по посещениям и просмотрам отдельных страниц сайта.

О том, как настроить отчет, смотрите в разделе [Настройки отчета](ru/reports/report-general#set-report).

Обратите внимание, что отчет не поддерживает:

- группировки и метрики, отличные от заданных по умолчанию;
- установку [цели](ru/general/goals);
- [атрибуцию](ru/reports/attribution-model);
- настройки [статистической достоверности](ru/reports/false-data).
