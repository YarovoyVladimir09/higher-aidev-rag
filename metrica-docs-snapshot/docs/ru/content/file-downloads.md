# Отчет «Загрузки файлов»

- [Какие задачи может решать отчет](ru/content/file-downloads#case)
- [Структура и настройки отчета](ru/content/file-downloads#data)

Отчет показывает, сколько раз посетители попытались скачать файлы с вашего сайта: аудио, видео, архивы, изображения и др. При этом остается вероятность, что загрузка не была завершена.

| 3GP 7Z AAC AVI APK CSV DJVU DOCX EXE | FLAC FLV GZ KEY MIDI MKA MKV MP3 MP4 | MPEG MOV MSI OGG PDF PKG PPS PPT PPTX | RAR RTF TXT WAV WMA WMV WMF XLSX ZIP |
| --- | --- | --- | --- |

Вы можете добавить в отчет другие расширения с помощью метода [addFileExtension](ru/objects/addfileextension).

Посмотреть отчет: **Отчеты** → **Содержание** → **Загрузки файлов**.

## ru/content/file-downloads#caseКакие задачи может решать отчет

Отчет покажет, сколько раз посетители попытались скачать тот или иной файл, размещенный на вашем сайте.

Отчет покажет количество посетителей, которые попытались скачать файл с вашего сайта.

## ru/content/file-downloads#dataСтруктура и настройки отчета

Данные в отчете сгруппированы по адресу, по которому расположен файл для скачивания.

[Как настроить отчет](ru/reports/report-general)

Обратите внимание, что в отчете нельзя использовать цели, а также ограничен набор группировок и метрик.
