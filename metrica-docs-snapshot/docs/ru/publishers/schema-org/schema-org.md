# Schema.org

Schema.org — это словарь семантической разметки данных в сети, который поддерживается основными поисковыми системами, включая Яндекс. Словарь представляет собой набор классов, описывающих различные сущности и их свойства.

[Перейти на сайт Schema.org](http://schema.org/docs/documents.html)

Примечание

Размеченные данные становятся общедоступными, и любой сервис может извлечь и использовать их.

Вы можете использовать два способа разметки: [Microdata](ru/publishers/schema-org/microdata) или [JSON-LD](ru/publishers/schema-org/json-ld).

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.
