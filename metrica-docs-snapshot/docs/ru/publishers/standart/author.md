# Отчет «Авторы»

- [Какие задачи может решать отчет](ru/publishers/standart/author#case)
- [Условия для получения отчета](ru/publishers/standart/author#ness)
- [Структура и настройки отчета](ru/publishers/standart/author#data)

Отчет содержит статистику об авторах материалов, размещенных на вашем сайте.

Посмотреть отчет: **Отчеты** → **Контентная аналитика** → **Авторы**.

## ru/publishers/standart/author#caseКакие задачи может решать отчет

Популярность материалов можно оценивать по количеству просмотров.

При анализе данных нужно обратить внимание на метрику «Рециркуляция».

## ru/publishers/standart/author#nessУсловия для получения отчета

Чтобы статистика собиралась и отображалась корректно, убедитесь, что материалы на сайте размечены в соответствии с рекомендациями ([Schema.org](ru/publishers/schema-org/schema-org) или [Open Graph](ru/publishers/open-graph/open-graph)).

## ru/publishers/standart/author#dataСтруктура и настройки отчета

Данные сгруппированы по автору — значению которое размечено в статье.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
