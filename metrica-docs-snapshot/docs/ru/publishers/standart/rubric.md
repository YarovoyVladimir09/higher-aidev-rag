# Отчет «Рубрики»

- [Какие задачи может решать отчет](ru/publishers/standart/rubric#case)
- [Условия для получения отчета](ru/publishers/standart/rubric#ness)
- [Структура и настройки отчета](ru/publishers/standart/rubric#data)

Отчет содержит общую статистику по рубрикам и материалам вашего сайта. Чтобы посмотреть, как посетители сайта взаимодействуют с материалами, воспользуйтесь отчетом [Отчеты по рубрикам](ru/publishers/reports/rubric).

Посмотреть отчет: **Контент** → **Отчеты** → **Рубрики**.

## ru/publishers/standart/rubric#caseКакие задачи может решать отчет

При анализе данных нужно обратить внимание на метрику «Рециркуляция».

## ru/publishers/standart/rubric#nessУсловия для получения отчета

Чтобы статистика собиралась и отображалась корректно, убедитесь, что материалы на сайте размечены в соответствии с рекомендациями ([Schema.org](ru/publishers/schema-org/schema-org) или [Open Graph](ru/publishers/open-graph/open-graph)).

## ru/publishers/standart/rubric#dataСтруктура и настройки отчета

Данные сгруппированы по рубликам и материалам. Группировки вида «Рубрика ур.» соответствуют тому, как размечена вложенность разделов сайта, где размещен материал. Может быть только два уровня вложенности.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
