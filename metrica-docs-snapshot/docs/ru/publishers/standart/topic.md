# Отчет «Тематики»

- [Какие задачи может решать отчет](ru/publishers/standart/topic#case)
- [Условия для получения отчета](ru/publishers/standart/topic#ness)
- [Структура и настройки отчета](ru/publishers/standart/topic#data)

Отчет содержит статистику по тематикам материалов вашего сайта.

Посмотреть отчет: **Отчеты** → **Контентная аналитика** → **Тематики**.

## ru/publishers/standart/topic#caseКакие задачи может решать отчет

**Определить наиболее популярные тематики**

Популярность можно оценивать по количеству просмотров.

## ru/publishers/standart/topic#nessУсловия для получения отчета

Чтобы статистика собиралась и отображалась корректно, убедитесь, что материалы на сайте размечены в соответствии с рекомендациями ([Schema.org](ru/publishers/schema-org/schema-org) или [Open Graph](ru/publishers/open-graph/open-graph)).

## ru/publishers/standart/topic#dataСтруктура и настройки отчета

Данные сгруппированы по тематике и заголовку материала.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
