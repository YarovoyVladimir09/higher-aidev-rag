# Проверка передачи данных контентной аналитики

После того, как вы разметили контент сайта, убедитесь, что данные передаются в Метрику правильно. Проверка подходит и для проверки микроразметки на Турбо-сайтах.

Чтобы убедиться, что размеченные данные передаются:

1. В браузере откройте страницу сайта с размеченным контентом.
2. В адресной строке браузера добавьте к адресу страницы параметр `_ym_debug=2` и загрузите страницу. http://example.com/?_ym_debug=2
3. Внизу страницы нажмите значок — появится панель отладки. source: ru/_includes/popup/id-debug/navig.md Чтобы переключаться между данными того или иного счетчика, нажмите — выбор сохраняется при переходе между вкладками. endsource: ru/_includes/popup/id-debug/navig.md

Примечание

Параметр `_ym_debug=2` работает только, если на сайте установлен [новый код счетчика Метрики](ru/general/tag-info). Если установлена предыдущая версия кода или панель отладки не появилась, используйте консоль браузера.

Если разметка настроена правильно, в блоке во вкладке **Publishers** отобразится тип разметки и информация о размеченном материале. Подробные данные можно посмотреть во вкладке **Console**.

Также вы можете [использовать лог ваших действий](ru/general/debugger#logs) при работе с отладчиком.

Полную статистику можно получить по материалу, в тексте которого больше 500 символов. Если в размеченной статье меньше 500 символов, при проверке микроразметки появится предупреждение об этом.

Используйте этот способ, если на вашем сайте стоит предыдущая версия счетчика Метрики.

1. В браузере откройте страницу сайта с размеченным контентом.
2. В адресной строке браузера добавьте к адресу страницы параметр `_ym_debug=2` и загрузите страницу. http://example.com/?_ym_debug=2
3. Вызовите консоль браузера с помощью сочетания клавиш **Ctrl** + **Shift** + **J** (**⌥** + **⌘** + **J** для семейства операционных систем Apple).

Если разметка настроена правильно, в консоли отобразятся:

- 1 — Тип разметки, указанный в настройках счетчика.
- 2 — Размеченные данные, которые передаются в Метрику. Если такой информации в консоли нет, проверьте размеченный контент. Для этого обратитесь к вебмастеру.
