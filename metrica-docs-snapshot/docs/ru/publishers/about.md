# Статистика по медийным и контентным проектам

- [Как получать статистику по материалам](ru/publishers/about#how-to)
- [Узнайте больше](ru/publishers/about#uznajte-bolshe)

В Метрике есть набор инструментов для решения задач медийных и контентных проектов. Посмотрев [специальные отчеты](ru/publishers/reports/main), вы можете узнать, какие тематики и материалы наиболее популярны, как люди читают и взаимодействуют с этими материалами, какие источники приносят больше всего трафика и т. д. Эти инструменты позволят вам:

- следить за трафиком в режиме реального времени;
- анализировать эффективность контента;
- изучать поведение аудитории каждого материала или рубрики;
- принимать решения по развитию контентного проекта;
- оценивать доходность материалов.

## ru/publishers/about#how-toКак получать статистику по материалам

Для сбора статистики Метрика использует микроразметку: [Schema.org](http://www.schema.org/) и [Open Graph](http://ogp.me/). Как правило, она предназначается для структурирования данных, размещенных на сайте. Размеченная информация используется разными сервисами, в том числе поисковыми системами — например, для формирования [сниппетов](https://yandex.ru/support/webmaster/search-results/site-description.html).

Для встраивания микроразметки на сайт можно использовать плагины. Часто их разрабатывают под поисковые системы. Поэтому они могут не полностью подходить для формата разметки, который использует Метрика. Различие заключается в том, что разработанный для поисковых систем плагин обрабатывает все содержимое страниц сайта, а для Метрики нужно разметить только определенные атрибуты (текст статьи, автор, тематика, рубрика и т. д.). В результате данные или не передаются в Метрику и отчеты не формируются, или передаются избыточные данные (вместо текста статьи передается весь текст страницы) и отчеты формируются некорректно.

Внимание

Если вы встраиваете микроразметку с помощью плагина, вероятно, потребуется его доработка. Для этого обратитесь к разработчику плагина или другому специалисту, который обладает навыками разработки.

Чтобы получать статистику, выполните следующее:

1. В настройках счетчика включите опцию **Контентная аналитика**. Укажите, какой тип разметки данных вы собираетесь использовать или уже используете: Schema.org (Microdata или JSON-LD), Open Graph. Если на вашем сайте уже есть оба варианта разметки, выберите предпочтительный.
2. [Установите счетчик Метрики](ru/general/creating-counter) на все страницы сайта или [проверьте, что счетчик установлен правильно](ru/general/check-counter). Примечание Статистика собирается и отображается в отчетах, только если на сайте установлен [новый код счетчика](ru/general/tag-info).
3. Разметьте страницы с материалами, которые вы хотите анализировать. Подробнее о разметке: [Schema.org](ru/publishers/schema-org/schema-org); [Open Graph](ru/publishers/open-graph/open-graph).

1. В настройках счетчика включите опцию **Контентная аналитика**. Выбирать тип разметки не требуется — для Турбо-сайтов данные по контенту собираются независимо от указанного в настройках типа разметки.
2. Чтобы получать совмещенную статистику по материалам на основном и Турбо-сайте: [установите](ru/code/install-counter-turbo) на Турбо-сайте тот же счетчик Метрики, что и на основном сайте; для каждого материала задайте одинаковые идентификаторы или заголовки (идентификаторы в таком случае должны быть пустыми) на основном и Турбо-сайте.
3. Чтобы смотреть [отчет по рубрикам](ru/publishers/reports/rubric), добавьте их в виде `breadcrumblist` в структуру RSS-канала Турбо-сайта.

Чтобы Метрика начала учет данных и отчеты начали отображаться, посетитель должен просмотреть размеченную статью размером более 500 символов или любую страницу с разметкой [Вопросы и ответы](https://yandex.ru/support/webmaster/supported-schemas/q-and-a.html).

По размеченным материалам и страницам Турбо-сайта начнет собираться статистика. Отчеты появятся в [разделе **Контент**](ru/publishers/reports/main) через несколько часов.
