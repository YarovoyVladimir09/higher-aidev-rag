# Отчет «Посещаемость по времени суток»

- [Какие задачи может решать отчет](ru/visitors/activity-daytime#case)
- [Структура и настройки отчета](ru/visitors/activity-daytime#data)

Отчет показывает распределение трафика на сайте по времени суток. Время соответствует часовому поясу, который вы указали в настройках счетчика.

Посмотреть отчет: **Отчеты** → **Аудитория** → **Посещаемость по времени суток**.

## ru/visitors/activity-daytime#dataСтруктура и настройки отчета

Данные в отчете сгруппированы по часовым интервалам в течение суток. Можно просмотреть статистику по визитам, которые начались в один из таких интервалов.

Например, группировка «10:00» объединяет данные по визитам, которые начались в период между 10:00 и 11:00.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.

[Написать в чат](https://yandex.ru/chat/#/user/036e6a02-3620-9cdc-4c5e-a34667a7379e?utm_source=spravka)
