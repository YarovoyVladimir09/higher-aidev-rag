# Отчет «Долгосрочные интересы»

- [Какие задачи может решать отчет](ru/visitors/interests#case)
- [Структура и настройки отчета](ru/visitors/interests#data)
- [Отличие от отчета «Долгосрочные интересы (старая версия)»](ru/visitors/interests#diff-report)

Внимание

Данные в отчете доступны с 24 августа 2018 г.

Отчет показывает, насколько та или иная тематика интересна посетителям вашего сайта, а также позволяет анализировать поведение посетителей на сайте в зависимости от их интересов.

Интересы посетителей вычисляются путем анализа их поведения в интернете с помощью технологии [Крипта](http://company.yandex.ru/technologies/crypta/). Из-за особенностей использования этой технологии количество визитов, представленное в отчете, может быть меньше, чем в других отчетах сервиса.

Посмотреть отчет: **Отчеты** → **Аудитория** → **Долгосрочные интересы**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/interest2?period=month&selected_rows=%5B%7B%22path%22%3A%5B%22business%22%5D%2C%22name%22%3A%5B%22%D0%91%D0%B8%D0%B7%D0%BD%D0%B5%D1%81%22%5D%7D%2C%7B%22path%22%3A%5B%22tourism%22%5D%2C%22name%22%3A%5B%22%D0%A2%D1%83%D1%80%D0%B8%D0%B7%D0%BC%22%5D%7D%2C%7B%22path%22%3A%5B%22cars%22%5D%2C%22name%22%3A%5B%22%D0%90%D0%B2%D1%82%D0%BE%D0%BC%D0%BE%D0%B1%D0%B8%D0%BB%D0%B8%22%5D%7D%2C%7B%22path%22%3A%5B%22construction%22%5D%2C%22name%22%3A%5B%22%D0%9E%D0%B1%D1%83%D1%81%D1%82%D1%80%D0%BE%D0%B9%D1%81%D1%82%D0%B2%D0%BE%22%5D%7D%2C%7B%22path%22%3A%5B%22mobile%22%5D%2C%22name%22%3A%5B%22%D0%9C%D0%BE%D0%B1%D0%B8%D0%BB%D1%8C%D0%BD%D0%B0%D1%8F+%D1%81%D0%B2%D1%8F%D0%B7%D1%8C+%D0%B8+%D0%B8%D0%BD%D1%82%D0%B5%D1%80%D0%BD%D0%B5%D1%82%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/visitors/interests#caseКакие задачи может решать отчет

Отчет поможет увидеть общую картину интересов посетителей сайта.

Вы можете выбрать ТОП тематик, которые интересны большинству посетителей сайта — с помощью анализа [аффинити-индекса](ru/visitors/interests#affinity).

Для этого [создайте и настройте цель](ru/general/goals), а затем [используйте ее](ru/reports/goals) в отчете.

Примечание

Для этого необходимо [передавать в Метрику данные электронной коммерции](ru/data/e-commerce).

Отчет покажет интересы посетителей, которые принесли сайту доход больше, меньше или равный указанной вами сумме. Например:

1. В группе условий **для людей, у которых** нажмите значок .
2. Выберите условие **Электронная коммерция** → **Суммарный доход**.
3. Выберите значение **Больше**, **Меньше** или **Равно** и укажите сумму.

## ru/visitors/interests#dataСтруктура и настройки отчета

Данные в отчете объединены по категориям интересов посетителей. У некоторых категорий может быть до двух подуровней.

Иногда сервис не может определить, к какой подкатегории относится посетитель — в этом случае он будет отнесен к категории первого уровня. Таким образом, количество посетителей в первом уровне не равно сумме во всех вложенных уровнях.

Для каждой тематики в отчете рассчитывается *аффинити-индекс* — показатель того, насколько сильно эта тематика интересует посетителей сайта по сравнению с аудиторией интернета в целом:

- Значение, близкое к 100%, говорит о том, что интерес пользователей к теме ничем не отличается от среднего по интернету.
- Если аффинити-индекс, наоборот, заметно превышает 100%, тематика может быть привлекательной для вашей аудитории. Например, индекс 200% для автомобилей означает, что посетители сайта вдвое чаще интересуются темой авто, чем обычные пользователи в сети.

Анализируя аффинити-индекс, вы можете выявить смежные интересы вашей аудитории. Например, узнать, что ваши целевые посетители интересуются не только авто, но и финансами.

Сопоставив аффинити-индекс с другими показателями отчета (визитами, отказами, конверсией), вы можете определить предпочтения посетителей, которые конвертируются лучше всего.

Чтобы добавить метрику **Аффинити-индекс** в другой отчет Яндекс Метрики, сначала добавьте в него группировку **Категории интересов**, а затем — метрику. Без добавления этой группировки метрика недоступна.

Отчет поддерживает [настройки, доступные в Яндекс Метрике](ru/reports/report-general).
