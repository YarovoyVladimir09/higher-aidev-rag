# Отчет «Глубина просмотра»

- [Какие задачи может решать отчет](ru/visitors/activity-depth#case)
- [Структура и настройки отчета](ru/visitors/activity-depth#data)

Отчет содержит информацию о количестве просмотренных страниц. С помощью этого показателя вы можете определить степень заинтересованности аудитории вашего сайта.

Посмотреть отчет: **Отчеты** → **Аудитория** → **Глубина просмотра**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/deepness_depth?period=month&selected_rows=%5B%7B%22path%22%3A%5B%221%22%5D%2C%22name%22%3A%5B%221%22%5D%7D%2C%7B%22path%22%3A%5B%222-3%22%5D%2C%22name%22%3A%5B%222-3%22%5D%7D%2C%7B%22path%22%3A%5B%224-7%22%5D%2C%22name%22%3A%5B%224-7%22%5D%7D%2C%7B%22path%22%3A%5B%228-15%22%5D%2C%22name%22%3A%5B%228-15%22%5D%7D%2C%7B%22path%22%3A%5B%2216-31%22%5D%2C%22name%22%3A%5B%2216-31%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/visitors/activity-depth#caseКакие задачи может решать отчет

Отчет покажет, сколько страниц просматривают посетители в течение *визита*.

Чтобы получить эту информацию, [создайте цель](ru/general/goals) и [используйте ее в отчете](ru/reports/goals).

## ru/visitors/activity-depth#dataСтруктура и настройки отчета

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.

Последовательность действий (активность) одного [посетителя](ru/visitors/activity-depth#user-main) на сайте (на одном счетчике). Активностью посетителя считаются: просмотры страниц, переходы по внешним ссылкам, загрузки файлов и вызов функций [reachGoal](ru/objects/reachgoal), [hit](ru/objects/hit), [params](ru/objects/params-method), [extLink](ru/objects/extlink), [file](ru/objects/file), [notBounce](ru/objects/notbounce).
