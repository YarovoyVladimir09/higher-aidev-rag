# Отчет «Общее число визитов»

- [Какие задачи может решать отчет](ru/visitors/loyalty-general#case)
- [Структура и настройки отчета](ru/visitors/loyalty-general#data)

Отчет содержит информацию о количестве визитов посетителей. В отчете учитываются только те посетители, которые были на сайте в выбранный период.

Посмотреть отчет: **Отчеты** → **Аудитория** → **Общее число визитов**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/loyalty_visits?metric=ym%3As%3Ausers&period=month).

## ru/visitors/loyalty-general#caseКакие задачи может решать отчет

С помощью отчета вы можете узнать, например, в каком визите посетители достигают цели. Чтобы получить эту информацию, [создайте цель](ru/general/goals) и [используйте ее в отчете](ru/reports/goals).

## ru/visitors/loyalty-general#dataСтруктура и настройки отчета

Данные в отчете сгруппированы по количеству визитов.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.
