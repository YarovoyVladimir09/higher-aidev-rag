# Отчет «Пол»

- [Какие задачи может решать отчет](ru/visitors/sex#case)
- [Структура и настройки отчета](ru/visitors/sex#data)

Отчеты по основным социально-демографическим характеристикам пользователей представлены на основе данных, полученных с помощью технологии [Крипта](http://company.yandex.ru/technologies/crypta/). Из-за особенностей использования этой технологии количество визитов, представленное в отчете, может быть меньше, чем в других отчетах сервиса.

Посмотреть отчет: **Отчеты** → **Аудитория** → **Пол**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/demography_structure?period=month&selected_rows=%5B%7B%22path%22%3A%5B%22male%22%5D%2C%22name%22%3A%5B%22%D0%BC%D1%83%D0%B6%D1%81%D0%BA%D0%BE%D0%B9%22%5D%7D%2C%7B%22path%22%3A%5B%22female%22%5D%2C%22name%22%3A%5B%22%D0%B6%D0%B5%D0%BD%D1%81%D0%BA%D0%B8%D0%B9%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/visitors/sex#caseКакие задачи может решать отчет

Отчет помогает определить пол аудитории вашего сайта.

Сделать это можно с помощью отказов. Чем выше показатель отказов, тем меньше сайт вовлекает посетителей — они уходят в течение 15 секунд, просмотрев только одну страницу.

Чтобы получить объединенные данные по полу и возрасту, добавьте необходимую группировку: **Аудитория** → **Возраст**.

Чтобы получить эту информацию, [создайте цель](ru/general/goals) и [используйте ее в отчете](ru/reports/goals).

Примечание

При анализе целевых визитов и посетителей важно учитывать [модель атрибуции](ru/reports/attribution-model).

## ru/visitors/sex#dataСтруктура и настройки отчета

В отчете приведена информация по полу посетителей. Данные разделены на две группы: женский и мужской пол.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
