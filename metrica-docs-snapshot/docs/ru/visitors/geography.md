# Отчет «География»

- [Какие задачи может решать отчет](ru/visitors/geography#case)
- [Структура и настройки отчета](ru/visitors/geography#data)

Отчет содержит информацию о географическом распределении посетителей вашего сайта.

Посмотреть отчет: **Отчеты** → **Аудитория** → **География**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/geo?period=month&iselected_rows=%5B%7B%22path%22%3A%5B%22225%22%5D%2C%22name%22%3A%5B%22%D0%A0%D0%BE%D1%81%D1%81%D0%B8%D1%8F%22%5D%7D%2C%7B%22path%22%3A%5B%22994%22%5D%2C%22name%22%3A%5B%22%D0%98%D0%BD%D0%B4%D0%B8%D1%8F%22%5D%7D%2C%7B%22path%22%3A%5B%2284%22%5D%2C%22name%22%3A%5B%22%D0%A1%D0%A8%D0%90%22%5D%7D%2C%7B%22path%22%3A%5B%22983%22%5D%2C%22name%22%3A%5B%22%D0%A2%D1%83%D1%80%D1%86%D0%B8%D1%8F%22%5D%7D%2C%7B%22path%22%3A%5B%22120%22%5D%2C%22name%22%3A%5B%22%D0%9F%D0%BE%D0%BB%D1%8C%D1%88%D0%B0%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/visitors/geography#dataСтруктура и настройки отчета

В отчете используются группировки, аналогичные иерархии территориального деления:

- Страна.
- Область (административная единица). Может не определяться.
- Город.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
