# Отчет «Возраст»

- [Какие задачи может решать отчет](ru/visitors/age#case)
- [Структура и настройки отчета](ru/visitors/age#data)

Отчеты по основным социально-демографическим характеристикам пользователей представлены на основе данных, полученных с помощью технологии [Крипта](http://company.yandex.ru/technologies/crypta/). Из-за особенностей использования этой технологии количество визитов, представленное в отчете, может быть меньше, чем в других отчетах сервиса.

Посмотреть отчет: **Отчеты** → **Аудитория** → **Возраст**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/demography_age?period=month&selected_rows=%5B%7B%22path%22%3A%5B%2217%22%5D%2C%22name%22%3A%5B%22%D0%BC%D0%BB%D0%B0%D0%B4%D1%88%D0%B5+18+%D0%BB%D0%B5%D1%82%22%5D%7D%2C%7B%22path%22%3A%5B%2218%22%5D%2C%22name%22%3A%5B%2218%E2%80%9124+%D0%B3%D0%BE%D0%B4%D0%B0%22%5D%7D%2C%7B%22path%22%3A%5B%2225%22%5D%2C%22name%22%3A%5B%2225%E2%80%9134+%D0%B3%D0%BE%D0%B4%D0%B0%22%5D%7D%2C%7B%22path%22%3A%5B%2235%22%5D%2C%22name%22%3A%5B%2235%E2%80%9144+%D0%B3%D0%BE%D0%B4%D0%B0%22%5D%7D%2C%7B%22path%22%3A%5B%2245%22%5D%2C%22name%22%3A%5B%2245-54+%D0%B3%D0%BE%D0%B4%D0%B0%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/visitors/age#caseКакие задачи может решать отчет

Отчет помогает определить возраст аудитории вашего сайта.

Сделать это можно с помощью отказов. Чем выше показатель отказов, тем меньше сайт вовлекает посетителей — они уходят в течение 15 секунд, просмотрев только одну страницу.

Чтобы получить объединенные данные по полу и возрасту, добавьте необходимую группировку: **Аудитория** → **Пол**.

Чтобы получить эту информацию, [создайте цель](ru/general/goals) и [используйте ее в отчете](ru/reports/goals).

Примечание

При анализе целевых визитов и посетителей важно учитывать [модель атрибуции](ru/reports/attribution-model).

## ru/visitors/age#dataСтруктура и настройки отчета

В отчете приведена информация по возрасту посетителей. Данные распределены по возрастным группам:

- младше 18;
- 18–24;
- 25-34;
- 35–44;
- 45–54;
- 55 и старше.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
