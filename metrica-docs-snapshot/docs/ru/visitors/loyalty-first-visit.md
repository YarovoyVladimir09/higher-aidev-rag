# Отчет «Время с первого визита»

- [Какие задачи может решать отчет](ru/visitors/loyalty-first-visit#case)
- [Структура и настройки отчета](ru/visitors/loyalty-first-visit#data)

Отчет показывает, через сколько дней посетители возвращаются на сайт после первого визита. В отчете учитываются только те посетители, которые были на сайте в выбранный период.

Посмотреть отчет: **Отчеты** → **Аудитория** → **Время с первого визита**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/loyalty_newness?sort=-ym%3As%3Avisits&period=2018-12-12%3A2018-12-31selected_rows=%5B%7B%22path%22%3A%5B%220%22%5D%2C%22name%22%3A%5B%220+%D0%B4%D0%BD%D0%B5%D0%B9%22%5D%7D%2C%7B%22path%22%3A%5B%2264-127%22%5D%2C%22name%22%3A%5B%2264%E2%80%91127+%D0%B4%D0%BD%D0%B5%D0%B9%22%5D%7D%2C%7B%22path%22%3A%5B%22128-255%22%5D%2C%22name%22%3A%5B%22128%E2%80%91255+%D0%B4%D0%BD%D0%B5%D0%B9%22%5D%7D%2C%7B%22path%22%3A%5B%2216-31%22%5D%2C%22name%22%3A%5B%2216%E2%80%9131+%D0%B4%D0%B5%D0%BD%D1%8C%22%5D%7D%2C%7B%22path%22%3A%5B%228-15%22%5D%2C%22name%22%3A%5B%228%E2%80%9115+%D0%B4%D0%BD%D0%B5%D0%B9%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/visitors/loyalty-first-visit#caseКакие задачи может решать отчет

Отчет покажет статистику с разбивкой по количеству дней с момента первого визита на сайт. Посетителей с наиболее длинной историей визитов можно считать лояльной аудиторией.

Чтобы получить эту информацию, [создайте цель](ru/general/goals) и [используйте ее в отчете](ru/reports/goals).
