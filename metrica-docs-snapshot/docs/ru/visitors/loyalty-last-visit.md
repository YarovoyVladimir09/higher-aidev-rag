# Отчет «Время с предпоследнего визита»

- [Какие задачи может решать отчет](ru/visitors/loyalty-last-visit#case)
- [Структура и настройки отчета](ru/visitors/loyalty-last-visit#data)

Отчет показывает, как часто посетители возвращаются на сайт. Он может быть полезен при анализе сайтов, контент которых регулярно обновляется, например, новостных ресурсов. В отчете учитываются только те посетители, которые были на сайте в выбранный период и совершили не меньше двух визитов с момента установки счетчика на сайт.

Посмотреть отчет: **Отчеты** → **Аудитория** → **Время с предпоследнего визита**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/loyalty_recency?sort=-ym%3As%3Avisits&period=2018-12-12%3A2018-12-31&selected_rows=%5B%7B%22path%22%3A%5B%220%22%5D%2C%22name%22%3A%5B%220+%D0%B4%D0%BD%D0%B5%D0%B9%22%5D%7D%2C%7B%22path%22%3A%5B%221%22%5D%2C%22name%22%3A%5B%221+%D0%B4%D0%B5%D0%BD%D1%8C%22%5D%7D%2C%7B%22path%22%3A%5B%222-3%22%5D%2C%22name%22%3A%5B%222%E2%80%913+%D0%B4%D0%BD%D1%8F%22%5D%7D%2C%7B%22path%22%3A%5B%224-7%22%5D%2C%22name%22%3A%5B%224%E2%80%917+%D0%B4%D0%BD%D0%B5%D0%B9%22%5D%7D%2C%7B%22path%22%3A%5B%228-15%22%5D%2C%22name%22%3A%5B%228%E2%80%9115+%D0%B4%D0%BD%D0%B5%D0%B9%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/visitors/loyalty-last-visit#caseКакие задачи может решать отчет

С помощью отчета вы можете определить, сколько посетителей возвращаются на сайт ежедневно. Для этого обратите внимание на строку «1 день».
