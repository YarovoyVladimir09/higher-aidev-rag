# Отчет «Время на сайте»

- [Какие задачи может решать отчет](ru/visitors/activity-time#case)
- [Структура и настройки отчета](ru/visitors/activity-time#data)

Отчет содержит информацию о времени, которое посетители провели на сайте. С помощью этого показателя вы можете определить степень заинтересованности аудитории вашего сайта.

Посмотреть отчет: **Отчеты** → **Аудитория** → **Время на сайте**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/deepness_time?period=month&selected_rows=%5B%7B%22path%22%3A%5B%220%22%5D%2C%22name%22%3A%5B%220+%D1%81%D0%B5%D0%BA%D1%83%D0%BD%D0%B4+(%D0%BE%D1%82%D0%BA%D0%B0%D0%B7)%22%5D%7D%2C%7B%22path%22%3A%5B%221%22%5D%2C%22name%22%3A%5B%221+%E2%80%93+9+%D1%81%D0%B5%D0%BA%D1%83%D0%BD%D0%B4%22%5D%7D%2C%7B%22path%22%3A%5B%2210%22%5D%2C%22name%22%3A%5B%2210+%E2%80%93+29+%D1%81%D0%B5%D0%BA%D1%83%D0%BD%D0%B4%22%5D%7D%2C%7B%22path%22%3A%5B%2230%22%5D%2C%22name%22%3A%5B%2230+%E2%80%93+59+%D1%81%D0%B5%D0%BA%D1%83%D0%BD%D0%B4%22%5D%7D%2C%7B%22path%22%3A%5B%2260%22%5D%2C%22name%22%3A%5B%221+%D0%BC%D0%B8%D0%BD%D1%83%D1%82%D0%B0%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/visitors/activity-time#caseКакие задачи может решать отчет

Отчет покажет, сколько в среднем длится *визит* посетителей сайта.

Чтобы получить эту информацию, [создайте цель](ru/general/goals) и [используйте ее в отчете](ru/reports/goals).

Последовательность действий (активность) одного [посетителя](ru/visitors/activity-time#user-main) на сайте (на одном счетчике). Активностью посетителя считаются: просмотры страниц, переходы по внешним ссылкам, загрузки файлов и вызов функций [reachGoal](ru/objects/reachgoal), [hit](ru/objects/hit), [params](ru/objects/params-method), [extLink](ru/objects/extlink), [file](ru/objects/file), [notBounce](ru/objects/notbounce).
