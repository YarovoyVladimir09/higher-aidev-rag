# Клик по кнопке

- [Передача дохода β](ru/simple-goal/click-beta#transfer)
- [Ограничения](ru/simple-goal/click-beta#general)
- [Вопросы и ответы](ru/simple-goal/click-beta#qanda)
- [Узнайте больше](ru/simple-goal/click-beta#uznajte-bolshe)

Вы можете настроить достижение цели по кликам на различные кнопки и ссылки на вашем сайте. При создании цели Метрика сохраняет информацию о расположении и свойствах этих элементов.

Когда посетители вашего сайта нажимают на кнопки или ссылки, Метрика распознает этот клик и фиксирует достижение цели. Каждый раз, когда пользователь нажимает на кнопку или ссылку, цель считается достигнутой.

Примечание

Для поиска элемента на странице Метрика использует `XPATH` — язык запросов для поиска узлов в HTML-документе, а также атрибут ID или контент элемента. Если расположение кликабельного элемента на сайте повторяется на разных страницах в одном и том же месте, то цель будет достигаться на нескольких страницах. Например, ссылки в навигационном меню вашего сайта.

`XPATH` — это язык запросов, который позволяет находить определенные элементы в XML- и HTML-документах. С его помощью можно указать путь к нужному элементу или группе элементов.

```
        <html>
          <body>
            <div class="container">
              <p>Первый абзац.</p>
              <ul>
                <li>Первый элемент списка.</li>
                <li>Второй элемент списка.</li>
              </ul>
              <p>Второй абзац.</p>
            </div>
          </body>
        </html>
```

Если вы хотите найти второй элемент списка (`<li>`), используйте следующий `XPATH`-запрос:

`//HTML/BODY/DIV/UL/LI[2]`

Чтобы создать цель вручную:

1. В Метрике перейдите на страницу **Цели** в левом меню.
2. Нажмите кнопку **Добавить цель**.
3. В поле **Название** укажите имя создаваемой цели.
4. Выберите тип цели **Клик по кнопке**.
5. Укажите в поле страницу сайта, на которой размещена кнопка. По умолчанию будет показан самый популярный URL на счетчике. Нажмите **Перейти и выбрать кнопку**.
6. В режиме **Выбор элемента** наведите курсор мыши на нужную вам кнопку, выберите ее и нажмите Отслеживать клики. Чтобы перейти на другую страницу или открыть всплывающее окно, выберите режим **Взаимодействие с сайтом**. [Почему выбор кнопки может не отображаться](ru/simple-goal/click-beta#qanda).
7. Нажмите кнопку **Добавить цель**. Созданная цель отобразится в списке целей. Метрика начнет сбор статистики по ней в течение нескольких минут.
8. [Проверьте](ru/general/check-goal#check-goal), правильно ли работает цель.

Внимание

Перед использованием этого типа цели в рекламе обязательно [проверьте](ru/general/check-goal#check-goal) корректность настройки этой цели и ее достижения на вашем сайте. Любые изменения в HTML-верстке вашего сайта могут привести к некорректной работе цели.

Достижение цели зафиксируется, когда посетитель нажмет на кликабельный элемент. Чтобы посмотреть статистику по цели, используйте [Отчет «Конверсии»](ru/reports/conversion#conversion) и [добавляйте цель](ru/reports/report-general#set-report/choose-goal) в другие отчеты Метрики.

## ru/simple-goal/click-beta#transferПередача дохода β

Важно

**Передача дохода** сейчас находится на этапе открытого тестирования. Если ваш сайт соответствует требованиям работы этого функционала, но при работе с ним возникают проблемы, — [напишите нам](https://yandex.ru/chat/#/user/036e6a02-3620-9cdc-4c5e-a34667a7379e?utm_source=spravka).

Если вы хотите передавать вместе с достижением цели **Клик по кнопке** доход, указанный на странице вместе с этой кнопкой, вы можете его выбрать при настройке цели:

1. В режиме **Выбор элемента** выберите кнопку, по которой хотите отслеживать клики.
2. В нижней панели нажмите **Указать доход**. Активируется режим выбора элемента на странице вашего сайта, содержащего контент.
3. Выберите блок, в котором содержится число, указывающее на получение дохода при клике по выбранной кнопке.
4. Нажмите кнопку **Отслеживать клики** и завершите настройку целей в интерфейсе Метрики.

Валюта дохода для данного типа целей указывается в настройках счетчика.

Внимание

Отправка дохода будет происходить при каждом клике по кнопке. Если на вашем сайте не настроена проверка заполнения всех необходимых полей, неоднократное нажатие на кнопку пользователями вашего сайта приведет к нескольким отправкам дохода, которые будут просуммированы в отчетах.

Вы можете проверить корректность передаваемых данных, используя [инструкцию](ru/general/check-goal#check-goal).

- Контент-элемент, содержащий доход, должен иметь уникальный путь `XPATH` или атрибуты `ID` или `CLASS` в структуре веб-страницы. В случае изменений на HTML-странице, доход может не передаваться или передаваться некорректно.
- Для корректной работы контент-элемент должен содержать внутри числовое значение.
- Контент-элемент, содержащий доход, должен находится на одной странице с кнопкой или формой в момент достижения цели.
- Если клик по кнопке или отправка формы подразумевают переход на другую страницу сразу после совершения действия пользователям, цель может не достигаться, если у пользователя устаревший браузер, слабое устройство или медленный интернет.
- Во избежание отправки нескольких целей с одинаковым доходом рекомендуем сделать для кнопки проверку выполнения всех необходимых условий.

## ru/simple-goal/click-beta#qandaВопросы и ответы

Если в настройках счетчика не подключен Вебвизор, цель может работать без него.

Цель может работать для кода счетчика предыдущей версии.

Если в настройках счетчика на вкладке **Фильтры** включена операция **Заменять https на http**, выбор кнопки недоступен.

Если страница, на которой вы хотите выбрать кнопку, перенаправляет на другую, то выбор кнопки недоступен. Чтобы отслеживать нажатие на определенную кнопку, используйте [Цель через JavaScript-событие](ru/general/goal-js-event).

Если сайт использует технологию [Content Security Policy](https://www.w3.org/TR/CSP/), добавьте в исключения [домены Метрики](ru/code/install-counter-csp#murls).

Цели в Яндекс Метрике работают одинаково для всех источников. Возможно, ни один посетитель из интересующего вас источника еще не достиг цель.

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.

Это может происходить по следующим причинам:

- В Яндекс Метрике условие цели не охватывает все возможные варианты. Например, цель настроена на посещение страницы с подтверждением заказа, а на сайте еще есть возможность оформить быстрый заказ.
- У посетителя сайта в браузере установлен плагин, блокирующий работу счетчика.
- У посетителя подключен антивирус с жесткими настройками приватности.
- У посетителя низкоскоростное интернет-подключение, из-за которого на целевой странице не загрузился счетчик.
