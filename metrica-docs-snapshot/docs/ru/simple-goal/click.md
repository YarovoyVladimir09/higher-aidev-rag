# Клик по кнопке

- [Ограничения](ru/simple-goal/click#general)
- [Вопросы и ответы](ru/simple-goal/click#qanda)
- [Узнайте больше](ru/simple-goal/click#uznajte-bolshe)

Вы можете настроить достижение цели по кликам на различные кнопки и ссылки на вашем сайте. При создании цели Метрика сохраняет информацию о расположении и свойствах этих элементов.

Когда посетители вашего сайта нажимают на кнопки или ссылки, Метрика распознает этот клик и фиксирует достижение цели. Каждый раз, когда пользователь нажимает на кнопку или ссылку, цель считается достигнутой.

Примечание

Для поиска элемента на странице Метрика использует `XPATH` — язык запросов для поиска узлов в HTML-документе, а также атрибут ID или контент элемента. Если расположение кликабельного элемента на сайте повторяется на разных страницах в одном и том же месте, то цель будет достигаться на нескольких страницах. Например, ссылки в навигационном меню вашего сайта.

`XPATH` — это язык запросов, который позволяет находить определенные элементы в XML- и HTML-документах. С его помощью можно указать путь к нужному элементу или группе элементов.

```
        <html>
          <body>
            <div class="container">
              <p>Первый абзац.</p>
              <ul>
                <li>Первый элемент списка.</li>
                <li>Второй элемент списка.</li>
              </ul>
              <p>Второй абзац.</p>
            </div>
          </body>
        </html>
```

Если вы хотите найти второй элемент списка (`<li>`), используйте следующий `XPATH`-запрос:

`//HTML/BODY/DIV/UL/LI[2]`

Чтобы создать цель вручную:

1. В Метрике перейдите на страницу **Цели** в левом меню.
2. Нажмите кнопку **Добавить цель**.
3. Выберите тип цели **Клик по кнопке**.
4. В поле **Название** укажите имя создаваемой цели.
5. Укажите в поле страницу сайта, на которой размещена кнопка. По умолчанию будет показан самый популярный URL на счетчике. Нажмите **Перейти и выбрать кнопку**.
6. В режиме **Выбор элемента** наведите курсор мыши на нужную вам кнопку, выберите ее и нажмите **Отслеживать клики**. Чтобы перейти на другую страницу или открыть всплывающее окно, выберите режим **Взаимодействие с сайтом**. [Почему выбор кнопки может не отображаться](ru/simple-goal/click#dont)
7. Нажмите кнопку **Добавить цель**. Созданная цель отобразится в списке целей. Метрика начнет сбор статистики по ней в течение нескольких минут.
8. [Проверьте](ru/general/check-goal), правильно ли работает цель.

Внимание

Перед использованием этого типа цели в рекламе и продвижении обязательно [проверьте](ru/general/check-goal#check-goal) корректность настройки этой цели и ее достижения на вашем сайте. Любые изменения в HTML-верстке вашего сайта могут привести к некорректной работе цели.

Достижение цели зафиксируется, когда посетитель нажмет на кликабельный элемент. Чтобы посмотреть статистику по цели, используйте [Отчет «Конверсии»](ru/reports/conversion) и [добавляйте цель](ru/reports/report-general#choose-goal) в другие отчеты Метрики.

- source: ru/_includes/general/goal-page-visit/id-general/3.md Во время одного визита посетителя сервис может фиксировать до 1000 достижений офлайн-целей и 400 достижений онлайн-целей, созданных для счетчика. endsource: ru/_includes/general/goal-page-visit/id-general/3.md
- Использование iframe-элементов на странице может приводить к ее некорректной работе.
- source: ru/_includes/general/goal-page-visit/id-general/4.md При редактировании счетчика или цели накопленная ранее информация не изменяется. endsource: ru/_includes/general/goal-page-visit/id-general/4.md
- source: ru/_includes/general/goal-page-visit/id-general/5.md Если вы удалите цель, собранная по ней информация будет недоступна в отчетах. endsource: ru/_includes/general/goal-page-visit/id-general/5.md
- source: ru/_includes/general/goal-page-visit/id-general/7.md Цель не сработает, если в настройках счетчика на вкладке [Фильтры](ru/general/filters): Включены обе операции: **Вырезать все параметры** и **Привести к нижнему регистру** для URL страницы и ее параметров. Включена операция **Вырезать все параметры** для URL страницы. endsource: ru/_includes/general/goal-page-visit/id-general/7.md

## ru/simple-goal/click#qandaВопросы и ответы

Если в настройках счетчика не подключен Вебвизор, цель может работать без него.

Цель может работать для кода счетчика предыдущей версии.

Если в настройках счетчика на вкладке **Фильтры** включена операция **Заменять https на http**, выбор кнопки недоступен.

Если страница, на которой вы хотите выбрать кнопку, перенаправляет на другую, то выбор кнопки недоступен. Чтобы отслеживать нажатие на определенную кнопку, используйте [Цель через JavaScript-событие](ru/general/goal-js-event).

Если сайт использует технологию [Content Security Policy](https://www.w3.org/TR/CSP/), добавьте в исключения [домены Метрики](ru/code/install-counter-csp#murls).

Цели в Яндекс Метрике работают одинаково для всех источников. Возможно, ни один посетитель из интересующего вас источника еще не достиг цель.

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.

Это может происходить по следующим причинам:

- В Яндекс Метрике условие цели не охватывает все возможные варианты. Например, цель настроена на посещение страницы с подтверждением заказа, а на сайте еще есть возможность оформить быстрый заказ.
- У посетителя сайта в браузере установлен плагин, блокирующий работу счетчика.
- У посетителя подключен антивирус с жесткими настройками приватности.
- У посетителя низкоскоростное интернет-подключение, из-за которого на целевой странице не загрузился счетчик.

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.
