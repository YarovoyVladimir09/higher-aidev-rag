# Отследить переход в социальные сети

- [Ограничения](ru/simple-goal/social-networks#general)
- [Узнайте больше](ru/simple-goal/social-networks#uznajte-bolshe)

Примечание

Цель создается автоматически, если в настройках счетчика включена опция **Автоматические цели**.

Вы можете управлять этой целью также, как и другими [автоматическими целями](ru/general/auto-goals).

Если на вашем сайте размещены ссылки на социальные сети, с помощью Метрики вы можете отслеживать количество переходов по ним.

Для этого в Метрике нужно настроить специальную цель. Вы можете создать ее:

- Для всех социальных сетей на сайте. Метрика распознает социальные сети по наличию их URL в ссылках. Например: <a href="social-network.com">Присоединиться</a>
- Для определенной социальной сети. Используйте этот способ, например, для отслеживания разных социальных сетей. Метрика будет искать `<указанный адрес>` в ссылках.

| Facebook * | facebook.com, m.facebook.com |
| YouTube | youtube.com, youtu.be |

Чтобы создать цель вручную:

1. В Метрике перейдите на страницу **Цели** в левом меню.
2. Нажмите кнопку **Добавить цель**.
3. Выберите тип цели **Переход в соц. сеть**.
4. В поле **Название** укажите имя создаваемой цели.
5. Выберите, для каких социальных сетей нужно создать цель.
6. Нажмите кнопку **Добавить цель**. Созданная цель отобразится в списке целей. Метрика начнет сбор статистики по ней в течение нескольких минут.
7. source: ru/_includes/simple-goal/messengers/id-messengers/li-check.md Проверить, работает ли цель, можно в отчетах [Конверсии](ru/reports/conversion) или [Внешние переходы](ru/content/external-links). В них должны появиться данные. Для проверки нужно выполнить целевое действие на сайте. Если в настройках счетчика задан фильтр **Не учитывать мои визиты**, проверьте цели на сайте в приватном режиме браузера (например, [Инкогнито](https://yandex.ru/support/browser/personal-data-protection/incognito-mode.html) в Яндекс Браузере). endsource: ru/_includes/simple-goal/messengers/id-messengers/li-check.md

Достижение цели будет зафиксировано, когда посетитель нажмет на ссылку, которая ведет в социальную сеть. Чтобы посмотреть статистику по цели, используйте [Отчет «Конверсии»](ru/reports/conversion) и [добавляйте цель](ru/reports/report-general#choose-goal) в другие отчеты Метрики.

Цели в Яндекс Метрике работают одинаково для всех источников. Возможно, ни один посетитель из интересующего вас источника еще не достиг цель.

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.

Это может происходить по следующим причинам:

- В Яндекс Метрике условие цели не охватывает все возможные варианты. Например, цель настроена на посещение страницы с подтверждением заказа, а на сайте еще есть возможность оформить быстрый заказ.
- У посетителя сайта в браузере установлен плагин, блокирующий работу счетчика.
- У посетителя подключен антивирус с жесткими настройками приватности.
- У посетителя низкоскоростное интернет-подключение, из-за которого на целевой странице не загрузился счетчик.
