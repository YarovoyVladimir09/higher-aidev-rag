# Отследить скачивание файлов

- [Ограничения](ru/simple-goal/download#general)
- [Узнайте больше](ru/simple-goal/download#uznajte-bolshe)

Примечание

Цель создается автоматически, если в настройках счетчика включена опция **Автоматические цели**.

Вы можете управлять этой целью также, как и другими [автоматическими целями](ru/general/auto-goals).

Если на вашем сайте размещены прайс, лицензионное соглашение или другие файлы, вы можете отслеживать, как часто посетители скачивают их.

Для этого в Метрике нужно настроить специальную цель. Вы можете создать ее:

- Для любого файла на сайте. Эта цель будет работать для самых популярных файлов типа: документ; текст; исполняемый файл; презентация; приложения; сжатый файл; видео; аудио. Поддерживаемые расширения: 3GP 7Z AAC AVI APK CSV DJVU DOCX EXE FLAC FLV GZ KEY MIDI MKA MKV MP3 MP4 MPEG MOV MSI OGG PDF PKG PPS PPT PPTX RAR RTF TXT WAV WMA WMV WMF XLSX ZIP
- Для конкретного файла. В этом случае укажите название файла с расширением или без. Например, `file` или `file.pdf`. Метрика будет искать его в ссылках. Для этой цели можно указывать любое расширение файла. Если у вас необычное расширение, проверьте в консоли, работает ли с ним цель. Как проверить В адресной строке браузера добавьте к адресу страницы, где есть ссылка для скачивания, параметр `_ym_debug=2` и откройте страницу в браузере. http://example.com/?_ym_debug=2 Внизу страницы появится панель отладки. Чтобы ее открыть, нажмите значок . Нажмите на странице на ссылку для загрузки. Информация о достижении цели появится во вкладке **Console**. Всё в порядке, если здесь есть строка вида `File. Counter 12345. Url: https://example.com/download/price.nameshop`, где значение `Url` — ссылка на скачивание файла, которую вы указали при создании цели. Подробно: [Проверка цели](ru/general/check-goal). Цель будет достигнута при клике на ссылку с файлом. Чтобы посмотреть статистику по цели, используйте [Отчет «Конверсии»](ru/reports/conversion) и [добавляйте цель](ru/reports/report-general#choose-goal) в другие отчеты Метрики. Чтобы создать цель вручную: В Метрике в левом меню перейдите на страницу **Цели**. Нажмите кнопку **Добавить цель**. Выберите тип цели **Скачивание файла**. В поле **Название** укажите имя создаваемой цели. Выберите, для каких файлов нужно создать цель. Если вы выбрали **Конкретный файл**, укажите название файла с расширением или без в поле вручную. Например, `file` или `file.pdf`. Убедитесь, что написание полностью совпадает. Нажмите кнопку **Добавить цель**. Созданная цель отобразится в списке целей. Метрика начнет сбор статистики по ней в течение нескольких минут. Проверить, работает ли цель, можно в отчетах [Конверсии](ru/reports/conversion) или [Загрузки файлов](ru/content/file-downloads). В них должны появиться данные. Для проверки нужно выполнить целевое действие на сайте.
