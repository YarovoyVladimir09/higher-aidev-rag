# Возврат из платежной системы

- [Ограничения](ru/simple-goal/payment-system#general)
- [Узнайте больше](ru/simple-goal/payment-system#uznajte-bolshe)

Примечание

Цель создается автоматически, если в настройках счетчика включена опция **Автоматические цели**.

Вы можете управлять этой целью также, как и другими [автоматическими целями](ru/general/auto-goals).

Если у вас на сайте есть ссылки на платежные системы, с помощью специальной цели вы можете отследить, сколько посетителей вернулось на сайт после перехода по ним.

Когда посетитель возвращается на сайт из платежной системы, в Метрику передается URL этой системы через [реферер](https://ru.wikipedia.org/wiki/HTTP_referer). Если посетитель не вернулся на сайт или в реферер не передался адрес платежной системы, достижение цели засчитано не будет.

Метрика не отслеживает данные о действиях на сайте платежной системы (например, об оплате). Поэтому возврат из платежной системы на сайт не всегда означает совершение оплаты.

Вы можете отслеживать переходы из следующих систем:

- Advcash;
- CloudPayments;
- Interkassa;
- MIXPLAT;
- PayAnyWay;
- PAYEER;
- Paykeeper;
- PayMaster;
- PayPal;
- Perfect Money;
- Platron;
- Uniteller;
- QIWI Кошелек;
- Robokassa;
- securepayments.sberbank.ru;
- Unitpay;
- WebMoney;
- Единая Касса (Wallet One);
- Тинькофф Оплата;
- ЮMoney.

Вы можете создать цель для всех платежных систем на сайте. Метрика распознает платежные системы по наличию их URL в реферере при возврате на сайт.

Чтобы создать цель вручную:

1. В Метрике в левом меню перейдите на страницу **Цели**.
2. Нажмите кнопку **Добавить цель**.
3. Выберите тип цели **Возвращение из платежной системы**.
4. В поле **Название** укажите имя создаваемой цели.
5. Нажмите кнопку **Добавить цель**. Созданная цель отобразится в списке целей. Метрика начнет сбор статистики по ней в течение нескольких минут.
6. source: ru/_includes/simple-goal/email/id-email/check.md Проверить, работает ли цель, можно с помощью [панели отладки](ru/general/check-goal#email), а также в отчете [Конверсии](ru/reports/conversion). Для этого на сайте выполните целевое действие. Если в настройках счетчика задан фильтр **Не учитывать мои визиты**, проверьте цели на сайте в приватном режиме браузера (например, [Инкогнито](https://yandex.ru/support/browser/personal-data-protection/incognito-mode.html) в Яндекс Браузере). endsource: ru/_includes/simple-goal/email/id-email/check.md

Чтобы посмотреть статистику по цели, используйте [Отчет «Конверсии»](ru/reports/conversion) и [добавляйте цель](ru/reports/report-general#choose-goal) в другие отчеты Метрики.

## ru/simple-goal/payment-system#generalОграничения

- source: ru/_includes/general/goal-page-visit/id-general/2.md Сервис фиксирует достижение посетителем одной и той же цели на одном счетчике не чаще, чем раз в секунду. endsource: ru/_includes/general/goal-page-visit/id-general/2.md
- source: ru/_includes/general/goal-page-visit/id-general/3.md Во время одного визита посетителя сервис может фиксировать до 1000 достижений офлайн-целей и 400 достижений онлайн-целей, созданных для счетчика. endsource: ru/_includes/general/goal-page-visit/id-general/3.md
- source: ru/_includes/general/goal-page-visit/id-general/4.md При редактировании счетчика или цели накопленная ранее информация не изменяется. endsource: ru/_includes/general/goal-page-visit/id-general/4.md
- source: ru/_includes/general/goal-page-visit/id-general/5.md Если вы удалите цель, собранная по ней информация будет недоступна в отчетах. endsource: ru/_includes/general/goal-page-visit/id-general/5.md

Цели в Яндекс Метрике работают одинаково для всех источников. Возможно, ни один посетитель из интересующего вас источника еще не достиг цель.

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.

Это может происходить по следующим причинам:

- В Яндекс Метрике условие цели не охватывает все возможные варианты. Например, цель настроена на посещение страницы с подтверждением заказа, а на сайте еще есть возможность оформить быстрый заказ.
- У посетителя сайта в браузере установлен плагин, блокирующий работу счетчика.
- У посетителя подключен антивирус с жесткими настройками приватности.
- У посетителя низкоскоростное интернет-подключение, из-за которого на целевой странице не загрузился счетчик.
