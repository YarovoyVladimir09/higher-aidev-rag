# Размещение контактных данных на всех страницах

Телефон и другие контактные данные (или ссылку на них) необходимо указывать на каждой странице сайта. При этом они должны быть хорошо заметны, иначе посетитель, готовый позвонить и сделать заказ, может не найти ваших контактов и уйти к конкурентам.

Чтобы посетитель мог выбрать удобный для него способ заказа товара, укажите все свои контактные данные: телефон, электронная почта, Skype, ICQ и т. д. В большинстве случаев городской номер телефона вызывает больше доверия, чем мобильный.

Рекомендуем указать точное время работы оператора и офиса, чтобы клиент не наткнулся на безответные гудки телефона или закрытую дверь магазина.

Если у вас есть пункты самовывоза, желательно отметить их на карте в разделе «Контактные данные». Сделать удобную и понятную карту для сайта можно с помощью конструктора [Яндекс Карт](http://api.yandex.ru/maps/)[Яндекс Карт](http://api.yandex.com/maps/). Также можно указать, как добраться до вас на общественном транспорте, и добавить фотографию здания. Тогда клиенту найти ваш магазин будет просто.

Примечание

Определить популярность раздела «Контакты» поможет отчет [Карта кликов](ru/behavior/click-map).
