# Возможность перейти в «Корзину» с любой страницы

Покупатель обычного магазина всегда может посмотреть, какой товар он уже выбрал, — достаточно заглянуть в корзину с покупками. Предоставьте вашим клиентам подобную возможность — в любой момент и с любой страницы сайта заглядывать в «Корзину».

Примечание

Чтобы определить количество посетителей из Рекламной сети Яндекса, которые оставили заказ на сайте, [установите в качестве цели](ru/general/goals) (желаемого результата рекламной кампании) страницу подтверждения заказа.
