# Указание цены рядом с каждым товаром

Покупатель привык видеть рядом с товаром его цену. Отсутствие цены может отпугнуть потенциального клиента. Во-первых, это настораживает: можно подумать, что цена слишком высокая, неконкурентная, поэтому ее не стали указывать. Во-вторых, зачем пользователю делать лишние усилия (звонить, скачивать прайс-лист, искать в каталоге на другой странице), если есть сайты с ценами? Мы рекомендуем сделать информацию о стоимости товара или услуги максимально доступной.

Примечание

Узнать, как ведет себя пользователь после ознакомления с ценой товара, можно с помощью отчета Яндекс Метрики [Вебвизор](ru/webvisor/info).
