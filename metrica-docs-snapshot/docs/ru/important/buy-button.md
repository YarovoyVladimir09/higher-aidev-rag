# Наличие кнопки «Купить» («Заказать») рядом с каждым товаром

В обычном магазине покупатель просто берет товар и идет оформлять покупку. В интернет-магазине он сообщает о решении купить товар с помощью кнопки **Купить**. Если ее непросто найти в интерфейсе, человек может отказаться от покупки. Чтобы этого не произошло, кнопка должна быть хорошо заметна и находиться рядом с описанием товара.

Также желательно сделать [форму заказа](ru/advisable/simple-order) максимально простой.

Примечание

Если вы хотите узнать, как цвет кнопки **Купить** влияет на конверсию по цели «Переход в корзину», воспользуйтесь отчетом Яндекс Метрики [Параметры визитов](ru/reports/visit-params).
