# Турбо-сайты

С помощью счетчика Метрики можно собирать статистику по Турбо-сайтам, созданным в Директе. Ссылка на них используется в рекламных объявлениях. Это может быть полезно, например, если у вас нет сайта.

При формировании Турбо-сайта в Директе создается *автоматический* счетчик. На нем уже настроены цели. Владелец кампании получает [доступ на просмотр](ru/general/access#guest) статистики. К автоматическому счетчику нельзя подключить [Вебвизор](ru/general/counter-webvisor). Чтобы редактировать настройки счетчика и давать доступ к статистике другим пользователям, привяжите к кампании собственный счетчик и настройте цели. [Узнать больше](https://yandex.ru/support/direct/efficiency/turbo-pages-statistics.html)

[Как установить счетчик на Турбо-сайты](ru/code/install-counter-turbo)

С помощью Метрики вы можете анализировать статистику по-разному:

- Смотреть [статистику по Турбо-сайтам](ru/turbo/stat).
- Выделять аудиторию Турбо-сайтов по определенным характеристикам. Например, посмотреть статистику по пользователям смартфонов. Для этого нужно использовать [сегментацию](ru/general/segmentation).
- Прослеживать действия посетителей, которые начались на сайте, а завершились на Турбо-странице или наоборот. Для этого нужно установить один счетчик на основной и Турбо-сайт.
- Отслеживать конверсии действий посетителей. Для этого нужно [настроить цели](ru/turbo/goals).
