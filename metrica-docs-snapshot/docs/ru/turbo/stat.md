# Статистика по Турбо-сайтам

- [Узнать информацию о ходе кампании в Яндекс Директе](ru/turbo/stat#ad)
- [Посмотреть другую статистику](ru/turbo/stat#other)
- [Узнайте больше](ru/turbo/stat#uznajte-bolshe)

С помощью счетчика Метрики можно собирать статистику по [Турбо-сайтам](ru/turbo/about), созданным в Директе.

Отчеты по Турбо-сайтам строятся с учетом *визитов*, во время которых посетители просматривали страницы Турбо-сайта. С помощью статистики вы можете узнать, как посетители просматривают страницы Турбо-сайта, сравнить показатели со статистикой страниц основного сайта.

| Где установлен счетчик | Как просматривать статистику |
| --- | --- |
| Отдельный счетчик на Турбо-сайте | Просматривайте отчеты |
| Общий счетчик для основного и Турбо-сайта | Добавляйте в отчеты сегменты и группировки, чтобы отфильтровать данные по определенной кампании или только по страницам Турбо-сайта |

Сегментация и группировки помогают решать разные задачи, например:

[Посмотреть другую статистику](ru/turbo/stat#other)

## ru/turbo/stat#adУзнать информацию о ходе кампании в Яндекс Директе

Рекомендуем использовать [отчеты по Директу](ru/general/direct-reports).

Чтобы выделить из всех данных только статистику по определенному объявлению или группе объявлений, можно создать сегмент:

**По URL, на который ведет объявление**

1. В группе условий **Визиты в которых** нажмите значок .
2. Выберите условие **Поведение** → **Просмотр URL** и укажите URL, который используете в объявлении в Директе.
3. Нажмите кнопку **Применить**.

**По номеру кампании или объявления**

1. В группе условий **Визиты в которых** нажмите значок .
2. Выберите условие **Кампания** или **Объявление Директа** и выберите кампанию или объявление.
3. Нажмите кнопку **Применить**.

## ru/turbo/stat#otherПосмотреть другую статистику

| Информация | Отчет |
| --- | --- |
| Общая статистика по Турбо-сайтам | Отчет «Турбо-страницы» и другие стандартные отчеты |
| Если вы монетизируете сайт с помощью Рекламной сети Яндекса или Adfox | Отчеты группы «Рекламная сеть Яндекса» или Отчеты группы «Adfox» |
| Если анализируете статистику контентных проектов | Отчеты по контенту |

Чтобы оставить в отчетах статистику только по Турбо-сайту, используйте:

1. В группе условий **Визиты, в которых** нажмите значок .
2. Выберите условие **Поведение** → **Турбо-страница** → **Турбо**.
3. Нажмите кнопку **Применить**.

1. Нажмите кнопку **Группировки**.
2. Выберите значение **Поведение** → **Турбо-страница**.
3. Нажмите кнопку **Применить**.
