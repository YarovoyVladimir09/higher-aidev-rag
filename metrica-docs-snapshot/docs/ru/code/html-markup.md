# Настройка сбора данных

Яндекс Метрика позволяет влиять на некоторые виды собираемых данных с помощью HTML-разметки. JavaScript-код счетчика Яндекс Метрики реагирует на наличие у HTML-элементов классов (атрибут [class](http://www.w3schools.com/tags/att_global_class.asp)). Правила, определенные для класса, срабатывают для самого элемента и всех дочерних элементов, если не указано другое.

| Класс | Действие |
| --- | --- |
| ym-disable-clickmap | Отключение отслеживания кликов. Информация о кликах по таким элементам не собирается и не отображается в Карте кликов Одиночный элемент < a href = "/forum/" class = "ym-disable-clickmap" > Форум </ a > Элемент-контейнер < ul class = "ym-disable-clickmap" > < li > < a href = "/events/" > События </ a > </ li > < li > < a href = "/specials/" > Спецпредложения </ a > </ li > < li > < a href = "/contacts/" > Контактная информация </ a > </ li > </ ul > Страница целиком < body class = "ym-disable-clickmap" > ... </ body > |
| ym-disable-tracklink | Установка признака того, что ссылка не является внешней. Переходы по таким ссылкам не отображаются в отчете Внешние переходы < a href = "/top-secret/" class = "ym-disable-tracklink" > Секретно </ a > |
| ym-disable-submit | Отключение отслеживания событий отправки данных формы. Информация об отправке данных формы не будет представлена в инструментах Вебвизор и Аналитика форм |
| ym-disable-keys | Отключение записи данных, вводимых в поля. Используйте этот класс для элементов textarea и input . Информация о заполнении полей не будет представлена в инструментах Вебвизор и Аналитика форм . |
| ym-hide-content | Отключение записи элементов интерфейса. Доступен только при использовании Вебвизора . |
| ym-show-content | Включение записи произвольных элементов сайта. Доступен только при использовании Вебвизора |
| ym-record-keys | Включение записи содержимого полей. Доступен только при использовании Вебвизора. Используйте этот класс для элементов textarea и input |
| ym-external-link | Установка признака того, что ссылка является внешней < a href = "/forum/" class = "ym-external-link" > Форум </ a > |
