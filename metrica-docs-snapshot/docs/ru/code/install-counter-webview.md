# Установка счетчика на WebView (Android)

Счетчик Яндекс Метрики предполагает сбор сторонних файлов cookies (ThirdPartyCookies). Чтобы статистика собиралась корректно, когда сайт открыт через WebView на Android-устройствах, убедитесь, что в вашей версии WebView эта возможность не заблокирована.

[Документация для разработчиков](https://developer.android.com/reference/android/webkit/CookieManager#setAcceptThirdPartyCookies(android.webkit.WebView,%20boolean))
