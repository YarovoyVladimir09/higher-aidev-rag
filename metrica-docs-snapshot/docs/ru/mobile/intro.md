# О мобильной версии Яндекс Метрики

В мобильной версии Метрики доступны:

- Список счетчиков, сортировка и поиск.
- Сводная статистика за текущий день.
- Просмотр стандартной сводки по статистике.
- Записи Вебвизора. Записи Вебвизора можно просматривать в адаптированном для мобильных устройств виде.
- Стандартные и сохраненные отчеты.
- Стандартная настройка отчетов: выбор периода и детализации, добавление цели, фильтрация по выбранной метрике.
- Использование в отчетах готовых (предложенных сервисом) и сохраненных сегментов.
- Выгрузка отчетов в формате PDF.

Некоторые отчеты можно посмотреть только в версии для компьютеров — они отмечены значком . Чтобы воспользоваться всеми инструментами Метрики, используйте версию для компьютеров. Ссылка на нее размещена внизу страницы мобильной версии.
