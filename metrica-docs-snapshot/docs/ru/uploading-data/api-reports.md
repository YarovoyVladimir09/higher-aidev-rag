# API отчетов

API отчетов позволяет получать агрегированную информацию о статистике посещений сайта и другие данные, которые соответствуют данным в отчетах, не используя интерфейс Яндекс Метрики.

При формировании запроса к API используются:

- группировки (dimensions) — атрибут визита или хита, по которому можно сгруппировать данные;
- метрики (metrics) — числовая величина, которая рассчитывается на основе атрибута хита или визита.

API поддерживает два типа группировок и метрик: визиты и хиты.

Метрики и группировки, указанные в запросе к API, позволяют формировать необходимую структуру отчета, например, по глубине просмотра с группировкой данных по типу и версии операционной системы.

API возвращает ответы в кодировке UTF-8. Ответы имеют формат JSON или CSV.
