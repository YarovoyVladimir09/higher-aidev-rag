# Logs API

С помощью Logs API можно выгрузить неагрегированные данные, собираемые Яндекс Метрикой. Этот API предназначен для пользователей сервиса, которые хотят самостоятельно обрабатывать статистические данные и использовать их для решения уникальных аналитических задач, например:

- объединение данных из разных источников и построение сквозной аналитики;
- получение отчетов, которых нет в интерфейсе Яндекс Метрики;
- использование произвольных моделей атрибуции и т.д.

Данные выгружаются в виде двух таблиц: [визиты](https://yandex.ru/dev/metrika/ru/logs/fields/visits) и [события](https://yandex.ru/dev/metrika/ru/logs/fields/hits).

Хранить полученные данные и управлять ими можно с помощью базы данных [ClickHouse](https://yandex.ru/dev/metrika/ru/logs/clickhouse-integration).

Данные по событиям и визитам доступны за предыдущий день.

[Подробнее о Logs API](https://yandex.ru/dev/metrika/ru/logs/)
