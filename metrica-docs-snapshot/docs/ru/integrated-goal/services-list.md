# Цели для интегрированных с Метрикой сервисов

Яндекс Метрика позволяет автоматически отслеживать некоторые cобытия, которые присылают сервисы, интегрированные с Метрикой. Это сервисы, которые могут быть включены в код вашего сайта. Например, виджет для общения с клиентами, CMS (система управления контентом) и т. д.

Автоцели создаются в Метрике для сервисов, перечисленных в таблице.

| Сервисы | События | Инструкции |
| --- | --- | --- |
| Яндекс Билеты | Открытие виджета, выбор мест или билетов, ввод персональных данных, подтверждение заказа, оплата заказа, покупка и т. д. | Цели Яндекс Билетов |
| Яндекс Пэй | Клиент перешел в оплату через Яндекс Пэй. | Цель Яндекс Пэй |
| Яндекс Сплит | Клиент перешел в оплату через Яндекс Сплит. | Цель Яндекс Сплит |
| Jivo | Клиент написал в чат, ответил на приглашение оператора, оставил офлайн сообщение и т. д. | Цели Jivo |
| Marquiz | Запуск квиза, показ результата, страница «Спасибо», успешная оплата и т. д. | Цели Marquiz |
| Nethouse | Покупки, заказы, отправка форм и т. д. | Цели Nethouse |

Вы можете управлять этими целями так же, как другими [автоматическими целями](ru/general/auto-goals).
