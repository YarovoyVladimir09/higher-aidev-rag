# Рекомендуемые цели

[Что такое цели. Типы целей](ru/general/goals)

Рекомендуемые цели помогают отследить и проанализировать значимые действия посетителей на сайте: оформление заказа, успешную оплату, добавление товара в корзину, обращение к консультанту в чате, подтверждение заказа и т. д.

Чтобы просматривать статистику по целям, настройте их на сайте с помощью метода [reachGoal](ru/objects/reachgoal). При создании цели укажите ее идентификатор из таблицы ниже.

## ru/general/recommend-goals#qandaВопросы и ответы

**Чем отличаются рекомендуемые цели от других автоматических целей**

По данным Метрики рекомендуемые цели отслеживают более точные события. Например, цель «Отправка формы» может отслеживать заполнение всех форм на сайте, а цель «Отправка формы заявки» отслеживает отправку определенной формы.

Вы можете наблюдать за статистикой достижения тех и других целей и проанализировать эффективность. При необходимости можно [удалить](ru/general/auto-goals#activate) менее эффективную, но после этого восстановить ее будет невозможно.
