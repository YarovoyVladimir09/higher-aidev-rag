# Мультицель

- [Как создать мультицель](ru/general/multi#create-goal)
- [Передача дохода](ru/general/multi#price)
- [Требования и ограничения](ru/general/multi#general)

**Мультицель** позволяет объединять в одну цель несколько различных типов условий, включая как онлайн-, так и офлайн-события. Это помогает собрать единую статистику по событиям, которые решают одинаковую бизнес-задачу, но имеют разные технические параметры.

Цель считается достигнутой, если выполнено хотя бы одно из условий, заданных в настройках мультицели. Если в рамках одного визита произошло несколько событий, подходящих под условия мультицели, каждое такое событие засчитывается как достижение цели.

## ru/general/multi#create-goalКак создать мультицель

1. В Метрике перейдите на страницу **Цели** в левом меню.
2. Нажмите кнопку **Добавить цель**.
3. Выберите тип цели **Мультицель**.
4. В поле **Название** укажите имя создаваемой цели.
5. Добавьте необходимые условия. В качестве условий вы можете использовать доступные типы целей: [Целевое событие](ru/general/goal-js-event) [Посещение страниц](ru/general/goal-page-visit) [Поиск по сайту](ru/simple-goal/search) [Отправка формы](ru/simple-goal/form) [Клик по кнопке](ru/simple-goal/click) [Клик по номеру телефона](ru/simple-goal/tel) [Клик по email](ru/simple-goal/email) [Звонки](ru/general/call-goal) [Чаты](ru/general/chat-goal) [Переход в мессенджер](ru/simple-goal/messengers) [Переход в социальные сети](ru/simple-goal/social-networks) [Возвращение из платежной системы](ru/simple-goal/payment-system) [Скачивание файла](ru/simple-goal/download) [Параметры](ru/general/parameters-goal) Всего может быть использовано не более 10 условий.
6. Нажмите кнопку **Добавить цель**. Созданная цель отобразится в списке целей. Метрика начнет сбор статистики по ней в течение нескольких минут.

## ru/general/multi#priceПередача дохода

В рамках мультицели доход может быть передан двумя способами:

- Через отправку дохода непосредственно через условие. Подробнее читайте в разделе [Доход по цели](ru/general/price-goal).
- Как статический доход, указанный в дополнительных настройках цели.

## ru/general/multi#generalТребования и ограничения

- source: ru/_includes/general/goal-page-visit/id-general/8.md Условия в шагах объединяются логическим оператором `ИЛИ`. Шаг цели будет достигнут, если выполнено хотя бы одно из заданных условий в нем. endsource: ru/_includes/general/goal-page-visit/id-general/8.md
- source: ru/_includes/general/goal-page-visit/id-general/1.md Для каждого счетчика можно задать до 200 целей. endsource: ru/_includes/general/goal-page-visit/id-general/1.md
- source: ru/_includes/general/goal-page-visit/id-general/2.md Сервис фиксирует достижение посетителем одной и той же цели на одном счетчике не чаще, чем раз в секунду. endsource: ru/_includes/general/goal-page-visit/id-general/2.md
- source: ru/_includes/general/goal-page-visit/id-general/3.md Во время одного визита посетителя сервис может фиксировать до 1000 достижений офлайн-целей и 400 достижений онлайн-целей, созданных для счетчика. endsource: ru/_includes/general/goal-page-visit/id-general/3.md
- source: ru/_includes/general/goal-page-visit/id-general/4.md При редактировании счетчика или цели накопленная ранее информация не изменяется. endsource: ru/_includes/general/goal-page-visit/id-general/4.md
- source: ru/_includes/general/goal-page-visit/id-general/5.md Если вы удалите цель, собранная по ней информация будет недоступна в отчетах. endsource: ru/_includes/general/goal-page-visit/id-general/5.md

Цели в Яндекс Метрике работают одинаково для всех источников. Возможно, ни один посетитель из интересующего вас источника еще не достиг цель.

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.

Это может происходить по следующим причинам:

- В Яндекс Метрике условие цели не охватывает все возможные варианты. Например, цель настроена на посещение страницы с подтверждением заказа, а на сайте еще есть возможность оформить быстрый заказ.
- У посетителя сайта в браузере установлен плагин, блокирующий работу счетчика.
- У посетителя подключен антивирус с жесткими настройками приватности.
- У посетителя низкоскоростное интернет-подключение, из-за которого на целевой странице не загрузился счетчик.
