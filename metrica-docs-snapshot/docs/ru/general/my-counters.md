# Мои счетчики

- [Как восстановить удаленный счетчик](ru/general/my-counters#delete-counter)
- [Вопросы и ответы](ru/general/my-counters#qanda)[Узнайте больше](ru/general/my-counters#uznajte-bolshe)

На странице [Мои счетчики](https://metrika.yandex.ru/list?) отображаются:

- счетчики, которые вы создали;
- счетчики, к которым у вас есть гостевой доступ;
- счетчики, установленные на сайтах, подключенных к Рекламной сети Яндекса;
- счетчики, которые были удалены, — вы можете [восстановить их](ru/general/my-counters#delete-counter).

Для каждого счетчика доступна следующая информация:

- Статистика за текущий день и сводные диаграммы, которые помогают увидеть динамику посещаемости сайта за последние 8 дней. Информация собирается по часовому поясу, который указан в настройках счетчика. По умолчанию отображаются данные без учета [роботных данных](ru/general/robots#metrika-robot).
- Цели счетчика. Они отображаются в том порядке, в котором отсортированы в настройках счетчика (вкладка **Цели**). В списке видны первые 5 целей. При нажатии на цель (или кнопку **Все цели** в выпадающем списке) открывается отчет **Конверсии**.

Список счетчиков можно сортировать по названию (домену сайта), количеству визитов, просмотров и посетителей.

На странице вы можете использовать следующие инструменты:

- — чтобы перейти к редактированию счетчика;
- — чтобы управлять [метками](ru/general/tag-counter);
- — чтобы [проверить счетчик](ru/general/check-counter), добавить счетчик в избранное (или убрать из избранного), удалить счетчик, перейти в Яндекс Директ и Яндекс Вебмастер.

## ru/general/my-counters#delete-counterКак восстановить удаленный счетчик

Чтобы восстановить счетчик, перейдите на вкладку **Удаленные**. Счетчик можно восстановить в течение трех месяцев с момента удаления. Вместе со счетчиком восстановится собранная им статистика сайта. Через три месяца счетчик пропадет из списка удаленных — его нельзя будет восстановить.

## ru/general/my-counters#qandaВопросы и ответы

**В списке отображается чужой счетчик**

Если в списке счетчиков Метрики вы видите незнакомый счетчик, это может быть:

- Счетчик другого пользователя, к которому вам выдали доступ. На странице **Настройки** (вкладка **Доступы**) посмотрите, кто является владельцем счетчика и у кого есть права на редактирование счетчика. Возможно, кто-то знакомый выдал вам права на этот счетчик.
- [Автоматический счетчик Метрики](ru/general/auto-tag), установленный на сервисах Яндекса.
