# Профиль сайта

**Профиль сайта** — это раздел, который помогает:

- подобрать оптимальные настройки и инструменты Метрики под специфику задач вашего бизнеса;
- найти точные инструкции под ваше техническое окружение (CMS и CRM);
- повысить релевантность рекомендаций в интерфейсе.

Чтобы открыть раздел, перейдите в **Настройки** → **Профиль сайта**.

### ru/general/site-profile#kakie-dannye-mozhno-ukazatКакие данные можно указать

Данные используются для персонализации интерфейса и рекомендаций по настройке аналитических инструментов:

- **Тип сайта** — выберите один из типов, к которому относится ваш сайт: **Интернет-магазин** Сайт с каталогом, корзиной и оплатой **Промо-сайт** Сайт с контактами и формой заявки **Облачное приложение** Сайт, предоставляющий онлайн-сервис (SaaS): онлайн-банк, почтовый клиент, CRM, хостинг и другие **Информационный сайт** Сайт с текстовым контентом **Другое** Выберите этот вариант, если сайт сложно отнести к одному из типов
- **Индустрия** — укажите одну или несколько сфер деятельности вашего проекта.
- **CMS** — выберите используемую систему управления контентом (CMS), если применимо.
- **CRM** — укажите CRM-систему, с которой работает сайт, если она есть.
- **Ваша роль в проекте** — отметьте вашу основную или несколько ролей: владелец бизнеса, маркетолог, разработчик и другие. Примечание Можно выбрать несколько ролей, если вы совмещаете несколько функций. При этом для каждого счетчика сохраняется свой набор.
