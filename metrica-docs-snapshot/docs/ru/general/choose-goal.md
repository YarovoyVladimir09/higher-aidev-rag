# Как определить, какую цель создать

- [Информационный сайт](ru/general/choose-goal#info)
- [Сайт, предлагающий услуги или товары](ru/general/choose-goal#e-com)
- [Сайт с конкурсом, акцией и пр.](ru/general/choose-goal#promo)
- [Узнайте больше](ru/general/choose-goal#uznajte-bolshe)

[Цели](ru/general/goals) позволяют отслеживать действия посетителей на сайте. Например, вы можете узнать, сколько человек зарегистрировалось на сайте за месяц, но не отправило заявку. Как правило, действия различаются для разных типов сайтов.

## ru/general/choose-goal#infoИнформационный сайт

Узнать количество зарегистрировавшихся на сайте посетителей можно, отслеживая выполнение некоторых условий.

| Условие | Рекомендуемый тип цели |
| --- | --- |
| Отправка формы с помощью кнопки, например, «Отправить заявку». | Отправка формы |
| Последовательность действий: нажатие на ссылку, по которой открывается форма; нажатие кнопки для отправки формы. | Составная цель |

Отследить такое действие поможет цель [Посещение страниц](ru/general/goal-page-visit#goal-page-visit).

Используйте цель [Посещение страниц](ru/general/goal-page-visit#goal-page-visit).

## ru/general/choose-goal#e-comСайт, предлагающий услуги или товары

Совет

Если у вас интернет-магазин с большим количеством товаров, [настройте передачу Ecommerce-данных](ru/ecommerce/about#about) и [используйте специальную группу отчетов](ru/reports/ecommerce#ecommerce).

Чтобы отследить отправку заявки, можно фиксировать следующие действия:

| Действие | Рекомендуемый тип цели |
| --- | --- |
| Нажатие кнопки, например, Отправить заявку , после заполнения специальной формы. | Отправка формы |
| Нажатие на email (с последующей отправкой письма-заявки). | Клик по email |
| Посещение страницы с формой для заявки или другим средством для ее отправки. | Этот вариант менее результативный, так как не фиксирует сам факт заявки. Для отслеживания используйте цель Посещение страниц . |

Узнать количество зарегистрировавшихся на сайте посетителей можно, отслеживая выполнение некоторых условий.

| Условие | Рекомендуемый тип цели |
| --- | --- |
| Отправка формы с помощью кнопки, например, “Отправить заявку”. | Отправка формы |
| Последовательность действий: нажатие на ссылку, по которой открывается форма; нажатие кнопки для отправки формы. | Составная цель |

Отследить такое действие можно несколькими способами. Выбор способа зависит от того, в каком виде информация размещена на сайте.

| Формат | Рекомендуемый тип цели |
| --- | --- |
| Список на отдельной странице | Посещение страниц Пример отслеживания скачивания файла |
| Список в файле |  |

Используйте цель [Посещение страниц](ru/general/goal-page-visit#goal-page-visit).
