# Автоматический счетчик Метрики

- [Сбор статистики](ru/general/auto-tag#stat)
- [Вопросы и ответы](ru/general/auto-tag#qanda)

Если вы заметили [в списке счетчиков Метрики](ru/general/my-counters) незнакомый счетчик, который вы не создавали, это может быть автоматический счетчик.

Автоматические счетчики создаются и настраиваются сервисами Яндекса для сбора данных на них, если:

- Вы владелец кампании в [Яндекс Директе](https://yandex.ru/support/direct/) или у вас есть представительский доступ к кампании. Счетчик используется на сформированных в Директе [Турбо-сайтах](ru/turbo/about) и [лендингах](https://yandex.ru/support/direct/ru/efficiency/landing/about).
- Вы владелец организации в [Яндекс Бизнесе](https://yandex.ru/support/business-priority/ru/) или у вас есть доступ к организации. Счетчик используется для отслеживания [целевых событий на Яндексе](ru/general/events).
- Вы партнер [Яндекс Маркета](https://yandex.ru/support/marketplace/ru/) и у вас есть страница магазина. Счетчик используется для отслеживания [статистики по магазину-партнеру Маркета](ru/general/market).
- Вы партнер [РСЯ](https://yandex.ru/support/partner2). Счетчик используется для отслеживания статистики показов рекламных блоков.

Как правило, в списке автоматический счетчик называется стандартно, например:

- Счетчик для страниц Турбо-сайта Директа — `Turbo Pages <произвольный набор символов>`.
- Счетчик лендинга Директа — `Счетчик лендинга № <номер>`.
- Счетчик, связанный с Бизнесом, — `<Название вашей организации> - <Адрес организации, если указан в Бизнесе>`.
- Счетчик для бизнеса в Маркете — `<Название бизнеса> на Маркете`.
- Счетчик РСЯ — `<Название страницы РСЯ> - <Номер страницы РСЯ>`.

На счетчике лендинга Директа можно создавать собственные цели и сегменты без написания кода. Остальные счетчики доступны только для просмотра, редактировать их нельзя. Правила выдачи доступа другим пользователям различаются для каждого сервиса.

## ru/general/auto-tag#statСбор статистики

Автоматический счетчик устанавливается на сервисах Яндекса и собирает только определенный набор данных.

| Тип собираемых данных | Где посмотреть статистику | Примечание |
| --- | --- | --- |
| Данные, связанные с размещенными в Бизнесе кампаниями: статистика по звонкам из Директа; информация о целевых событиях на Яндексе | Отчеты группы «Звонки» — статистика по звонкам из Директа. Отчет «Целевые события на Яндексе» и Отчет «Конверсии» — информация о целевых событиях на Яндексе | Автоматический счетчик не регистрирует поведение посетителей. Поэтому не следует смотреть на нем связанные с этим метрики: глубина просмотра, показатель отказов, время на сайте и пр. |
| Статистика по Турбо-сайтам, созданным в Директе | Отчеты | — |
| Статистика по лендингам, созданным в Директе | Отчеты | По умолчанию на счетчике настроены цели с типом JavaScript-событие . Но, в отличие от других автоматических счетчиков, на счетчике лендинга можно создавать собственные цели и сегменты без написания кода. Вебвизор на счетчике лендинга не работает и его нельзя включить. |
| Статистика по магазинам, размещенным на Маркете | Отчеты электронной коммерции | На счетчике отсутствует подключение Вебвизора, карт и аналитики форм. |
| Статистика по показам рекламных блоков | Отчеты | На счетчике отсутствует подключение Вебвизора, карт и аналитики форм. |

## ru/general/auto-tag#qandaВопросы и ответы

Если вы удалите счетчик из списка, то потеряете доступ к собранной им статистике. Чтобы снова получить доступ, нужно будет обратиться в службу поддержки. Поэтому рекомендуем не удалять счетчик.

Удалить счетчик РСЯ и автоматические счетчики можно, если вы остановите в Рекламной сети показы для этого счетчика. В [Партнерском интерфейсе](https://partner2.yandex.ru) выберите нужный сайт и нажмите кнопку  → **Остановить показы**. Через сутки после остановки счетчик станет обычным счетчиком Метрики и его можно будет удалить.

Не рекомендуем ставить этот счетчик на сайт, так как у вас не будет доступа на его редактирование. Поэтому статистика будет собираться некорректно.
