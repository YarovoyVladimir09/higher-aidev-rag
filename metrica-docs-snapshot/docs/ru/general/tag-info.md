# Переход на новую версию кода счетчика Метрики

В Метрике доступно несколько версий кода счетчика — они различаются сборками библиотек, с которыми работают: `tag.js` и `watch.js`. Код счетчика с `tag.js` обладает рядом преимуществ:

|  | tag.js | watch.js |
| --- | --- | --- |
| Передача целей , параметров визитов , посетителей и пр. сразу после начала загрузки сайта, когда код счетчика еще мог не загрузиться. Например, если код размещен в конце страницы сайта |  | — |
| Вебвизор |  | — |
| Статистика по контенту |  | — |
| Стабильная работа и регулярное обновление библиотеки |  | — |
| Проверка сбора данных на счетчике с помощью панели отладки |  | — |

Чтобы перейти на версию счетчика с `tag.js`, обновите код счетчика на вашем сайте:

1. Перейдите в Метрику на страницу **Настройка** (вкладка **Счетчик**).
2. В блоке **Код счетчика** нажмите **Скопировать код**.
3. Обновите код на всех страницах вашего сайта.

## ru/general/tag-info#det-codeКак определить, какая версия кода счетчика установлена на сайте

Посмотрите, как выглядит код счетчика на страницах вашего сайта. Ниже приведены основные отличия кода счетчика с `tag.js` от кода с `watch.js`.

|  | tag.js | watch.js |
| --- | --- | --- |
| Содержимое элемента script | Начинается с function(m,e,t,r,i,k,a) | Начинается с function (d, w, c) |
| Метод | ym | yaCounter |
| Библиотека | tag.js | watch.js |
