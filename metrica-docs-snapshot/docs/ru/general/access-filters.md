# Фильтры доступа к данным счетчика

Фильтр доступа позволяет выбрать, какие данные о посещаемости сайта будут доступны пользователю Метрики. Например, можно отфильтровать трафик с определенной рекламной кампании или геолокации и предоставить пользователю доступ только к этому трафику.

Если пользователь имеет доступ к счетчику с фильтром доступа, то во всех отчетах ему будет доступна только та информация, которая удовлетворяет условиям фильтра. Остальные данные показываться не будут.

Примечание

В Метрике можно создать только один фильтр доступа к данным счетчика. Для пакета Метрика Про доступно большее количество фильтров.

## ru/general/access-filters#limitationsОграничения при работе с фильтром доступа

- Фильтр доступа применяется только в отчетах, где есть информация о визитах.
- Пользователю с фильтром доступа не доступны отчеты, в которых нет информации о визитах (например, «Посетители и клиенты», «Параметры посетителей», «Популярное», некоторые отчеты электронной коммерции, а так же отчеты Вебвизора).
- Фильтр доступа применяется в интерфейсе Метрики и в API.
- Пользователю с фильтром доступа не доступна выгрузка данных через Logs API.
- Пользователь может иметь доступ к счетчику только с одним примененным фильтром доступа, либо к счетчику без фильтров.
- Применить фильтр доступа можно только для ролей **Аналитика** и **Просмотр**.
- Отчет с еженедельными данными не отправляется пользователю с фильтром доступа.
- Отчеты по расписанию пользователю с фильтром доступа отправляются с учетом условий его фильтра.

## ru/general/access-filters#filter-managementУправление фильтром доступа

### ru/general/access-filters#create-filterСоздать фильтр доступа

1. Откройте любой отчет, где есть информация о визитах, например, [Источники, сводка](ru/sources/sources-summary).
2. Выберите период, за который будут отображаться данные в отчете.
3. Установите фильтры в отчете в группах условий **Визитов, в которых** и **для людей, у которых**.
4. Выберите **Сегмент** → **Сохранить как фильтр доступа**.
5. В открывшемся окне введите название фильтра и нажмите **Сохранить**.

После создания фильтр появится в разделе **Настройки** → **Доступ** в списке **Фильтры доступа**.

Примечание

Можно создать два одинаковых фильтра доступа с разными названиями.

### ru/general/access-filters#remove-filterУдалить фильтр доступа

1. Откройте **Настройки** → **Доступ**.
2. В блоке **Фильтры доступа** выберите нужный фильтр и нажмите .
3. Подтвердите удаление фильтра.

Примечание

После удаления фильтра все пользователи, для которых настроен фильтр, потеряют доступ к счетчику.

### ru/general/access-filters#view-conditionsПросмотреть условия фильтра доступа

Пользователи с любой ролью в любом отчете видят список созданных фильтров и могут просматривать, как они применяются к отчетам.

Примечание

Если пользователь просматривает фильтры в отчетах, где нет информации о визитах, то данные, удовлетворяющие условиям фильтра, показываться не будут.

Чтобы просмотреть условия фильтра доступа, нажмите **Настройки** → **Доступ**. В выпадающем списке **Фильтры доступа** выберите для просмотра нужный фильтр.

Фильтры накладываются друг на друга. Если для пользователя настроен фильтр доступа, он увидит отчет со своим и просматриваемым фильтром.

При удалении условий своего фильтра пользователю будут показываться данные с наложенным фильтром доступа.

## ru/general/access-filters#managing-rolesУправление доступами

### ru/general/access-filters#issue-rightsВыдать доступ к счетчику с фильтром доступа

1. Откройте **Настройки** → **Доступ**.
2. В блоке **Индивидуальный доступ** нажмите **Добавить пользователя**.
3. В поле **Права доступа** выберите **Только просмотр** или **Аналитика**.
4. В поле **Фильтры доступа** выберите нужный фильтр.

### ru/general/access-filters#revoke-rightsОтозвать доступ к счетчику с фильтром доступа

1. Откройте **Настройки** → **Доступ**.
2. В блоке **Индивидуальный доступ** выберите логин и нажмите .

Примечание

Фильтр не удаляется, даже если из него удалены все пользователи, которым был выдан доступ.

### ru/general/access-filters#change-rightsИзменить права доступа

Внимание

При добавлении фильтра для пользователя с уже настроенным фильтром, фильтры накладываются друг на друга.

1. Откройте **Настройки** → **Доступ**.
2. В блоке **Индивидуальный доступ** выберите логин и нажмите .
3. В открывшемся окне выберите другой фильтр доступа или доступ без фильтра.
