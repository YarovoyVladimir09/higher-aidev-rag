*Роботы* — это программы, которые обходят сайт с определенной целью. Например, для индексирования сайта или проверки его работы. Какие-то роботы представляются сами, другие — наоборот, стараются маскироваться под реального пользователя, чтобы аналитические системы их не вычислили. Метрика определяет роботов по поведенческим факторам и другим техническим сигналам.

Также к визитам роботов Метрика может относить посещения сайтов, которые не указаны в [настройках счетчика](ru/general/counter-general) (поля **Адрес** и **Дополнительный адрес**).

Примечание

В Метрике и Директе разные системы определения роботов.

Фильтрация роботного трафика в отчетах Метрики помогает получать точные значения метрик. Например, показателя отказов, времени на сайте и глубины просмотра.

## ru/general/robots#which-robotsКак понять, какие роботы посещают сайт

Примечание

Если в настройках счетчика включен фильтр **фильтровать роботов по поведению**, дополнительная настройка фильтрации роботов недоступна. При этом можно увидеть роботную активность в отчете [Роботы](ru/reports/robots).

Вы можете использовать фильтрацию роботов по поведению, если вы пользуетесь [Logs API Метрики](https://yandex.ru/dev/metrika/doc/api2/logs/intro.html) и вам нужны неагрегированные данные без роботов. В других случаях меняйте режим отображения данных в отчетах, как описано ниже.

Роботы, которые представились (их User-agent известен), сразу исключаются из статистических данных. Их можно посмотреть в отчете [Роботы](ru/reports/robots). Он поможет определить, например, приходят ли на сайт поисковые роботы, чтобы проиндексировать страницы. Посмотрите, [как представляются роботы Яндекса](https://yandex.ru/support/webmaster/robot-workings/check-yandex-robots.html#check-yandex-robots).

По умолчанию статистика отображается с учетом визитов роботов, которые определены по поведению. Чтобы исключить посещения роботов из отчета, [настройте сегментацию](ru/general/robots#from-report).

[Как отфильтровать визиты роботов с помощью API Метрики](https://yandex.ru/dev/metrika/doc/api2/api_v1/examples.html#segment__robots)

## ru/general/robots#comparКак сравнить статистику с роботными данными и без них

Чтобы сравнить статистику, в отчете в настройке **Данные: без роботов** выберите **Сравнить с данными с роботами**. Так вы сможете увидеть, как роботы влияют на ваш сайт. Например, роботы могут стать причиной снижения глубины просмотров и увеличения отказов.

## ru/general/robots#delete-robotsКак исключить визиты роботов

### ru/general/robots#from-reportИз отчета

Исключить визиты роботов из отчета можно двумя способами:

- [Создайте](ru/reports/overview) новый отчет с [сегментом](ru/general/segmentation-report) без роботов.
- [Создайте](ru/general/segmentation-report#segmentation-report__segment) сегмент без роботов.

### ru/general/robots#from-widgetИз виджета

Чтобы исключить визиты роботов из виджета, используйте один из вариантов:

- Создайте новый отчет с [сегментом](ru/general/segmentation-report) без роботов и добавьте его на дашборд.
- [Создайте](ru/general/segmentation-report#segmentation-report__operations) сегмент без роботов и примените его при редактировании виджета.
