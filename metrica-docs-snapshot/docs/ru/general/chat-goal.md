Если вы передаете в Метрику данные о чатах, вы можете использовать специальные цели — чтобы более гибко настраивать кампании в Директе и отслеживание статистики в Метрике.

При первой загрузке данных о чат-конверсии автоматически создается специальная цель с типом **Чат**. Эта автоцель появится в интерфейсе Метрики на странице управления целями. Цель **Чаты** учитывает любые чаты в мессенджерах: WhatsApp, Telegram или Viber. Название и описание цели могут быть произвольными, если данные передаются через [API Метрики](https://yandex.ru/dev/metrika/ru/management/conversion).

Заводить отдельную цель вручную не нужно — Метрика распознает загруженные события чатов и начнет считать их достижения.

Цель **Чат** можно добавлять во все отчеты Метрики. Для этой цели будут доступны целевые метрики (конверсии, достигнутые цели и т.д.) Также цель и полученные конверсии можно использовать при оптимизации рекламы, редактировать на срабатывание только для определенных чатов и добавлять новые цели этого типа.

Если для отслеживания чатов вам нужны другие данные, в дополнение к готовой цели вы можете [создать новую цель вручную](ru/general/chat-goal#create). Отредактировать названия целей или удалить их из списка в Метрике можно в любой момент.

Чтобы посмотреть статистику по целям, используйте [Отчет «Конверсии»](ru/reports/conversion) и [добавляйте цель](ru/reports/report-general#choose-goal) в другие отчеты Метрики. Данные начнут отображаться в отчетах, когда информация поступит в Метрику — в течение суток.

## ru/general/chat-goal#createСоздание цели вручную

Чтобы отслеживать чаты с критериями, отличными от предзаданных Метрикой, вы можете создавать подобные цели самостоятельно.

Примечание

Цель **Чат** нельзя создать вручную по умолчанию. Она появится в списке доступных целей только после передачи данных о чатах в Метрику.

Чтобы создать цель:

1. В Метрике перейдите на страницу **Цели** в левом меню.
2. Нажмите кнопку **Добавить цель**.
3. Выберите тип цели **Чат**.
4. В поле **Название** укажите имя создаваемой цели.
5. Укажите [условия для достижения цели](ru/general/chat-goal#chat-type).
6. Нажмите кнопку **Добавить цель**. Созданная цель отобразится в списке целей. Метрика начнет сбор статистики по ней в течение нескольких минут.

## ru/general/chat-goal#chat-typeУсловия для достижения цели

Задайте условия, которые должны одновременно выполняться для достижения цели:

- Мессенджер — **WhatsApp**, **Telegram**, **Viber** или **Все**.
- Отвечен ли чат — **Не важно**, **Отвечен** или **Пропущен**.
- Метка: **совпадает**. Укажите метку полностью, например, `test-chat`. **содержит**. Укажите часть метки, например, `chat`. Используйте этот способ, если схожих меток несколько и нужно отслеживать все подобные чаты. **начинается с**. Укажите начало значения метки, например, `test-`. **регулярное выражение**. Используйте для отслеживания меток, соответствующих [произвольным шаблонам](ru/general/regexp).
- Доход — в указанной валюте.

Цели в Яндекс Метрике работают одинаково для всех источников. Возможно, ни один посетитель из интересующего вас источника еще не достиг цель.

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.

Это может происходить по следующим причинам:

- В Яндекс Метрике условие цели не охватывает все возможные варианты. Например, цель настроена на посещение страницы с подтверждением заказа, а на сайте еще есть возможность оформить быстрый заказ.
- У посетителя сайта в браузере установлен плагин, блокирующий работу счетчика.
- У посетителя подключен антивирус с жесткими настройками приватности.
- У посетителя низкоскоростное интернет-подключение, из-за которого на целевой странице не загрузился счетчик.

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.
