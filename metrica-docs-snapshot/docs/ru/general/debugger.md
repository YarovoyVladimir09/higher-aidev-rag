# Отладчик работы счетчика Метрики

- [Сохранение логов действий во время работы с отладчиком](ru/general/debugger#logs)
- [Почему не работает отладчик](ru/general/debugger#debugger)

Отладчик помогает проверить, [какие данные собирает счетчик Метрики](ru/general/check-counter), а так же правильно ли собираются:

- [цели](ru/general/check-goal);
- [события электронной коммерции](ru/ecommerce/check);
- [данные статистики по контенту](ru/publishers/check-data).

Чтобы использовать отладчик, в адресной строке браузера добавьте к адресу страницы параметр `_ym_debug=2` и загрузите страницу:

```
http://example.com/?_ym_debug=2
```

[Какие данные отображаются при использовании панели отладки](ru/general/check-counter#data-debug)

## ru/general/debugger#logsСохранение логов действий во время работы с отладчиком

Вы можете отслеживать последовательность действий при работе с отладчиком. Действия записываются в течение сессии. Например, вы можете совершать действия на странице сайта, переходить на другие страницы. А затем переключаться между вкладками отладчика, чтобы проанализировать данные.

Опция доступна на вкладках **Console**, **Events**, **Ecommerce**, **Parameters**.

Чтобы записывать логи действий, в дополнительном меню включите опцию **Preserve log**. По умолчанию опция отключена — при каждом обновлении страницы сайта логи действий не сохраняются.

## ru/general/debugger#debuggerПочему не работает отладчик
