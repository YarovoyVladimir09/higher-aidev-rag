# Временные файлы, устанавливаемые Яндекс Метрикой

Яндекс Метрика предоставляет обезличенную информацию о посещаемости вашего сайта. Например, количество посетителей, источники их визитов, а также поведение посетителей на страницах сайта. Для учета посетителей Метрика использует анонимные идентификаторы браузеров, которые сохраняются в cookie, а также в localStorage-свойства. Cookie и свойства устанавливаются на домен верхнего уровня, например `.example.com`.

| Название | Тип | Срок действия | Описание | Домен, на который устанавливается |
| --- | --- | --- | --- | --- |
| _ym_metrika_enabled | Аналитическая | 60 минут | Проверяет, правильно ли установлены другие cookies Метрики | Домен, на котором установлен счетчик |
| _ym_isad | 20 часов | Используется для определения наличия у посетителя блокировщиков рекламы |  |  |
| _ym_uid | 1 год | Позволяет различать посетителей |  |  |
| _ym_fa | Cлужебная кука, в сочетании с кукой ym_uid предназначена для идентификации пользователей сайта |  |  |  |
| _ym_d | Хранит дату первого визита посетителя на сайт |  |  |  |
| _ym_ucs | Источник для _ym_uid . Появляется, если настроено серверное перевыставление cookie |  |  |  |
| gdpr | Техническая | До 2 лет | Позволяет различать посетителей из зоны действия Генерального регламента о защите данных (General Data Protection Regulation, GDPR) |  |
| _ym_debug | Техническая | В течение визита | Индикатор включенного отладочного режима |  |
| _ym_visorc_* | Аналитическая | 30 минут | Используется для корректной работы Вебвизора |  |
| _ym_hostIndex | 1 сутки | Позволяет ограничить количество запросов |  |  |
| _ym_sup_debug | Техническая | 1 сутки | Используется для работы отладчика счетчика Метрики |  |
| is_gdpr | Техническая | До 2 лет | Позволяет различать посетителей из зоны действия Генерального регламента о защите данных (General Data Protection Regulation, GDPR) | Все домены Яндекс Метрики |
| is_gdpr_b | Позволяет различать посетителей из зоны действия Генерального регламента о защите данных (General Data Protection Regulation, GDPR) |  |  |  |
| yabs-sid | Техническая | В течение сессии браузера | Идентификатор визита |  |
| i | Техническая | 1 год | Позволяет различать посетителей |  |

| yuidss |  |  |  |  |
| ymex | Аналитическая | 1 год | Хранит вспомогательную информацию для работы Метрики: время создания идентификаторов и их альтернативные значения |  |
| usst | Хранит вспомогательную информацию для синхронизации идентификаторов посетителей между разными доменами Яндекса |  |  |  |

Свойства устанавливаются на домен, на котором размещен счетчик Метрики.

| Название | Описание |
| --- | --- |
| _ym<номер счетчика>_lastHit | Используется для уточнения времени при определении точного показателя отказов |
| _ym<номер счетчика>_lsid | Позволяет различать посетителей |
| _ym<номер счетчика>_reqNum | Используется для определения порядкового номера запроса счетчика Метрики в браузере |
| _ym_hide_phones | Позволяет скрывать телефонные номера |
| _ym_retryReqs | Содержит запросы, которые счетчик не смог отослать на сервер |
| _ym_uid | Позволяет различать посетителей |
| ytm_tf_<номер_счетчика>_<id_триггера> | Позволяет различать посетителей для работы триггера Яндекс Тег Менеджера |
| ytm_tag_<номер_счетчика>_<id_тега> | Позволяет различать посетителей для работы тега Яндекс Тег Менеджера |
| zz | Позволяет различать посетителей |

| Название | Тип | Описание | Домен, на который устанавливается |
