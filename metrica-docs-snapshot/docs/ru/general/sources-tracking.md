# Как Метрика определяет источник трафика

Источники переходов на сайт определяются по рефереру ([HTTP-заголовок Referer](https://ru.wikipedia.org/wiki/HTTP_referer)) и по *меткам*. Если необходимо заменить реферер на ваш собственный, используйте параметр [utm_referrer](ru/general/source-tags#utm-referrer).

Яндекс Метрика определяет источник перехода по метке, если она есть в данных о **первом** *просмотре* в течение *визита* посетителя. Если метки нет в первом просмотре, источник перехода определяется по рефереру.

Например, посетитель перешел на сайт с закладки в браузере (первый просмотр). Затем покинул сайт, и в течение 30 минут вернулся, перейдя из почтовой рассылки по ссылке с меткой (второй просмотр в визите). Такой визит будет отнесен к прямому заходу на сайт.

Метка используется для определения названия мессенджера. Например, utm_source=viber . Если этой метки нет в URL, она указана без значения или значение не известно Метрике, то источник будет отнесен к типу Другое, определено по меткам . Полный список меток skype — для Skype; telegram — для Telegram; viber — для Viber; wechat — для WeChat; whatsapp — для WhatsApp. | Отчет «Мессенджеры» Отчет «Метки UTM» |

В отчет не включаются данные по обменным сетям и агрегаторам новостей (Новости, Рамблер/новости, Google News) Подробнее Метрика различает следующие системы: Мир тесен Рамблер Flipboard Google Discover. | Внутренние переходы | Если активность пользователя на сайте прервалась и тайм-аут визита закончился, но окно браузера осталось открытым, то при возобновлении активности будет создан новый визит с источником «внутренний переход». Примечание Для более точного определения внутренних переходов убедитесь, что адрес сайта указан верно в настройках счетчика (вкладка Счетчик ). | Отчет «Источники, сводка» |  |
| Переходы из почтовых рассылок | Метки UTM, Openstat, From. Как правильно сформировать метки | Посетитель перешел на сайт по ссылке в почтовом сообщении. Определяются по меткам UTM, Openstat и from. Как правильно сформировать метку | Отчет «Метки UTM» Отчет «Метки Openstat» Отчет «Метки From» |
| Переходы по QR-кодам | Переходы на сайт по QR-кодам определяются по меткам UTM. Как правильно сформировать метку | Отчет «Источники, сводка» Отчет «Метки UTM» |  |
| Не определено | — | Строка Не определено означает, что некоторые характеристики визита не удалось распознать, при этом сам визит был учтен в системе. Например, посещения из Яндекс Директа могут относиться к источнику Яндекс Директ: Не определено . Это значит, что Метрика распознала только рекламную систему, а кампанию, фразу и другие данные определить не удалось Почему визиты не распознаются Визиты в Метрике могут «не определяться» по многим причинам. Например, причиной появления строки Яндекс Директ: Не определено для переходов из Директа может служить разрыв во времени между генерацией метки yclid в Директе и записью визита в Метрике. Это может произойти в следующих случаях: Посетитель перешел на страницу по объявлению, оставил вкладку со страницей открытой, а позже обновил. Посетитель перешел по ссылке из объявления, а затем переслал ее кому-то другому — повторный визит по этой ссылке также не получится связать с кликом из Директа. Редиректы на сайте могут приводить к исчезновению yclid-метки из ссылки и потере реферера. | Отчет «Источники, сводка» |
