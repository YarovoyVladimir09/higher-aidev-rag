# Использование ClientID и UserID

Яндекс Метрика автоматически присваивает ClientID каждому уникальному посетителю сайта. Этот идентификатор — анонимный: он создается случайным образом и определяет браузер, в котором посетитель просматривает сайт. Таким образом, если посетитель просматривал ваш сайт из двух разных браузеров, в Яндекс Метрике будет зафиксировано два разных ClientID.

При необходимости вы можете присваивать посетителям вашего сайта собственные идентификаторы и передавать их в Яндекс Метрику в качестве *UserID*.

Эти идентификаторы используются для [передачи параметров посетителей](ru/data/user-params-data) и для [отслеживания офлайн-данных](ru/data/offline-params). Кроме этого, ClientID можно использовать в отчетах Яндекс Метрики, не передавая дополнительные данные:

**В качестве группировки**

1. В отчете нажмите кнопку **Группировки**.
2. Выберите группировку **Аудитория** → **ClientID**.

**В качестве условия сегментации**

1. В отчете в группе условий **для людей, у которых** нажмите значок .
2. Выберите условие **Характеристики** → **ClientID**.
