# Подписка на уведомления

- [Подписаться на уведомления](ru/general/notifications#subscribe)
- [Изменить почту для получения уведомлений](ru/general/notifications#change)
- [Отменить подписку](ru/general/notifications#cancel)

Метрика может присылать на вашу электронную почту сообщения разной тематики:

| Тема | Описание |
| --- | --- |
| Рекомендации и советы по вашим счетчикам | Подсказки по настройкам для ваших сайтов и счетчиков. Они помогут разобраться в Метрике и получить максимальную пользу от сервиса. По умолчанию рекомендации формируются для всех счетчиков, которые принадлежат вам. Вы можете изменить эту настройку. Для этого выберите одно из значений: Все, у которых я владелец . Все, которые могу редактировать . Некоторые счетчики . Выберите из списка. Если вы выбрали Все, у которых я владелец или Все, которые могу редактировать , рекомендации будут приходить и для всех счетчиков, к которым у вас есть доступ представителя |
| Новые возможности Метрики | Анонсы новых отчетов и функций, обучающие статьи и видео, приглашения на вебинары и мероприятия |
| Изменения в API Метрики | Оповещения об изменениях в работе Reporting API и Logs API |
| Предложения от других сервисов Яндекса для бизнеса | Советы, как повысить отдачу от продвижения в Директе |

## ru/general/notifications#subscribeПодписаться на уведомления

1. Перейдите на страницу **Настройка аккаунта** на вкладку **Уведомления**.
2. Укажите адрес электронной почты, на которую хотите получать сообщения.
3. Нажмите кнопку **Подписаться**.

После этого вам будут приходить рекомендации по счетчикам и сообщения о новых возможностях Метрики. Вы можете включить другие темы.

## ru/general/notifications#changeИзменить почту для получения уведомлений

1. Перейдите на страницу **Настройка аккаунта** на вкладку **Уведомления**.
2. Напротив адреса электронной почты нажмите значок .
3. Укажите адрес и сохраните изменения.

## ru/general/notifications#cancelОтменить подписку

Отменить подписку можно несколькими способами:

В письме с рассылкой нажмите кнопку **Отписаться**.

1. Перейдите на страницу **Настройка аккаунта** на вкладку **Уведомления**.
2. Напротив адреса электронной почты нажмите кнопку **Отменить подписку**.

Вам перестанут приходить уведомления о новинках в Метрике, подборки полезных материалов и рекомендации.
