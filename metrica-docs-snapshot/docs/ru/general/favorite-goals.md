# Избранные цели

- [Преимущества использования избранных целей](ru/general/favorite-goals#advantages)
- [Как использовать избранные цели](ru/general/favorite-goals#cases)
- [Вопросы и ответы](ru/general/favorite-goals#qanda)

**Избранные цели** — функция, позволяющая вам выделить и отслеживать ключевые цели вашего сайта. Вы можете выбрать цели, важные для вашего бизнеса, отметив их как избранные, после чего статистика по этим целям будет автоматически отображаться в отчетах Метрики. Это упрощает анализ эффективности трафика и помогает экономить время, избегая необходимости вручную анализировать каждую цель.

## ru/general/favorite-goals#casesКак использовать избранные цели

**Выбор целей**

В разделе **Цели** отметьте звездочками те цели, которые вы хотите сделать избранными.

Сделать это можно и на странице настройки цели с помощью опции **Сделать цель избранной**.

**Просмотр в отчетах**

Суммарная статистика по избранным целям будет автоматически отображаться в отчетах Метрики — в них появятся три новых столбца с показателями: **Достижения избранных целей**, **Доход по избранным целям** и **Конверсия посетителей по избранным целям**.

В кнопке рядом с метриками будет показано количество избранных целей. По клику на кнопку откроется окно со списком этих целей.

**Дополнительные метрики**

Кроме 3 стандартных метрик вы можете использовать дополнительные метрики по избранным целям. Они доступны во вкладке **Метрики** → **Поведение** → **Конверсии по избранным целям**.

Полный список метрик для использования в отчетах:

- **Конверсия в избранные цели** — доля целевых визитов с избранными целями
- **Достижения избранных целей** — количество выполненных избранных целей в визитах
- **Визиты с избранными целями**
- **Доход по избранным целям** — суммируется по всем избранным целям
- **Посетители с избранными целями**
- **Конверсия посетителей по избранным целям** — доля посетителей, достигших избранных целей, от общего числа уникальных посетителей
- **Достижения избранных целей на посетителя**
- **Средний доход визита по избранным целям**

## ru/general/favorite-goals#qandaВопросы и ответы

Да, вы можете в любой момент добавить новые цели или удалить существующие из списка избранных.

Если на вашем счетчике настроена электронная коммерция, цель **Ecommerce: покупка** автоматически будет включена в список избранных. Вы можете настроить этот список по своему усмотрению.

Функция доступна во всех стандартных отчетах по визитам, позволяя интегрировать данные по избранным целям для удобства анализа.

В таком случае в метрики по избранным попадут полные достижения выбранных составных целей (только те конверсии, в которых были выполнены все шаги цели).
