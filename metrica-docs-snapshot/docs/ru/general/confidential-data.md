# Конфиденциальность персональных данных

Чтобы сохранить конфиденциальность персональных данных, Условия использования сервиса Яндекс Метрика запрещают передавать идентификационную информацию в Метрику, за исключением использования функций сервиса, прямо предусматривающих такую передачу (например, [Передача данных из CRM](ru/crm/about)).

К идентификационным данным могут относиться:

- фамилия, имя и отчество;
- данные документов, удостоверяющих личность (например, паспортные);
- данные банковской карты;
- почтовый индекс;
- номер телефона;
- адрес электронной почты;
- административный адрес;
- информация о местоположении, определенная, например, с помощью GPS;
- налоговая информация (например, ИНН);
- медицинская и страховая информация (например, полис страхования);
- пароли к учетным записям.

Если вы сомневаетесь, является ли та или иная информация идентификационной в рамках законодательства вашего государства, проконсультируйтесь с юристом.

## ru/general/confidential-data#section_fjs_hzv_tcbРекомендации при передаче идентификационных данных

Следите за тем, чтобы идентификационные данные не передавались в Яндекс Метрику, включая следующие случаи:

- Отправка *UserID*. Не используйте персональные данные при формировании системы идентификаторов на сайте.
- Передача параметров [визитов](ru/data/visit-params-data) и [посетителей](ru/data/user-params-data).
- Передача [JavaScript-событий](ru/objects/reachgoal).
- Заполнение полей форм и поиска на сайте. Вы можете [настроить запись полей Вебвизором](ru/webvisor/settings).
- Формирование [UTM-меток](ru/general/source-tags#utm-construct). Не включайте персональные данные в параметры `utm_source`,`utm_medium`, `utm_term`, `utm_campaign` и `utm_content`.
- Формирование URL и заголовка страницы сайта.
