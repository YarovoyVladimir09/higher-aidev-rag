# Действия посетителей, которые можно отследить без цели

Получить информацию о том, до конца ли посетители просматривают страницу, можно с помощью [Карты скроллинга](ru/behavior/scroll-map#scroll-map). Также карта покажет области страницы, которые посетители просматривают чаще и дольше.

Узнать, сколько времени посетители провели на сайте, можно в любом отчете Яндекс Метрики — в таблице отображается метрика **Время на сайте**. Дополнительно вы можете [создавать сегменты](ru/general/segmentation#segmentation), указывая в качестве условия необходимое количество минут, которое, на ваш взгляд, посетитель должен проводить на сайте.

Отслеживать количество покупок, оформленных на сайте, а также их состав и стоимость, можно с помощью [электронной коммерции](ru/ecommerce/about#about).
