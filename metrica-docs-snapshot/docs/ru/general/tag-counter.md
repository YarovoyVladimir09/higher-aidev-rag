# Метки

- [Установка метки](ru/general/tag-counter#set-tag)
- [Быстрый доступ](ru/general/tag-counter#filter-tag)

Метки позволяют объединять счетчики в группы. Используйте метки, если у вас большое количество счетчиков или вы хотите [сформировать отчет по данным нескольких счетчиков одновременно](ru/reports/report-tag).

Вы можете создать свою метку, а также воспользоваться системными метками:

| Метка | Значение | Устанавливается автоматически |
| --- | --- | --- |
| Избранное | Счетчики, добавленные пользователем в избранное | Нет |
| Удаленные | Счетчики, которые были удалены . Через три месяца счетчик пропадет из списка удаленных — его нельзя будет восстановить | Да |
| РСЯ | Счетчики, которые входят в блоки РСЯ, установленные на сайте | Да |
| Гостевые | Счетчики, на которые пользователю выдан гостевой доступ | Да |

Примечание

Сервис позволяет отметить не больше 100 счетчиков одной меткой.

## ru/general/tag-counter#set-tagУстановка метки

Чтобы установить уже существующую метку для счетчика, на странице списка счетчиков нажмите значок  напротив нужного счетчика. Затем в открывшемся окне выберите необходимую метку и сохраните изменения.

Чтобы добавить метку, в этом же окне нажмите кнопку **Новая метка** и введите в поле ее название. Затем нажмите значок  и сохраните изменения. Новая метка будет установлена автоматически для данного счетчика.

Также вы можете добавить метку, нажав кнопку **Все метки**, а после установить ее для определенного счетчика.

## ru/general/tag-counter#filter-tagБыстрый доступ

Если вы часто работаете с некоторыми счетчиками, воспользуйтесь **Быстрым доступом**. Эта опция позволяет вынести необходимые метки в верхнее меню:

1. Нажмите кнопку **Все метки**, в появившемся окне нажмите кнопку **Быстрый доступ**.
2. Выберите из списка метки, с которыми часто работаете и нажмите кнопку **Сохранить**.

Выбранные метки отобразятся над общим списком счетчиков.
