# Статистика переходов по QR-кодам

*QR-код* — это двухмерный штрихкод, в котором может быть зашифрована любая информация, например, сведения о товаре, произвольный текст, адрес страницы сайта. Посетитель сканирует QR-код камерой мобильного телефона и переходит на сайт.

Для генерации QR-кода существуют специальные сервисы, например [генератор Яндекса](https://qr.yandex.ru/).

QR-код можно размещать как в электронном виде, так и на бумаге и других материальных носителях. Метрика позволяет отслеживать переходы на сайт с разных носителей QR-кода.

## ru/general/qrcode#kak-metrika-opredelyaet-qr-kod-v-kachestve-istochnikaКак Метрика определяет QR-код в качестве источника

Если вы используете генератор Яндекса, в ссылку автоматически добавляется специальная метка `yqrid`. С ее помощью Метрика определяет, что посетитель перешел на сайт по QR-коду. Метка формируется динамически при каждой генерации кода. Добавлять дополнительные параметры в ссылку необязательно.

Статистику переходов по сформированному в генераторе Яндекса QR-коду можно увидеть в отчете [Источники, сводка](ru/sources/sources-summary).

Если вы формируете QR-код другим способом, то в адрес страницы необходимо добавить [UTM-метку](ru/general/source-tags#form-rules).

Для отслеживания по UTM-метке обязателен параметр `utm_medium`. Рекомендуемые значения для этого параметра при переходе по QR-коду: `qr` или `qrcode`. Чтобы Метрика отличала переходы с разных носителей QR-кода, используйте параметры `utm_campaign` — название кампании и `utm_content` — содержание кампании.

Возьмем в качестве примера ситуацию, когда QR-код формируется из ссылки на страницу с информацией о бонусах и будет размещен на рекламном объявлении в метро. Тогда ссылка может выглядеть так:

```
https://example.com/?utm_medium=qrcode&utm_campaign=metro&utm_content=bonus
```

[Как Метрика определяет источники трафика](ru/general/sources-tracking)
