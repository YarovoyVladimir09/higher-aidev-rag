# Сегментация данных

Метрика [собирает и обрабатывает большой объем информации](ru/general/how-it-works) о посетителях сайта. Для решения бизнес-задач иногда необходимо выделить из этого множества только часть данных.

Метрика позволяет выбрать не только визиты посетителей по какому-либо действию (например, просмотр конкретной страницы, переход из какого-либо источника), но и по некоторым параметрам этих посетителей: пол, возраст и пр.

Кроме этого может быть важно получить статистику о посетителях, которые совершили какое-либо действие в прошлом, и проанализировать связь действий в прошлом и настоящем.

Построить отчет только по интересующим вас данным поможет [создание сегмента](ru/general/segmentation-report) — с учетом необходимых условий.

Сегменты можно создавать не только в веб-интерфейсе, но и с помощью [API Метрики](https://tech.yandex.ru/metrika/). Оба способа позволяют формировать до 500 сегментов. Таким образом, общее количество сегментов для одного счетчика может составлять 1 000.

При работе с сегментами следует учесть, что:

- Сегменты, созданные в веб-интерфейсе, вы можете использовать в [Директе](https://yandex.ru/support/direct/impression-criteria/retargeting-lists.html) и [Яндекс Аудиториях](https://yandex.ru/support/audience/segments/segment-new.html).
- Сегменты, созданные с помощью API, можно использовать только для подбора аудитории в Яндекс Директе. Они не отображаются в веб-интерфейсе Метрики.
- В некоторых случаях сегмент, созданный в одном из отчетов Метрики, не работает в другом отчете или недоступен в Яндекс Директе и Яндекс Аудиториях. Например, созданный в отчете [Директ, расходы](ru/sources/direct-clicks) сегмент нельзя применить в любом другом отчете, также такой сегмент нельзя выбрать при подборе аудитории в Яндекс Директе.

Примечание

Вы можете изменить созданные в веб-интерфейсе сегменты с помощью API, но после этого они перестанут отображаться в веб-версии сервиса.
