# Блокировщик Яндекс Метрики

По умолчанию Яндекс Метрика собирает сведения о всех посетителях сайта. Сбор сведений об отдельных посетителях может быть запрещен с помощью Блокировщика Яндекс Метрики.

Блокировщик представляет собой плагин для браузера. Он блокирует [размещение файлов cookie](ru/general/how-it-works#data_extract_pull) на компьютере посетителя и ограничивает отправку данных в Яндекс Метрику.

Варианты установки плагина для разных браузеров:

**Mozilla Firefox**

**Google Chrome**

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.
