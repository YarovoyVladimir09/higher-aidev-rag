# Статистика по поисковым запросам из браузеров с ограничением third-party cookies

## ru/general/search-query-sup#ispolzovanie-parametra-ysclidИспользование параметра ysclid

Яндекс Метрика собирает и анализирует статистику по поисковым запросам, которые привели посетителей на ваш сайт из результатов поиска. Эти данные представлены, например, в отчетах [Поисковые запросы](ru/sources/search-queries) и [Поисковые системы](ru/sources/search-engines).

В некоторых случаях статистика по поисковым запросам может отображаться не полностью. В частности, информация по поисковым запросам может частично отсутствовать, если посетители переходили на ваш сайт из поисковой выдачи в браузерах с ограничением межсайтовых cookies (third-party cookies) — например, Safari или Mozilla Firefox.

Чтобы более точно определять поисковые запросы, соблюдая при этом требования к сохранению приватности пользователей, Яндекс добавляет в ссылку специальный параметр — `ysclid` — при переходе на сайт из результатов поиска Яндекса.

Пример: `https://example.com/?ysclid=ksil7dwgjm`.

Параметр добавляется к выборочным адресам страниц в результатах поиска в браузерах, в которых не поддерживаются third-party cookies.

Параметр `ysclid` не отображается в отчетах Метрики, но может быть заметен при использовании сторонних инструментов, например для оптимизации сайта. Вы можете заметить появление в отчетах Метрики данных о поисковых запросах.

Если параметр `ysclid` отображается в ссылках в используемых системах веб-аналитики, добавьте его в исключения.
