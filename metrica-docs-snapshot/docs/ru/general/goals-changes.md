# Изменения в отслеживании целей

Метрика обновила алгоритм сбора данных по целям. Мы изменили тип некоторых целей, которые вы используете, чтобы статистика по ним стала более точной. В основном это цели типа [Посещение страниц](ru/general/goal-page-visit).

В некоторых случаях Метрика учитывала в статистике по цели не только посещение страницы, но и другие события (например, нажатие кнопки), если идентификатор таких событий содержал фрагмент адреса целевой страницы.

**Пример**

Цели типа «Посещение страниц», для которых 99% достижений составили иные события на сайте, мы заменили на цели типа [JavaScript-событие](ru/general/goal-js-event). Это коснулось целей с неточными настройками.

**Пример**

Теперь в статистике по цели отображаются только те события, которые соответствуют типу цели.

**Пример**

Такую цель мы заменили целью типа «JavaScript-событие», где идентификатор события содержит `purchase`.

В других случаях при настройке цели типа [Посещение страниц](ru/general/goal-page-visit) было указано несколько условий. Если хотя бы для одного из них зафиксирована неточность (в статистику записывались и другие целевые события), цель изменена на [Составную](ru/general/goal-steps).

Условием шага составной цели будет выбрано то условие, по которому Метрика зафиксировала достижения цели.

[Написать в чат](https://yandex.ru/chat/#/user/036e6a02-3620-9cdc-4c5e-a34667a7379e?utm_source=spravka)

Если нужно скорректировать цель, чтобы она и дальше фиксировала события, которые отличаются от посещения страниц, пожалуйста, опишите ситуацию в форме.
