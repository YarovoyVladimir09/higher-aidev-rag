# Сегмент как условие ретаргетинга и подбора аудитории в Яндекс Директе

В сегменте учитываются только те посетители, которые отвечают условиям, заданным при его создании. Другие данные, доступные в отчетах Яндекс Метрики, не влияют на формирование сегмента (например, на диапазон дат, добавленную цель, выборку).

В Яндекс Метрике новые данные добавляются в сегмент в течение 180 минут после выполнения условия. Сегмент пересчитывается ежедневно, поэтому содержит актуальные данные.

Пример создания сегмента:

Выделим посетителей, которые просмотрели определенные страницы сайта (например, каталог товаров одной из категорий), чтобы с помощью Яндекс Директа предложить им товар или услугу, связанную с этими страницами.

1. В группе условий **для людей, у которых** нажмете кнопку .
2. Выберите условие: **Поведение** → **Просмотр URL**, в строке введите URL необходимой страницы (например, `https://example.com/tariff/`). Используйте `@example.com`, чтобы сегментировать отчет по всем страницам, в адрес которых входит `example.com`.
3. [Сохраните полученный сегмент](ru/general/segmentation-report#save).
4. В Директе [добавьте условие ретаргетинга и подбора аудитории](https://yandex.ru/support/direct/impression-criteria/retargeting-lists.html#retargeting-lists).
