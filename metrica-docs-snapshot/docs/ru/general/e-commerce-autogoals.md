# Автоматические цели для электронной коммерции

- [Ограничения](ru/general/e-commerce-autogoals#restrictions)
- [Как использовать автоматические цели в продвижении](ru/general/e-commerce-autogoals#cases)

Передавая данные об [электронной коммерции](ru/ecommerce/about), вы можете собирать, анализировать и использовать в кампаниях Директа информацию о взаимодействии посетителей с товарами на сайте.

При отправке событий [добавления товара в корзину](ru/ecommerce/data#add) и [покупок](ru/ecommerce/data#purchase) будут созданы автоматические цели:

- «Ecommerce: добавление в корзину», чтобы отслеживать добавление товаров в корзину;
- «Ecommerce: покупка», чтобы отслеживать заказы.

Чтобы Метрика создала цели и начала собирать данные по ним, в настройках счетчика не нужно включать опцию **Автоматические цели**. Цели будут созданы при первой передаче с сайта этих событий.

Для просмотра статистики по целям, используйте [Отчет «Конверсии»](ru/reports/conversion) и [добавляйте цели](ru/reports/report-general#choose-goal) в другие отчеты Метрики.

Подобные конверсии также можно отслеживать с помощью:

- Цели [JavaScript-событие](ru/general/goal-js-event), чтобы фиксировать нажатия кнопки **Купить**, оформление заказа и т. д.
- Цели [Посещение страниц](ru/general/goal-page-visit), чтобы фиксировать посещения страницы с корзиной.

Подключить передачу данных в Метрику можно с помощью [официальных интеграций](ru/ecommerce/enabling) или [разработчика](ru/data/e-commerce). После подключения электронной коммерции вам станут доступны подробные отчеты о товарах, заказах и посетителях, которые их оформили.

## ru/general/e-commerce-autogoals#restrictionsОграничения

- source: ru/_includes/general/auto-goals/id-restrictions/step.md Данный тип цели невозможно использовать в [Составной цели](ru/general/goal-steps). endsource: ru/_includes/general/auto-goals/id-restrictions/step.md
- source: ru/_includes/general/auto-goals/id-restrictions/list.md Автоматические цели не учитываются в общем количестве целей счетчика. endsource: ru/_includes/general/auto-goals/id-restrictions/list.md
- source: ru/_includes/general/goal-page-visit/id-general/2.md Сервис фиксирует достижение посетителем одной и той же цели на одном счетчике не чаще, чем раз в секунду. endsource: ru/_includes/general/goal-page-visit/id-general/2.md
- source: ru/_includes/general/goal-page-visit/id-general/3.md Во время одного визита посетителя сервис может фиксировать до 1000 достижений офлайн-целей и 400 достижений онлайн-целей, созданных для счетчика. endsource: ru/_includes/general/goal-page-visit/id-general/3.md
- source: ru/_includes/general/goal-page-visit/id-general/4.md При редактировании счетчика или цели накопленная ранее информация не изменяется. endsource: ru/_includes/general/goal-page-visit/id-general/4.md
- Данный тип автоматических целей нельзя удалить, изменить название и доход по умолчанию.

## ru/general/e-commerce-autogoals#casesКак использовать автоматические цели в продвижении

Автоматические цели электронной коммерции для интернет-магазинов могут быть полезны для ведения объявлений в Директе.

**Стратегии Директа**

Стратегия [Максимум конверсий с ограничением по доле рекламных расходов](https://yandex.ru/support/direct/strategies/average-crr.html) с помощью автоцелей поддерживает оптимальное соотношение расходов на продвижение с доходом от продаж. Автоматические цели передают доход на основе стоимости товаров на сайте. В итоге стратегия приносит максимум конверсий по выбранной цели при заданной доле рекламных расходов: например, 10% от стоимости товара.

В стратегии [Максимум конверсий с оплатой за конверсии](https://yandex.ru/support/direct/strategies/average-cpa.html) можно выбрать автоматическую цель “Покупка” или “Корзина” и платить только за те переходы с объявлений, которые привели к достижению этих целей по конкретно заданной цене.

**Настройка таргетинга**

**Оценка эффективности продвижения**

Автоматические цели позволяют сравнивать эффективность рекламных каналов и определять:

- кто из посетителей стал покупателем;
- откуда приходят покупатели;
- какие рекламные каналы наиболее рентабельны.

Эта статистика поможет оценивать эффективность продвижения и оптимизировать затраты на продвижение в Директе.
