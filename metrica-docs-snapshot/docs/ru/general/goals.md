# Что такое цели. Типы целей

- [Использование целей в кампании Директа](ru/general/goals#direct)
- [Избранные цели](ru/general/goals#favorite)
- [Узнайте больше](ru/general/goals#uznajte-bolshe)

Для каждого счетчика Яндекс Метрики при настройке его параметров можно создавать цели. Цели помогают:

- Отслеживать действия посетителей на сайте (просмотр страницы, нажатие кнопки и т. д.).
- Настраивать ретаргетинг в [Директе](https://yandex.ru/support/direct/impression-criteria/retargeting-lists.html) и [Аудиториях](https://yandex.ru/support/audience/segments/segment-new.html).
- Следить за конверсионностью посетителей, которые видели ваш баннер или видеорекламу, — с помощью [Метрики для медийной рекламы](https://yandex.ru/support/media-metrica/index.html).

*Цель* — это действие посетителя, в котором заинтересован владелец сайта: просмотр определенного количества страниц, посещение конкретной страницы, нажатие кнопки, переход по ссылке, оплата заказа и т. д.

Когда пользователи приходят на ваш сайт и взаимодействуют с ним, Яндекс Метрика [собирает информацию об этом](ru/general/how-it-works#how-it-works) и фиксирует достижение целей. На основе собранных данных рассчитываются т. н. целевые метрики:

*Достижение цели* — это момент, в который посетитель выполнил заданное в параметрах цели условие.

*Целевой посетитель* — это посетитель, который выполнил условие, заданное в параметрах цели.

*Целевой визит* — это *визит*, в течение которого произошло достижение цели. В течение одного целевого визита может произойти несколько достижений одной и той же цели.

*Конверсия* — это отношение количества целевых визитов к общему числу визитов.

*Конверсия посетителей* — доля достигших целей в общем числе уникальных посетителей.

*Достижения на посетителя* — среднее количество достижений цели на уникального целевого посетителя.

*Доход по цели* — передаваемый с некоторыми целями параметр, обозначающий доход или ценность цели. Может быть указан при создании цели в интерфейсе как статический доход или передан как параметр с атрибутом `price` или `order_price`.

Пример:

Ваш сайт посвящен обучающим курсам. На сайте есть возможность оставить заявку на участие — заполнить специальную форму. В этом случае отправку формы можно считать целевым действием. Посетитель сайта, который оставил заявку, является целевым посетителем. А визит, в течение которого посетитель отправил форму — целевым визитом.

Целевые метрики можно отслеживать в [большинстве отчетов Яндекс Метрики](ru/reports/goals#goals). Кроме этого, доступен [отчет по конверсиям](ru/reports/conversion#conversion).

Цели делятся на несколько типов по условию достижения:

- [Целевое событие](ru/general/goal-js-event#create-goal). Информация о достижении цели передается с помощью JavaScript, API-интеграции или ручной загрузки файла.
- [Количество просмотров](ru/general/goal-page-views#goal-page-views). Просмотр определенного числа страниц сайта.
- [Посещение страниц](ru/general/goal-page-visit#goal-page-visit). Просмотр заданных страниц сайта.
- [Клик на email](ru/simple-goal/email). Отслеживание нажатия на все адреса на сайте или на указанный адрес.
- [Клик по номеру телефона](ru/simple-goal/tel). Отслеживание нажатия на все номера телефонов на сайте или на указанный номер.
- [Клик по кнопке](ru/simple-goal/click). Отслеживать нажатия на кнопки и другие кликабельные элементы.
- [Отправка формы](ru/simple-goal/form). Отслеживайте отправку всех форм на сайте или только некоторых из них.
- [Переход в мессенджер](ru/simple-goal/messengers). Отслеживайте переходы посетителей сайта по ссылкам в популярные мессенджеры.
- [Переход в социальные сети](ru/simple-goal/social-networks). Отслеживайте переходы посетителей сайта по ссылкам в популярные социальные сети.
- [Скачивание файлов](ru/simple-goal/download). Отслеживайте скачивания всех файлов на сайте или только некоторых из них.
- [Поиск по сайту](ru/simple-goal/search). Узнайте, насколько часто посетители пользуются поиском на вашем сайте.
- [Возврат из платежной системы](ru/simple-goal/payment-system). Отслеживайте, сколько посетителей вернулись на сайт после перехода в платежную систему.
- [Звонки](ru/general/call-goal). Отслеживание разных категорий звонков: всех, только уникальных, а также любых или уникальных длительностью больше 30 секунд.
- [Чаты](ru/general/chat-goal). Отслеживайте события из чатов: в каком мессенджере была переписка, был ли ответ на сообщение покупателя.
- [Мультицель](ru/general/multi). Позволяет объединить под одной целью разные перечисленные условия для достижения результата.
- [Составная цель](ru/general/goal-steps#goal-steps). Сочетает в себе некоторые перечисленные выше типы целей, которые достигаются последовательно по заранее заданным шагам.

Ряд целей Метрика [может создавать автоматически](ru/general/auto-goals#activate).

## ru/general/goals#directИспользование целей в кампании Директа

Если управлением ваших кампаний в Директе занимается кто-то кроме вас, например, агентство или специалист по настройке, вы можете дать разрешение на использование существующих в Метрике целей: [автоматических](ru/general/auto-goals) и созданных самостоятельно. Тогда пользователь Директа сможет использовать цели для оптимизации кампаний без доступа к счетчику Метрики.

При этом для пользователя Директа будет доступна только часть статистики, которая необходима для оценки эффективности созданных им кампаний.

Ограничение

Для настройки ретаргетинга и подбора аудитории дать разрешение на использование целей невозможно.

Чтобы дать разрешение на использование целей, в Метрике на странице **Цели** включите опцию **Разрешить в рекламных кампаниях оптимизацию по целям без доступа к счетчику**. Если вы недавно создали счетчик, опция включена по умолчанию.

[Как использовать опцию](https://yandex.ru/support/direct/statistics/metrika.html#access-to-goals)

## ru/general/goals#favoriteИзбранные цели

**Избранные цели** — функция, позволяющая вам выделить и отслеживать ключевые цели вашего сайта. Вы можете выбрать цели, важные для вашего бизнеса, отметив их как избранные, после чего статистика по этим целям будет автоматически отображаться в отчетах Метрики. Это упрощает анализ эффективности трафика и помогает экономить время, избегая необходимости вручную анализировать каждую цель. [Как использовать избранные цели](ru/general/favorite-goals)
