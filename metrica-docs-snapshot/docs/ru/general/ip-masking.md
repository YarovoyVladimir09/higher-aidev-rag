# Маскировка IP-адреса

Маскировка IP-адреса — это настройка счетчика, позволяющая указать, в каком виде Яндекс Метрика будет обрабатывать и хранить IP-адреса посетителей вашего сайта.

Эта настройка может быть необходима в некоторых случаях, например для выполнения требований по защите личных данных пользователей, включая политики конфиденциальности сторонних ресурсов и государственные законы.

По умолчанию в Яндекс Метрике сохраняется полный обезличенный IP-адрес посетителя. Он необходим для более точного определения региона посетителя сайта, но не отображается в отчетах сервиса.

Если вы включили маскировку IP-адресов, Яндекс Метрика скроет адрес при первой технической возможности на максимально ранней стадии сбора данных. При поступлении данных в Яндекс Метрику последний [октет](https://clck.ru/CyWcY) IPv4-адреса или последние 64 бита IPv6-адреса обнулятся — в системе запишется неполный адрес. Например, значение 192.0.2.2 изменится на 192.0.2.0.

Примечание

Маскировка IP-адресов может снизить точность гео-данных в отчетах Метрики.

## ru/general/ip-masking#kak-vklyuchit-maskirovku-ip-adresaКак включить маскировку IP-адреса

1. Перейдите на страницу **Настройка**.
2. На вкладке **Счетчик**, в блоке **Дополнительные условия обработки данных**, включите опцию **Не сохранять полные IP-адреса посетителей сайта**.

Также вы можете включить маскировку IP-адреса во время [создания счетчика](ru/general/creating-counter) — в блоке **Дополнительные условия обработки данных**.
