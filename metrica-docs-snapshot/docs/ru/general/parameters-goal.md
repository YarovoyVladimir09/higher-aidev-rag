# Цель «Параметры»

- [Создание цели](ru/general/parameters-goal#create)
- [Передача дохода](ru/general/parameters-goal#income)
- [Ограничения](ru/general/parameters-goal#limits)

Цель «Параметры» позволяет использовать передаваемые события как условие для достижения цели.

Цель можно использовать для:

- Событийной аналитики — отслеживать действия пользователей на сайте, чтобы понять, как посетители взаимодействуют с ресурсом.
- Анализа событий — отслеживать конкретные действия пользователей с большей детализацией. Например, на какие элементы страницы чаще кликают, на каких этапах пользователи отказываются от оформления заказа.
- Настройки и оптимизации рекламных кампаний. Например, чтобы понять, какие объявления приводят к нужным действиям на сайте.

Подробнее о передаче событий методом `params` читайте в разделе [Передача событий](ru/data/visit-params-data).

Цель «Параметры» срабатывает только для параметров размером до 2 КБ (приблизительно 2 048 символов). Если параметр больше 2 КБ — цель не будет достигнута.

На один визит посетителя сервис может фиксировать на счетчике до 400 достижений онлайн-целей. При создании цели «Параметры» заранее проверьте, что новая цель не будет превышать этот лимит.

## ru/general/parameters-goal#createСоздание цели

Чтобы создать цель:

1. В Метрике в левом меню перейдите на страницу **Цели**.
2. Нажмите кнопку **Добавить цель**.
3. Выберите тип цели **Параметры**.
4. В поле **Название** укажите имя создаваемой цели.
5. По кнопке **Атрибуты** можно выбрать, параметры какого уровня будут использоваться для настройки цели и в каком порядке.
6. В поле для ввода укажите условия. Для разделения уровней используйте символ `"."`. Для описания условий можно использовать следующие символы: `@` — содержит строку; `~` — регулярное выражение. ПримерЕсли вы сохранили в атрибутах стандартный порядок параметров, то условие может иметь следующий вид: param_1.param_2.param_3.param_4
7. Нажмите **Добавить цель**. Созданная цель отобразится в списке целей. Метрика начнет сбор статистики по ней в течение нескольких минут.

Метрика будет отслеживать комбинации параметров, которые содержат заданное условие. Это будет считаться достижением цели.

## ru/general/parameters-goal#incomeПередача дохода

Чтобы передать доход вместе с параметрами, используйте атрибуты `order_price` и `currency` (трехбуквенный [код валюты по ISO 4217](https://ru.wikipedia.org/wiki/ISO_4217)).

Пример:

```
// Пример передачи объекта. Максимальная вложенность — 10 уровней 
ym(XXXXXX, "params", { 
  order_price: "15000",
  currency: "RUB",
  level1_1: {
    level2_1: {
      level3_1: "example1",
      level3_2: "example2",
    },
    ...
    level2_2: "example3"
  }
})
```

## ru/general/parameters-goal#limitsОграничения

- Для каждого счетчика можно задать до 200 целей.
- Сервис фиксирует достижение посетителем одной и той же цели на одном счетчике не чаще, чем раз в секунду.
- Во время одного визита посетителя сервис может фиксировать до 1 000 достижений офлайн-целей и 400 достижений онлайн-целей, созданных для счетчика.
- Размер передаваемого параметра событий не должен превышать 2 КБ (приблизительно 2 048 символов).
- При редактировании счетчика или цели информация, которая была собрана ранее, не изменяется.
- Если вы удалите цель, собранная по ней информация будет недоступна в отчетах.
