# Интеграции с Метрикой

Яндекс Метрика предлагает инструменты аналитики, которые тесно связаны с работой сайта. Чтобы их использовать, в большинстве случаев нужны навыки программирования. Метрика стремится упростить настройку своих инструментов, поэтому ее команда и внешние разработчики создают дополнения для сайтов и CRM.

Все разработки можно посмотреть в Метрике на странице **Интеграции**. Например, на [демосчетчике](https://metrika.yandex.ru/r/marketplace?). Разработанные командой Метрики дополнения отмечены значком. Созданные сторонними разработчиками отображаются без метки.

Примечание

Команда Метрики не несет ответственности за интеграции, созданные внешними разработчиками. Если при их использовании возникли трудности, обратитесь к разработчикам.

## ru/marketplace#devРазработчикам интеграций

Чтобы создать интеграцию с Яндекс Метрикой, [используйте инструкцию](https://yastatic.net/s3/doc-binary/src/support/metrica/ru/MetricaIntegrationInstructions.pdf).

Если вы разработали дополнение, предложите разместить его в Метрике через форму ниже. Команда может принять или отклонить предложение, а при публикации дополнения изменить его название и описание.
