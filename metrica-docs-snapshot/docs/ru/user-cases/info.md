# Сайт-визитка, блог без рекламы

Если у вас небольшой сайт, который предлагает посетителям контент разной тематики, и вы не размещаете на нем рекламу, настройте Метрику следующим образом:

1. [Создайте счетчик Яндекс Метрики](ru/general/creating-counter).
2. [Подключите Вебвизор и карты](ru/general/counter-general#general).
3. [Настройте цели](ru/general/goals), чтобы отслеживать важные действия на сайте. Например, просмотр определенной страницы.
4. Если ваш сайт добавлен в [Яндекс Вебмастер](https://webmaster.yandex.ru), то [настройте индексирование страниц сайта](ru/general/link-webmaster) с установленным счетчиком Метрики.

Рекомендуем обратить внимание на следующие отчеты, которые помогут решить ваши задачи:

| Задача | Решение |
| --- | --- |
| Узнать, сколько людей приходят на сайт | Отчет «Посещаемость» поможет определить, сколько людей посещает ваш сайт и насколько он интересен |
| Узнать, откуда люди приходят на сайт | Отчет «Источники, сводка» поможет определить наиболее эффективные каналы привлечения посетителей: другие сайты, реклама и т. д. |
| Определить, какие материалы сайта больше нравятся посетителям — какие страницы они чаще просматривают | Вам помогут: Отчет «Популярное» — показывает наиболее популярные страницы сайта на основе количества посетителей и просмотров. Карта кликов — помогает увидеть наиболее кликабельные области страниц сайта. Карта ссылок — позволяет определить наиболее популярные ссылки на страницах. Карта скроллинга — показывает, какие области страницы посетители просматривают чаще |
| Найти недоработки в дизайне | Выяснить, как именно посетители передвигаются по сайту, какие действия совершают чаще, вам помогут: Вебвизор — показывает, как ведут себя посетители при просмотре страниц сайта. Например, можно выяснить, удобно ли посетителям пользоваться навигацией сайта. Как правило, если пользователь испытывает затруднения, он не выполняет ожидаемый сценарий перехода по ссылкам, движения мыши хаотичны. Карта кликов — помогает увидеть наиболее кликабельные области страниц сайта. Отчет «Страницы выхода» — помогает определить путь посетителя с начала до завершения визита |
