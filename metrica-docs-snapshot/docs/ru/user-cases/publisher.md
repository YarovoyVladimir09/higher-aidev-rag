# Информационный сайт, размещающий рекламу

Если у вас многостраничный сайт с часто обновляющимся контентом, например, новостной сайт, и вы размещаете рекламу на его страницах, настройте Метрику следующим образом:

1. [Создайте счетчик Яндекс Метрики](ru/general/creating-counter).
2. Подключите: [Вебвизор и карты](ru/general/counter-general#general); [Контентную аналитику](ru/publishers/about#how-to). Для включения опции поддержите разметку на сайте.
3. [Настройте цели](ru/general/goals), чтобы отслеживать важные действия на сайте. Например, просмотр определенной страницы или нажатие кнопки.
4. Если вы монетизируете сайт с помощью Рекламной сети Яндекса или Adfox, подключите отчеты ([РСЯ](ru/sources/yan-settings), [Adfox](ru/sources/adfox-settings)).
5. Если ваш сайт добавлен в [Яндекс Вебмастер](https://webmaster.yandex.ru), то [настройте индексирование страниц сайта](ru/general/link-webmaster) с установленным счетчиком Метрики.

Совет

Вы можете настроить передачу параметров [визитов](ru/data/visit-params-data) и [посетителей](ru/data/user-params-data), чтобы детально анализировать поведение на сайте. Например, сравнивать действия авторизованных и неавторизованных пользователей.

Рекомендуем обратить внимание на следующие отчеты, которые помогут решить ваши задачи:

| Задача | Решение |
| --- | --- |
| Узнать, откуда люди приходят на сайт | Отчет «Источники, сводка» поможет определить наиболее эффективные каналы привлечения посетителей: другие сайты, реклама и т. д. |
| Выяснить, сколько посетителей знают адрес сайта наизусть | В этом поможет Источники, сводка |
| Узнать наиболее популярные статьи | Вам помогут: Отчеты по материалам ; Отчеты по рубрикам |
| Понять, как посетители читают материалы сайта | Обратите внимание на показатели статистики по контенту, например скроллы и дочтения, время на материал |
| Найти недоработки в дизайне | Выяснить, как именно посетители передвигаются по сайту, какие действия совершают чаще, вам помогут: Вебвизор — показывает, как ведут себя посетители при просмотре страниц сайта. Например, можно выяснить, удобно ли посетителям пользоваться навигацией сайта. Как правило, если пользователь испытывает затруднения, он не выполняет ожидаемый сценарий перехода по ссылкам, движения мыши хаотичны. Карта кликов — помогает увидеть наиболее кликабельные области страниц сайта. Отчет «Страницы выхода» — помогает определить путь посетителя с начала до завершения визита |
| Найти новые идеи для получения дохода | Если для показа рекламы на сайте вы используете Рекламную сеть Яндекса или Adfox, вам помогут: Отчеты группы «Adfox» Отчеты группы «Рекламная сеть Яндекса» |
| Понять, как распределяется вовлеченный трафик между разными типами устройств | Используйте атрибуцию Кросс-девайс |
