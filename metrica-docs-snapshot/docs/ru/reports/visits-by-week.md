# Отчет «Посещаемость по дням недели»

- [Какие задачи может решать отчет](ru/reports/visits-by-week#case)
- [Структура и настройка отчета](ru/reports/visits-by-week#data)

Отчет показывает распределение трафика на сайте по дням недели. Время соответствует часовому поясу, который вы указали в настройках счетчика.

Посмотреть отчет: **Отчеты** → **Аудитория** → **Посещаемость по дням недели**.

## ru/reports/visits-by-week#caseКакие задачи может решать отчет

- Узнать, в какие дни недели посещаемость сайта достигает максимума

## ru/reports/visits-by-week#dataСтруктура и настройка отчета

Данные в отчете сгруппированы по дневным интервалам в течение недели. Можно просмотреть статистику по визитам, которые начались в один из таких интервалов.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
