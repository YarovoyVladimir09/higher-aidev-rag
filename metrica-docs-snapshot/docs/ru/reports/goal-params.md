# Отчет «Параметры целей»

- [Какие задачи может решать отчет](ru/reports/goal-params#case)
- [Структура и настройки отчета](ru/reports/goal-params#data)

Посмотреть отчет: **Отчеты** → **Содержание** → **Параметры целей**.

## ru/reports/goal-params#caseКакие задачи может решать отчет

Чтобы определить наиболее эффективный вариант, вы можете разметить интересующие вас события и цели параметрами. Для этого передайте события методом [params](ru/objects/params-method) или цели как [«JavaScript-события»](ru/general/goal-js-event). Чтобы добавить туда параметры, используйте объект [params](ru/code/counter-initialize#param-params).

Пример отправки данных:

```
<form action="">
    ...
    <input type="button" onclick="ym(XXXXXXXX, 'reachGoal', 'TARGET_NAME', {group: 'A'}); return true;" value="Заказать"/>
</form>
```

где XXXXXXXX — номер счетчика.

Вы можете узнать, на каких страницах чаще достигаются «JavaScript-события», и оценить их эффективность.

## ru/reports/goal-params#dataСтруктура и настройки отчета

Данные в отчете сгруппированы по целям и параметрам, которые вы передаете.

Отчет содержит дополнительную информацию о визитах посетителей:

- Информация, которая не собирается Метрикой [по умолчанию](ru/general/how-it-works#data_extract_pull) и известна только владельцу сайта (например, отзыв на сайте).
- Информация о действиях авторизованных на сайте посетителей, известная сайту.
- Информация, которую можно получить из браузера посетителя с помощью JavaScript.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
