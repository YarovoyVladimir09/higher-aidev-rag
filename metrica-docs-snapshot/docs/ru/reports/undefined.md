# Не определено

- [Отсутствие данных](ru/reports/undefined#no-data)
- [Недостаточно данных для определения](ru/reports/undefined#enough)
- [Технические причины](ru/reports/undefined#tech)
- [Данные не были переданы](ru/reports/undefined#transfer)

В отчетах Метрики иногда отображается строка **Не определено**. Она показывает, что по каким-то срезам выбранной в отчете группировки нет данных.

Почему данных может не быть:

- они отсутствуют;
- не были переданы в Метрику;
- недостаточно данных для определения;
- технические проблемы.

Подпись **Не определено** отображается не всегда — она скрыта, если не несет пользы для просмотра статистики.

Ниже приведены наиболее частые случаи, когда строка **Не определено** отображается в отчетах.

## ru/reports/undefined#no-dataОтсутствие данных

Подпись **Не определено** может появиться, если данные отсутствуют.

**Пример:**

Вы используете группировку **Страница входа**, которая показывает три уровня пути, а пользователь перешел на страницу с адресом, которой содержит два уровня пути:

```
https://example.com/level_1/level_2
```

В отчете отобразятся данные:

- Страница входа, уровень 1 — `level_1`.
- Страница входа, уровень 2 — `level_2`.
- Страница входа, уровень 3 — `Не определено`.

## ru/reports/undefined#enoughНедостаточно данных для определения

В некоторых группировках, например **Пол** или **Возраст**, должно накопиться достаточное количество данных, чтобы определить их принадлежность к тому или иному срезу.

Также в эту категорию может попасть, например, **Браузер** — если он новый или редкий, данных для его классификации может быть недостаточно.

## ru/reports/undefined#techТехнические причины

Данные могут не передаваться из-за технических проблем:

- На сайте. Например, данные могут передаваться некорректно при использовании нестандартной версии кода счетчика. Поэтому в некоторых группировках отобразится строка **Не определено**.
- На стороне пользователя вашего сайта. Например, при использовании устаревшего или нестандартного браузера, который передает не все данные, или при проблемах со стабильностью и скоростью интернета.

## ru/reports/undefined#transferДанные не были переданы

Самая частая причина, по которой данные могут отсутствовать, — если они не были переданы в Метрику.

Некоторые группировки Метрики, например **Цели**, **Электронная коммерция**, **Параметры события**, **Параметры визита** или **UTM-метки**, работают на данных, переданных с вашего сайта. Для работы таких группировок необходимо, чтобы данные передавались с сайта и фактически там присутствовали.
