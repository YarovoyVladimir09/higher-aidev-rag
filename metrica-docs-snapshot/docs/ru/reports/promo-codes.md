# Отчет «Промокоды»

Отчет содержит данные о покупках, которые были совершены по промокодам.

Посмотреть отчет: **Отчеты** → **Электронная коммерция** → **Промокоды**.

## ru/reports/promo-codes#caseКакие задачи может решать отчет

Отсортируйте данные в отчете по количеству покупок.

Отсортируйте данные в отчете по доходу.

## ru/reports/promo-codes#nessУсловия для получения отчета

Для формирования отчета необходимо использовать возможности сервиса по учету и анализу данных электронной коммерции — [Ecommerce](ru/data/e-commerce). При первой передаче данных отчет станет доступен в течение нескольких часов.

## ru/reports/promo-codes#dataСтруктура и настройка отчета

Данные сгруппированы по промокоду. Если вы передаете данные в разной валюте, в отчете вы можете [выбрать одну из них](ru/reports/report-general#currency). При выборе валюты значения денежных метрик пересчитываются в соответствии с курсом конвертации, который был днем ранее совершения дохода.

О том, как настроить отчет, смотрите в разделе [Настройки отчета](ru/reports/report-general#set-report).
