# Отчет «Параметры событий»

- [Какие задачи может решать отчет](ru/reports/event-params#case)
- [Структура и настройки отчета](ru/reports/event-params#data)

Посмотреть отчет: **Отчеты** → **Содержание** → **Параметры событий**.

## ru/reports/event-params#caseКакие задачи может решать отчет

Вы можете разметить интересующие вас события и цели параметрами, чтобы определить наиболее эффективный вариант. Для этого передайте события методом [params](ru/objects/params-method) или цели как [«JavaScript-события»](ru/general/goal-js-event), добавив туда параметры, используя объект [params](ru/code/counter-initialize#param-params).

Пример отправки данных:

```
<form action="">
    ...
    <input type="button" onclick="ym(XXXXXXXX, 'reachGoal', 'TARGET_NAME', {group: 'A'}); return true;" value="Заказать"/>
</form>
```

где XXXXXXXX — номер счетчика.

Вы можете передавать данные о пользователях в событиях и целях, используя параметры, чтобы лучше анализировать поведение посетителей.

Пример отправки данных:

```
ym(XXXXXXXX, 'params', {user_data: {authorized_user: 'yes', loyalty_program: 'bonus', bonus_quantity: '101', discount: '15'}}); 
```

где XXXXXXXX — номер счетчика.

Вы можете узнать, на каких страницах чаще достигаются «Java-Script события» и оценить их эффективность.

## ru/reports/event-params#dataСтруктура и настройки отчета

Отчет содержит дополнительную информацию о действиях на сайте:

- информация, которая не собирается Метрикой [по умолчанию](ru/general/how-it-works#data_extract_pull) и известна только владельцу сайта (например, отзыв на сайте);
- информация о действиях авторизованных на сайте посетителей, известная сайту;
- информация, которую можно получить из браузера посетителя с помощью JavaScript.

Данные в отчете сгруппированы по параметрам, которые вы передаете.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.

Примечание

Если вы передаете параметры с аргументом метода [reachGoal](ru/objects/reachgoal), но JavaScript-цель не заведена для счетчика или заведена только внутри составной цели — данные не попадут в отчет «Параметры событий».

Создайте отдельную JavaScript-цель в интерфейсе счетчика или используйте другие методы для передачи параметров: [params](ru/objects/params-method), [extLink](ru/objects/extlink), [file](ru/objects/file) или [hit](ru/objects/hit).
