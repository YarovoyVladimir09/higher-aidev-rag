Посмотреть отчет: **Отчеты** → **Содержание** → **Параметры посетителей**.

## ru/reports/user-params#caseКакие задачи может решать отчет

Например, можно разделить статистику по партнерам и обычным посетителям. Для этого передайте в Метрику информацию о статусе посетителя, как показано в [примере](ru/data/user-params-example#example2).

Например, вы можете добавить в форму поле с важной для вас информацией и передавать ее

в Метрику, как показано в [примере](ru/data/user-params-example#example3).

## ru/reports/user-params#nessУсловия для получения отчета

Для формирования отчета необходимо [передавать параметры посетителей вашего сайта в Метрику](ru/data/user-params-data) с помощью JavaScript API.

Примечание

Отправленные в Метрику параметры хранятся два года с момента последней загрузки. Когда срок хранения закончится, данные перестанут отображаться в отчете.

## ru/reports/user-params#dataСтруктура и настройки отчета

Отчет может содержать информацию, которую Метрика не собирает [по умолчанию](ru/general/how-it-works#data_extract_pull):

- известную только владельцу сайта (например, класс обслуживания пользователя сайта);
- о действиях авторизованных на сайте посетителей, известную сайту.

Данные в отчете сгруппированы по параметрам, которые вы передаете.

Отчет не поддерживает стандартные настройки Яндекс Метрики. Данные, представленные в отчете, можно добавлять в другие отчеты Метрики с помощью [сегментации](ru/general/segmentation).
