# Отчет «Популярные категории и бренды»

- [Какие задачи может решать отчет](ru/reports/popular-brands#case)
- [Условия для получения отчета](ru/reports/popular-brands#ness)
- [Структура и настройка отчета](ru/reports/popular-brands#data)
- [Узнайте больше](ru/reports/popular-brands#uznajte-bolshe)

Отчет содержит данные о категориях товаров и брендах, которые пользуются наибольшим спросом у посетителей сайта.

Посмотреть отчет: **Отчеты** → **Электронная коммерция** → **Популярные категории и бренды**.

## ru/reports/popular-brands#caseКакие задачи может решать отчет

Популярность можно определять по количеству просмотров. Поэтому отсортируйте данные по просмотрам товаров.

Для этого уберите из списка группировок **Категория товара, ур. 1**: нажмите кнопку **Группировки** и удалите группировку. Затем отсортируйте данные по просмотрам товаров.

Для этого уберите из списка группировок **Категория товара, ур. 1**: нажмите кнопку **Группировки** и удалите группировку. Затем отсортируйте данные по метрике **Товаров куплено**.

## ru/reports/popular-brands#nessУсловия для получения отчета

Для формирования отчета необходимо использовать возможности сервиса по учету и анализу данных электронной коммерции — [Ecommerce](ru/data/e-commerce). При первой передаче данных отчет станет доступен в течение нескольких часов.

## ru/reports/popular-brands#dataСтруктура и настройка отчета

Данные в отчете сгруппированы по категории, бренду и названию товара. Если вы передаете данные в разной валюте, в отчете вы можете [выбрать одну из них](ru/reports/report-general#currency). При выборе валюты значения денежных метрик пересчитываются в соответствии с курсом конвертации, который был днем ранее совершения дохода.

О том, как настроить отчет, смотрите в разделе [Настройки отчета](ru/reports/report-general#set-report).
