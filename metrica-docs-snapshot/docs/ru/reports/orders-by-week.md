# Отчет «Заказы по дням недели»

- [Какие задачи может решать отчет](ru/reports/orders-by-week#case)
- [Структура и настройка отчета](ru/reports/orders-by-week#data)

Отчет показывает, как меняется покупательское поведение на вашем сайте в зависимости от дня недели.

Для просмотра разных метрик на графике используйте кнопку . Время соответствует часовому поясу, который вы указали в настройках счетчика. Для получения более точной статистики рекомендуем использовать увеличенный интервал дат.

Посмотреть отчет: **Отчеты** → **Электронная коммерция** → **Заказы по дням недели**.

## ru/reports/orders-by-week#dataСтруктура и настройка отчета

Данные в отчете сгруппированы по дневным интервалам в течение недели. Можно просмотреть статистику по визитам и действиям пользователя, которые начались в один из таких интервалов.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
