# Отчет «Adfox, показы»

- [Какие задачи может решать отчет](ru/reports/adfox-impressions#case)
- [Условия для получения отчета](ru/reports/adfox-impressions#ness)
- [Структура и настройки отчета](ru/reports/adfox-impressions#data)

Посмотреть отчет: **Отчеты** → **Монетизация** → **Adfox, показы**.

## ru/reports/adfox-impressions#caseКакие задачи может решать отчет

С помощью отчета вы можете определить вид кампании, которая приносит наибольший доход.

## ru/reports/adfox-impressions#nessУсловия для получения отчета

Для просмотра отчета [включите показ отчетов по Adfox и укажите счетчик Метрики](ru/sources/adfox-settings#activate) в Adfox.

По умолчанию доступ к просмотру отчетов группы «Монетизация» ограничен. Вы можете [управлять правами доступа](ru/sources/adfox-settings#access).

## ru/reports/adfox-impressions#dataСтруктура и настройки отчета

Данные в отчете объединены в группировки:

- source: ru/_includes/popup/id-adfox/adfox-level-1.md Adfox, ур. 1 — тип монетизации (гарантия, динамическая монетизация, промо или загрузки по умолчанию). endsource: ru/_includes/popup/id-adfox/adfox-level-1.md
- source: ru/_includes/popup/id-adfox/adfox-level-2.md Adfox, ур. 2 — модели продаж (прямые продажи, РСЯ, технология Header Bidding, Google). endsource: ru/_includes/popup/id-adfox/adfox-level-2.md
- source: ru/_includes/popup/id-adfox/adfox-level-3.md Adfox, ур. 3 — параметры рекламных мест и кампаний (монетизатор Header bidding, РСЯ pageID, Название кампании для Прямых продаж, настройки кампаний Google). endsource: ru/_includes/popup/id-adfox/adfox-level-3.md
- source: ru/_includes/popup/id-adfox/adfox-level-4.md Adfox, ур. 4 — формат рекламы (баннер или блок). endsource: ru/_includes/popup/id-adfox/adfox-level-4.md

Метрики в отчете:

- source: ru/_includes/popup/id-adfox/impression.md Показы Adfox — зафиксированный системой показ рекламного баннера пользователю. endsource: ru/_includes/popup/id-adfox/impression.md
- source: ru/_includes/popup/id-adfox/estimated-revenue.md Суммарный доход Adfox — расчетный суммарный доход от показов рекламы. endsource: ru/_includes/popup/id-adfox/estimated-revenue.md
- source: ru/_includes/popup/id-adfox/ecpm.md eCPM (Effective cost per mille) Adfox — стоимость одной тысячи отрисовок рекламных блоков. В рублях без НДС. endsource: ru/_includes/popup/id-adfox/ecpm.md
- source: ru/_includes/popup/id-adfox/rpm.md RPM (Revenue per mille) Adfox — расчетная стоимость одной тысячи запросов кода Adfox, включая те запросы, по которым не удалось подобрать рекламу. В рублях без НДС. endsource: ru/_includes/popup/id-adfox/rpm.md
- source: ru/_includes/popup/id-adfox/revenue-visit.md Расчетный доход визита Adfox — средний расчетный доход на один визит. endsource: ru/_includes/popup/id-adfox/revenue-visit.md

Вы можете добавить эти группировки в другие отчеты — только сразу все четыре уровня. Если вы хотите изменить порядок группировок, то группировки Adfox, ур. 1 — 4 будут размещаться всегда после остальных.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
