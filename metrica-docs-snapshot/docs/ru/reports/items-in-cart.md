# Отчет «Товары в корзине»

- [Какие задачи может решать отчет](ru/reports/items-in-cart#case)
- [Условия для получения отчета](ru/reports/items-in-cart#ness)
- [Структура и настройка отчета](ru/reports/items-in-cart#data)
- [Узнайте больше](ru/reports/items-in-cart#uznajte-bolshe)

Отчет содержит информацию по каждому наименованию товара, который был добавлен в корзину посетителем сайта.

Посмотреть отчет: **Отчеты** → **Электронная коммерция** → **Товары в корзине**.

## ru/reports/items-in-cart#nessУсловия для получения отчета

Для формирования отчета необходимо использовать возможности сервиса по учету и анализу данных электронной коммерции — [Ecommerce](ru/data/e-commerce). При первой передаче данных отчет станет доступен в течение нескольких часов.

## ru/reports/items-in-cart#dataСтруктура и настройка отчета

Данные сгруппированы по названию товаров, которые вы передаете в Метрику. Если вы передаете данные в разной валюте, в отчете вы можете [выбрать одну из них](ru/reports/report-general#currency). При выборе валюты значения денежных метрик пересчитываются в соответствии с курсом конвертации, который был днем ранее совершения дохода.

О том, как настроить отчет, смотрите в разделе [Настройки отчета](ru/reports/report-general#set-report).
