# Отчет «Источники заказов»

- [Какие задачи может решать отчет](ru/reports/orders#case)
- [Условия для получения отчета](ru/reports/orders#ness)
- [Структура и настройка отчета](ru/reports/orders#data)
- [Узнайте больше](ru/reports/orders#uznajte-bolshe)

Отчет может содержать информацию о доходности вашего сайта, например:

- количество покупок;
- доход со всех покупок;
- средний показатель дохода покупки и визита;
- источники, из которых поступают более прибыльные заказы.

Посмотреть отчет: **Отчеты** → **Электронная коммерция** → **Источники заказов**.

## ru/reports/orders#caseКакие задачи может решать отчет

Для удобства отсортируйте данные по доходу.

## ru/reports/orders#nessУсловия для получения отчета

Для формирования отчета необходимо использовать возможности сервиса по учету и анализу данных электронной коммерции — [Ecommerce](ru/data/e-commerce). При первой передаче данных отчет станет доступен в течение нескольких часов.

## ru/reports/orders#dataСтруктура и настройка отчета

Данные в отчете объединены по [источникам трафика](ru/sources/sources-summary). Если вы передаете данные в разной валюте, в отчете вы можете [выбрать одну из них](ru/reports/report-general#currency). При выборе валюты значения денежных метрик пересчитываются в соответствии с курсом конвертации, который был днем ранее совершения дохода.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
