# Отчет «Параметры визитов»

- [Какие задачи может решать отчет](ru/reports/visit-params#case)
- [Условия для получения отчета](ru/reports/visit-params#ness)
- [Структура и настройки отчета](ru/reports/visit-params#data)

Посмотреть отчет: **Отчеты** → **Содержание** → **Параметры визитов**.

## ru/reports/visit-params#caseКакие задачи может решать отчет

Например, вы можете посмотреть, как цвет кнопки **Купить** влияет на конверсию по ранее созданной цели «Переход в корзину». Для этого:

1. Передайте в Метрику параметры, отвечающие за цвет кнопки, как описано в [примере](ru/data/visit-params-example#ab-test).
2. В отчете используйте цель «Переход в корзину».

Передайте в Метрику параметры, отвечающие за статус посетителя, как описано в [примере](ru/data/visit-params-example#auth).

## ru/reports/visit-params#nessУсловия для получения отчета

Для формирования отчета необходимо [передавать параметры событий в Метрику](ru/data/visit-params-data) с помощью JavaScript API.

## ru/reports/visit-params#dataСтруктура и настройки отчета

Отчет содержит дополнительную информацию о визитах посетителей:

- информация, которая не собирается Метрикой [по умолчанию](ru/general/how-it-works#data_extract_pull) и известна только владельцу сайта (например, отзыв на сайте);
- информация о действиях авторизованных на сайте посетителей, известная сайту;
- информация, которую можно получить из браузера посетителя с помощью JavaScript.

Данные в отчете сгруппированы по параметрам, которые вы передаете.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
