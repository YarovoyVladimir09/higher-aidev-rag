# Отчет «Чаты по мессенджерам и меткам»

- [Условия для получения отчета](ru/reports/chat-messengers#ness)
- [Структура и настройка отчета](ru/reports/chat-messengers#data)
- [Узнайте больше](ru/reports/chat-messengers#uznajte-bolshe)

Отчет поможет определить чаты по мессенджерам и меткам.

Посмотреть отчет: **Отчеты** → **Чаты** → **Чаты по мессенджерам и меткам**.

## ru/reports/chat-messengers#nessУсловия для получения отчета

Чтобы получить информацию, необходимо настроить [передачу данных о чатах](ru/data/chat) в Метрику.

## ru/reports/chat-messengers#dataСтруктура и настройка отчета

Данные сгруппированы по условиям: мессенджер, отвечен ли чат, метка. Метрики, представленные в отчете, можно использовать как [условие сегментации](ru/general/segmentation) по визитам посетителей.

О том, как настроить отчет, смотрите в разделе [Настройки отчета](ru/reports/report-general#set-report).
