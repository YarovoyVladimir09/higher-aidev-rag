**Средние показатели по рынку** — это аналитический инструмент, который позволяет сравнивать ключевые показатели вашего сайта с аналогичными средними показателями сайтов ближайших участников рынка.

С помощью этого инструмента вы можете:

- Оценить показатели сайта относительно средних показателей сайтов ближайших участников рынка.
- Найти наибольший потенциал и точки роста в развитии сайта и источников трафика.
- Оценить свое положение по сравнению со средними показателями по рынку.
- Корректировать стратегию развития относительно потенциала рынка.

**Средние показатели по рынку** доступны в формате виджетов, собранных на [дашборде](ru/reports/report-widget).

## ru/reports/benchmarks#how-it-worksКак это работает

Алгоритмы Метрики находят ближайших участников рынка со схожей аудиторией, учитывая географию и объём трафика и предоставляют агрегированные обезличенные данные, которые отображаются в формате виджетов на дашборде.

Вы можете [добавлять виджеты](ru/reports/report-widget#add) с этими данными на любые свои дашборды.

### ru/reports/benchmarks#metricsДоступные данные

В виджетах сравнения **Средних показателей по рынку** представлены следующие метрики и группировки:

**Метрики**

- **Визиты** — сравнение общего количества визитов на вашем сайте с медианным значением визитов за тот же период у ближайших участников рынка.
- **Время на сайте** — сравнение среднего времени, которое пользователи проводят на вашем сайте и у ближайших участников рынка.
- **Глубина просмотра** — сравнение среднего количества страниц, которые просматривают пользователи на вашем сайте и у ближайших участников рынка.
- **Отказы** — сравнение показателя отказов на вашем сайте со средним показателем отказов у ближайших участников рынка.

**Группировки**

- **Группировка по типам источников трафика**. Позволяет сравнить свои источники трафика по количеству визитов и показателям вовлеченности с ближайшими участниками рынка.
- **Группировка по типам устройств**. Позволяет сравнить показатели на разных типах устройств по количеству визитов и вовлеченности с ближайшими участниками рынка.

### ru/reports/benchmarks#workРабота с дашбордом

Чтобы использовать дашборд:

1. Перейдите в раздел **Дашборды** в боковом меню слева.
2. Откройте дашборд **Средние показатели по рынку**.

На дашборде представлен набор из готовых [специальных виджетов](ru/reports/report-widget#report-widget-benchmarks) сравнения.

Дашборд можно обновлять: добавлять на него любые виджеты и группы виджетов к уже установленным. При этом порядок системных виджетов сохранится.

## ru/reports/benchmarks#unavailableПочему инструмент может быть недоступен

**Опция «Получать доступ к отчётам по рынку» не была активна**

**Алгоритм Метрики не смог однозначно связать счетчик с доменом**

- Счетчик установлен на разных сайтах.
- На одном домене установлено несколько разных счетчиков, каждый из которых видит только часть данных. Для корректного подбора ближайших участников рынка убедитесь, что на всех страницах одного домена используется один счетчик, и дождитесь обновления данных.

**Не хватает данных**

**Мало ближайших участников рынка**

Метрика не смогла подобрать достаточное количество ближайших участников рынка для вашего сайта. Отправьте список своих ближайших участников рынка, чтобы алгоритм смог дообучиться на точных данных. В поле Домены укажите домены ближайших участников рынка.

**Новый сайт**

**Сайт из редкой индустрии**

Внимание

Средние показатели по рынку недоступны пользователям, для которых применен фильтр доступа.

Данные обновляются еженедельно по вторникам.

В статистику попадают средние показатели только тех сайтов, которые согласились делиться своими обезличенными данными с рынком (опция [Получать доступ к отчетам по рынку](ru/general/counter-general#benchmarks) в настройках счетчика).

На данный момент возможность интеграции данных через API находится в разработке. В будущих обновлениях планируется добавить эту функциональность, что позволит вам использовать данные в сторонних аналитических системах и инструментах.

С началом новой недели данные могут измениться из-за обновления состава ближайших участников рынка и пересчета средних значений.

Алгоритмы Метрики каждый вторник обновляют состав ближайших участников рынка в зависимости от рыночных изменений. Это позволяет сравнивать показатели вашего сайта со всегда актуальной выборкой, отражая последние изменения на рынке.
