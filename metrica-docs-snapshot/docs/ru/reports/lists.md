# Отчет «Списки товаров»

- [Какие задачи может решать отчет](ru/reports/lists#case)
- [Условия для получения отчета](ru/reports/lists#ness)
- [Структура и настройка отчета](ru/reports/lists#data)
- [Узнайте больше](ru/reports/lists#uznajte-bolshe)

Отчёт показывает просмотры, клики и долю посетителей, которые кликнули по товару в списке на вашем сайте. Также помогает оценивать эффективность товаров в определенных списках на определенных позициях.

Посмотреть отчет: **Отчеты** → **Электронная коммерция** → **Списки товаров**.

## ru/reports/lists#caseКакие задачи может решать отчет

Используйте показатель **Количество посетителей, посмотревших товар в списке**.

Обратите внимание на показатель **Просмотры товаров в списке**.

Используйте показатели **Количество посетителей, кликнувших по товару** и **Доля посетителей, кликнувших по товару**.

## ru/reports/lists#nessУсловия для получения отчета

Для формирования отчета необходимо использовать возможности сервиса по учету и анализу данных электронной коммерции — [Ecommerce](ru/data/e-commerce). При первой передаче данных отчет станет доступен в течение нескольких часов.

## ru/reports/lists#dataСтруктура и настройка отчета

Данные в отчете сгруппированы по спискам товаров, которые вы передаете в Метрику.

О том, как настроить отчет, смотрите в разделе [Настройки отчета](ru/reports/report-general#set-report).
