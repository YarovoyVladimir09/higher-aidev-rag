# Отчеты группы «Рекламная сеть Яндекса»

- [Условия для получения отчета](ru/reports/partner#ness)
- [Метрики, доступные в отчетах](ru/reports/partner#metrics)
- [Отчеты группы](ru/reports/partner#reports)

С помощью этой группы отчетов владельцы сайтов, участвующие в Рекламной сети Яндекса, могут глубже анализировать эффект от показов рекламы и увеличивать доход. Например, выявлять самые выгодные источники трафика — вплоть до поискового запроса, — отслеживать эффективность каждого раздела сайта, а также контролировать средний доход на одного посетителя.

Внимание

Все данные обновляются в течение суток. Данные о доходах, которые представлены в Яндекс Метрике, могут отличаться от данных в интерфейсе Рекламной сети Яндекса в пределах 10%. Если на вашем сайте блоки Рекламной сети Яндекса размещены во фрейме, то данные могут не отображаться в отчетах.

## ru/reports/partner#nessУсловия для получения отчета

Для просмотра отчета [включите показ отчетов и укажите счетчик Метрики](ru/sources/yan-settings#activate) в интерфейсе Рекламной сети Яндекса.

По умолчанию доступ к просмотру отчетов группы «Монетизация» ограничен. Вы можете [управлять правами доступа](ru/sources/yan-settings#access).

## ru/reports/partner#metricsМетрики, доступные в отчетах

**ARPU (Average revenue per user)** — средний доход на одного посетителя сайта.

**eCPM (Effective cost per mille)** — стоимость одной тысячи отрисовок рекламного блока.

**CPMV (Cost per mille viewable ads)** — стоимость одной тысячи показов рекламного блока с учетом проверки видимости рекламных блоков.

**RPM (Revenue per mille)** — стоимость одной тысячи запросов всех блоков, включая те, по которым не удалось подобрать рекламу.

**Запросы** — запросы кода вызова рекламы к, например, RTB-системе Яндекса.

**Отрисовки** — запросы к, например, RTB-системе Яндекса, по которым удалось успешно подобрать рекламу для показа (были объявления или баннеры, которые преодолели [порог CPM](https://yandex.ru/support/partner2/web/)).

**Отрисовки на посетителя** — среднее количество отрисовок рекламы на одного посетителя сайта за выбранный период отчета.

**Показы** — это отображение рекламного блока, объявления или баннера на странице сайта ее посетителю. В Рекламной сети Яндекса показы объявлений определяются с учетом [проверки видимости рекламных блоков](https://yandex.ru/support/partner2/technologies/ads-visibility-check.html).

**Расчетный доход** — ориентировочная стоимость показов рекламы, состоявшихся в выбранном периоде отчета. В рублях без НДС.

**Процент видимости** — соотношение числа показов к числу отрисовок.

## ru/reports/partner#reportsОтчеты группы

Отчеты доступны в пункте меню **Отчеты** → **Монетизация** → **Рекламная сеть Яндекса**. В группу входят следующие отчеты:

**РСЯ, источники**

**РСЯ, география**

**РСЯ, устройства**

**РСЯ, браузеры**

**РСЯ, наличие блокировщиков рекламы**

**РСЯ, страницы с рекламными событиями**

Вы можете формировать большинство отчетов с помощью [сегментации](ru/general/segmentation), целей, добавления группировок и метрик.
