# Отчет «Посещаемость по месяцам»

- [Какие задачи может решать отчет](ru/reports/visits-by-month#case)
- [Структура и настройка отчета](ru/reports/visits-by-month#data)

Отчет показывает распределение трафика на сайте по месяцам. Время соответствует часовому поясу, который вы указали в настройках счетчика.

Посмотреть отчет: **Отчеты** → **Аудитория** → **Посещаемость по месяцам**.

## ru/reports/visits-by-month#caseКакие задачи может решать отчет

- Узнать, в какие месяцы года посещаемость сайта достигает максимума

## ru/reports/visits-by-month#dataСтруктура и настройка отчета

Данные в отчете сгруппированы по месяцам в течение года. Можно просмотреть статистику по визитам, которые начались в один из месяцев.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
