# Трафик по минутам

- [Какие задачи может решать отчет](ru/reports/traffic-min#case)
- [Структура и настройки отчета](ru/reports/traffic-min#data)

Отчет показывает общее количество *просмотров* страниц сайта, а также среднее число просмотров в минуту за выбранный период времени. Эта информация может сообщать о степени нагрузки на сайт.

Посмотреть отчет: **Отчеты** → **Мониторинг** → **Трафик по минутам**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/traffic_by_minute?metric=ym%3Apv%3ApageviewsPerMinute&sort=-ym%3Apv%3Apageviews&period=month&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/reports/traffic-min#caseКакие задачи может решать отчет

Кроме общей информации по сайту, вы можете посмотреть статистику по отдельному разделу и странице сайта. Для этого нужно задать [сегмент](ru/general/segmentation) с интересующим вас адресом:

1. В группе условий **Просмотры, в которых** нажмите кнопку .
2. Выберите условие **Просмотр URL** и в строке укажите адрес страницы.
