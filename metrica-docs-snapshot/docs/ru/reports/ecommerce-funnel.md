# Отчет «Ecommerce-воронка»

- [Какие задачи может решать отчет](ru/reports/ecommerce-funnel#case)
- [Условия для получения отчета](ru/reports/ecommerce-funnel#ness)
- [Структура и настройка отчета](ru/reports/ecommerce-funnel#data)
- [Узнайте больше](ru/reports/ecommerce-funnel#uznajte-bolshe)

Отчет показывает достижение пользователем определенных шагов относительно всех посетителей.

Конверсии рассчитываются из отношения просматриваемого шага к первому шагу посетителей. По умолчанию первым шагом считается показатель **Все посетители**.

Важно

Каждый шаг в отчете считается независимо от других и равен отношению посетителя конкретного шага ко всем посетителям.

Посмотреть отчет: **Отчеты** → **Электронная коммерция** → **Ecommerce-воронка**.

## ru/reports/ecommerce-funnel#nessУсловия для получения отчета

Для формирования отчета необходимо использовать возможности сервиса по учету и анализу данных электронной коммерции — [Ecommerce](ru/data/e-commerce). При первой передаче данных отчет станет доступен в течение нескольких часов.

## ru/reports/ecommerce-funnel#dataСтруктура и настройка отчета

Данные в отчете сгруппированы по визитам. Вы можете настроить дату, выбрать группировку по параметрам и шаги, которые должны отображаться в таблице.

С помощью поля **Группировки** можно выбрать до 7 необходимых группировок или оставить поле пустым. Выбирая группировки и меняя их порядок в списке, можно настроить отображение строк в таблице — изменить вложенность элементов в строках и отображение по умолчанию в графике.

В поле **Столбцы** вы можете настроить отображение отдельных шагов.
