# Отчет «Заказы по месяцам»

- [Какие задачи может решать отчет](ru/reports/orders-by-month#case)
- [Структура и настройка отчета](ru/reports/orders-by-month#data)

Отчет показывает, как меняется покупательское поведение на вашем сайте в зависимости от месяца года.

Для просмотра разных метрик на графике используйте кнопку . Время соответствует часовому поясу, который вы указали в настройках счетчика. Для получения более точной статистики рекомендуем использовать увеличенный интервал дат.

Посмотреть отчет: **Отчеты** → **Электронная коммерция** → **Заказы по месяцам**.

## ru/reports/orders-by-month#dataСтруктура и настройка отчета

Данные в отчете сгруппированы по месяцам в течение года. Можно просмотреть статистику по визитам и действиям пользователя, которые начались в один из месяцев.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
