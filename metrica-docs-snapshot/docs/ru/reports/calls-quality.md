# Отчет «Качество обработки звонков»

- [Какие задачи может решать отчет](ru/reports/calls-quality#case)
- [Условия для получения отчета](ru/reports/calls-quality#ness)
- [Структура и настройка отчета](ru/reports/calls-quality#data)

Отчет поможет определить, насколько качественно обрабатываются звонки на основе специальных метрик. Например, вы сможете увидеть длительность ожидания ответа на звонок, длительность разговора, а так же был ли пропущен звонок.

Посмотреть отчет: **Отчеты** → **Звонки** → **Качество обработки звонков**.

## ru/reports/calls-quality#caseКакие задачи может решать отчет

Чтобы получить эту информацию, [создайте цель](ru/general/goals) и [используйте ее в отчете](ru/reports/goals).

## ru/reports/calls-quality#nessУсловия для получения отчета

Чтобы получить информацию, необходимо [настроить передачу данных](ru/data/calls) о поступающих к вам звонках в Метрику.

## ru/reports/calls-quality#dataСтруктура и настройка отчета

Отчет содержит информацию только о динамических звонках. Метрики, представленные в отчете, можно использовать как [условие сегментации](ru/general/segmentation) по визитам посетителей.

Обратите внимание, что отчет не поддерживает:

- source: ru/_includes/popup/id-popup/not-sup3.md [атрибуцию](ru/reports/attribution-model); endsource: ru/_includes/popup/id-popup/not-sup3.md
- source: ru/_includes/popup/id-popup/not-sup4.md настройки [статистической достоверности](ru/reports/false-data). endsource: ru/_includes/popup/id-popup/not-sup4.md
