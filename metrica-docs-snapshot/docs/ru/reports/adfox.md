# Отчеты группы «Adfox»

- [Метрики, доступные в отчетах](ru/reports/adfox#metrics)
- [Группировки в отчетах](ru/reports/adfox#groups)
- [Отчеты группы](ru/reports/adfox#reports)

С помощью этой группы отчетов владельцы сайтов, у которых настроена реклама через Adfox, могут глубже анализировать эффект от показов рекламы и увеличивать доход. Например, выявлять самые выгодные источники трафика — вплоть до поискового запроса, — отслеживать эффективность каждого раздела сайта, а также контролировать средний доход на одного посетителя.

Внимание

Данные о доходах, представленные в Яндекс Метрике, могут отличаться от данных в интерфейсе Adfox в пределах 10%. Если на вашем сайте рекламные блоки размещены во фрейме, то данные могут не отображаться в отчетах.

## ru/reports/adfox#metricsМетрики, доступные в отчетах

- Запросы кода Adfox — запросы кода Adfox со страниц, по которым был ответ от сервера Adfox (загрузки баннеров и загрузки по умолчанию).
- Показы Adfox — зафиксированный системой показ рекламного баннера пользователю.
- Загрузки по умолчанию — количество запросов кода, по которым были произведены показы баннеров по умолчанию. Баннеры по умолчанию показываются в том случае, если нет для показа баннеров из коммерческих рекламных кампаний в силу настроек размещения, ограничений по количеству показов, скорости открутки, таргетирований.
- Доля загрузок по умолчанию Adfox — отношение числа загрузок по умолчанию к числу запросов кода Adfox.
- Клики Adfox — количество кликов по рекламным баннерам.
- Процент видимости Adfox — доля засчитанных показов в общем количестве отрисовок.
- Отрисовки Adfox — запросы кода, по которым была засчитана загрузка баннера.
- Отрисовки на посетителя Adfox — среднее количество загрузок баннеров Adfox (в том числе РСЯ) на одного посетителя.
- Отрисовки на визит Adfox — среднее количество загрузок баннеров Adfox (в том числе РСЯ) на один визит.
- Отрисовки на просмотр Adfox — cреднее количество загрузок баннеров Adfox (в том числе РСЯ) на один просмотр страницы.
- CPMV (Cost per mille viewable ads) Adfox — расчетная cтоимость одной тысячи показов. В рублях без НДС.
- eCPM (Effective cost per mille) Adfox — стоимость одной тысячи отрисовок рекламных блоков. В рублях без НДС.
- RPM (Revenue per mille) Adfox — расчетная стоимость одной тысячи запросов кода Adfox, включая те запросы, по которым не удалось подобрать рекламу. В рублях без НДС.
- ARPU (Average revenue per user) Adfox — средний расчетный доход от показов рекламы на одного посетителя.
- Суммарный доход Adfox — расчетный суммарный доход от показов рекламы.
- Расчетный доход на посетителя Adfox — средний размер вознаграждения за показ рекламных блоков в расчете на одного посетителя. В рублях без НДС.
- Расчетный доход визита Adfox — средний расчетный доход на один визит.
- Расчетный доход просмотра Adfox — средний размер вознаграждения в расчете на один просмотр страницы. В рублях без НДС.
- Расчетный доход, Прямые продажи — ориентировочная стоимость показов рекламы, размещенной на площадке напрямую.
- Расчетный доход, РСЯ — суммарный доход за показы рекламных блоков РСЯ. В рублях без НДС.
- Расчетный доход, Google — ориентировочная стоимость показов рекламных блоков Google.
- Расчетный доход, Header Bidding — ориентировочная стоимость показов рекламных баннеров Header Bidding.
- Adfox, количество событий `{N}` — сколько раз выполнилось событие, которое в интерфейсе Adfox сохранено под номером `N`.

## ru/reports/adfox#groupsГруппировки в отчетах

- Сайт — адрес сайта, с которого перешел посетитель на ваш сайт.
- Раздел — раздел сайта, с которого перешел посетитель на ваш сайт.
- Площадка — формат рекламного блока.
- Adfox, ур. 1 — тип монетизации (гарантия, динамическая монетизация, промо или загрузки по умолчанию).
- Adfox, ур. 2 — модели продаж (прямые продажи, РСЯ, технология Header Bidding, Google).
- Adfox, ур. 3 — параметры рекламных мест и кампаний (монетизатор Header bidding, РСЯ pageID, Название кампании для Прямых продаж, настройки кампаний Google).
- Adfox, ур. 4 — формат рекламы (баннер или блок).
- Источник трафика — тип источника перехода на ваш сайт, например, переходы из поисковых систем.
- Источник трафика (детально) — второй уровень источника перехода (сайт, площадка, мессенджер и т. д.).
- Владелец — пользователь с ролью **Владелец сайта** в интерфейсе Adfox.
- Параметр рекламной кампании (puid) — название таргетинга в настройках кампании. Например, «тип пользователя», если настроено таргетирование для авторизованных и неавторизованных пользователей.
- Значение параметра рекламной кампании — значение таргетинга, например, «авторизованный пользователь» или «неавторизованный пользователь» при настроенном параметре «тип пользователя».
- Страна — страна, в которой происходит показ рекламной кампании.
- Область — административная единица, область, в которой происходит показ рекламной кампании. Может не определяться.
- Город — город, в котором происходит показ рекламной кампании.
