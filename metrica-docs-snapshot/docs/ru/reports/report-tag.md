# Отчет по группе счетчиков

Внимание

Отчет доступен только владельцу аккаунта и пользователям с [представительским доступом](ru/general/access).

Сервис позволяет формировать отчеты по данным нескольких счетчиков, для которых [установлена одна метка](ru/general/tag-counter).

В таких отчетах доступны основные возможности Яндекс Метрики (например, сегментация, настройка группировок и метрик, атрибуции), но не доступны данные по целям, [данные Вебвизора](ru/webvisor/info) и Карт. При формировании общего отчета посетитель, зашедший на все отслеживаемые сайты в течение дня, будет учтен Яндекс Метрикой только один раз.

Примечание

Отчеты формируются только по созданным вами меткам (не по системным).

Чтобы сформировать отчет для нескольких счетчиков:

1. На странице списка счетчиков установите одну метку для счетчиков, по которым хотите получить статистику.
2. Перейдите к отчету: Со страницы списка счетчиков — выберите установленную метку из списка меток (кнопка **Все метки**). Откроется страница с суммарными данными по выбранным счетчикам. Чтобы перейти к отчетам, нажмите кнопку **Статистика по метке**. Со страницы отчета другого счетчика — выберите из выпадающего списка счетчиков группу счетчиков с установленной меткой (выделяется, как ссылка).
