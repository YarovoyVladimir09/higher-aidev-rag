## ru/reports/monetization#activateКак подключить отчеты

1. В [интерфейсе Рекламной сети Яндекса](https://partner2.yandex.ru) перейдите к списку площадок: **Продукты** → **Тематические площадки** или **Продукты** → **Поисковые площадки**.
2. Выберите из списка нужную площадку и нажмите кнопку **Редактировать**.
3. На вкладке **Общие** включите опцию **Показывать отчеты по РСЯ в Метрике**.
4. В поле **Счетчики Метрики** укажите номер вашего счетчика и сохраните изменения.

1. В [интерфейсе Рекламной сети Яндекса](https://partner2.yandex.ru) перейдите к списку ресурсов: **Продукты** → **Ресурсы**.
2. Выберите из списка нужный ресурс и нажмите кнопку **Редактировать**.
3. На вкладке Общие включите опцию **Показывать отчеты по РСЯ в Метрике**.
4. В поле **Счетчики Метрики** укажите номер вашего счетчика и сохраните изменения.

Вам будет доступна статистика по видеоблокам [InStream](https://yandex.ru/support/partner2/video/products-instream/about.html), размещенным в плеере Яндекса, а также по [InPage-блокам](https://yandex.ru/support/partner2/video/).

1. В [Adfox](https://adfox.yandex.ru/promo) перейдите на страницу **Настройки** → **Системные** → **Счетчики Яндекс Метрики**.
2. В поле укажите номер вашего счетчика и сохраните изменения.

Примечание

Данные в отчетах группы «Монетизация» начинают отображаться в Яндекс Метрике в течение суток после того, как вы подключили счетчик в интерфейсе Рекламной сети Яндекса или Adfox.

Вы можете пользоваться отчетами, если у вас есть [гостевой доступ](ru/general/access) на редактирование счетчика или [представительский доступ](ru/general/access). Если у вас гостевой доступ типа «Только просмотр», обратитесь к владельцу счетчика, чтобы он дал вам доступ к отчетам.

## ru/reports/monetization#accessКак дать доступ к отчетам другому пользователю Метрики

Внимание

Права доступа к группе отчетов «Монетизация» отображаются только для счетчиков, которые подключены в интерфейсе Рекламной сети Яндекса или Adfox.

Если у пользователя есть [доступ на редактирование](ru/general/access), то ему уже доступны отчеты группы «Монетизация».

Если у пользователя тип доступа «Только просмотр», измените его:

1. Перейдите на страницу **Настройка** → **Доступ**.
2. Нажмите значок напротив нужного пользователя.
3. Выберите тип прав с доступом к группе отчетов «Монетизация». Пользователь сможет просматривать отчеты, добавлять группировки и метрики из группы «Монетизация» в другие отчеты.

Дайте пользователю специальный доступ к вашему счетчику Метрики:

1. Перейдите на страницу **Настройка** → **Доступ**.
2. Нажмите кнопку **Добавить пользователя**.
3. В появившемся окне заполните поля.
4. Выберите тип прав с доступом к группе отчетов «Монетизация». Пользователь сможет просматривать отчеты, добавлять группировки и метрики из группы «Монетизация» в другие отчеты.

## ru/reports/monetization#delete-accessКак отменить доступ к отчетам

Измените тип доступа пользователя к счетчику Метрики:

1. Перейдите на страницу **Настройка** → **Доступ**.
2. Нажмите значок напротив нужного пользователя.
3. Выберите тип прав «Только просмотр: без Монетизации».
