# Отчет «Рекомендательный виджет, материалы»

- [Какие задачи может решать отчет](ru/reports/recommend-content#case)
- [Условия для получения отчета](ru/reports/recommend-content#ness)
- [Структура и настройки отчета](ru/reports/recommend-content#data)

Отчет показывает статистику по рекомендуемому материалу. Например, сколько посетителей в течение визита увидели рекомендуемый материал в виджете на страницах сайта. В отчете не учитываются просмотры страницы самого материала.

Посмотреть отчет: **Отчеты** → **Монетизация** → **Рекомендательный виджет** → **Рекомендательный виджет, материалы**.

## ru/reports/recommend-content#caseКакие задачи может решать отчет

Вы можете ориентироваться на метрики **Процент видимости материала** и **CTR материала**.

Вы можете ориентироваться на метрики **Клики по рекомендациям** и **CTR материала**.

## ru/reports/recommend-content#nessУсловия для получения отчета

Чтобы просматривать отчеты, [включите показ отчетов](ru/sources/yan-settings#activate) и укажите счетчик Метрики в интерфейсе Рекламной сети Яндекса.

По умолчанию доступ к просмотру отчетов группы «Монетизация» ограничен. Вы можете [управлять правами доступа](ru/sources/yan-settings#access).

## ru/reports/recommend-content#dataСтруктура и настройки отчета

Данные в отчете сгруппированы по URL рекомендуемого материала.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
