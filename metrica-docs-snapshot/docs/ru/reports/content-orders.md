# Отчет «Содержимое заказов»

- [Какие задачи может решать отчет](ru/reports/content-orders#case)
- [Условия для получения отчета](ru/reports/content-orders#ness)
- [Структура и настройка отчета](ru/reports/content-orders#data)
- [Узнайте больше](ru/reports/content-orders#uznajte-bolshe)

Отчет содержит детализированную информацию о заказах с сайта и товарах, входящих в состав отдельного заказа: количество товаров в каждом заказе, стоимость заказа и общая стоимость всех заказов, совершенных за выбранный период времени.

Посмотреть отчет: **Отчеты** → **Электронная коммерция** → **Содержимое заказов**.

## ru/reports/content-orders#caseКакие задачи может решать отчет

Для удобства отсортируйте данные по сумме покупки.

Для этого нужно выделить [сегмент](ru/general/segmentation):

1. В группе условий **для людей, у которых** нажмите кнопку .
2. Выберите условие **Технологии** → **Устройство** → **Смартфоны**.

## ru/reports/content-orders#nessУсловия для получения отчета

Для формирования отчета необходимо использовать возможности сервиса по учету и анализу данных электронной коммерции — [Ecommerce](ru/data/e-commerce). При первой передаче данных отчет станет доступен в течение нескольких часов.

## ru/reports/content-orders#dataСтруктура и настройка отчета

Данные в отчете сгруппированы по идентификатору покупки с детализацией до товара в заказе. Если вы передаете данные в разной валюте, в отчете вы можете [выбрать одну из них](ru/reports/report-general#currency). При выборе валюты значения денежных метрик пересчитываются в соответствии с курсом конвертации, который был днем ранее совершения дохода.

Отчет поддерживает только [сегментацию](ru/reports/report-general#segmentation).
