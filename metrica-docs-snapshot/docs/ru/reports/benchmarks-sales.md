# Средние показатели продаж по рынку

- [Доступные данные](ru/reports/benchmarks-sales#metrics)
- [Работа с дашбордом](ru/reports/benchmarks-sales#work)
- [Почему инструмент может быть недоступен](ru/reports/benchmarks-sales#unavailable)

**Средние показатели продаж по рынку** — это аналитический инструмент, который позволяет сравнивать ключевые показатели продаж вашего сайта с аналогичными средними показателями ближайших участников рынка.

## ru/reports/benchmarks-sales#metricsДоступные данные

В виджетах сравнения на дашборде представлены следующие метрики и группировки:

**Метрики**

- **Визиты с просмотром товаров** — сравнение общего количества визитов с просмотром товаров на вашем сайте с медианным значением за тот же период у ближайших участников рынка.
- **Конверсия в просмотры товаров** — сравнение средней доли визитов с просмотром товаров от общего числа визитов на вашем сайте с медианным значением за тот же период у ближайших участников рынка.
- **Визиты с добавлением в корзину** — сравнение общего количества визитов с добавлением товаров в корзину на вашем сайте с медианным значением за тот же период у ближайших участников рынка.
- **Конверсия в корзину** — сравнение средней доли визитов с добавлением товаров в корзину от общего числа визитов на вашем сайте с медианным значением за тот же период у ближайших участников рынка.
- **Визиты с покупкой** — сравнение общего количества визитов с покупкой на вашем сайте с медианным значением за тот же период у ближайших участников рынка.
- **Конверсия в покупку** — сравнение средней доли визитов с покупкой от общего числа визитов на вашем сайте с медианным значением за тот же период у ближайших участников рынка.

**Группировки**

- **Группировка по типам источников трафика**. Позволяет сравнить показатели продаж по типам источников трафика с ближайшими участниками рынка. В системных виджетах отображаются 5 основных источников трафика, этот набор можно изменить вручную.
- **Группировка по типам устройств**. Позволяет сравнить показатели продаж по типам устройств с ближайшими участниками рынка.

## ru/reports/benchmarks-sales#workРабота с дашбордом

Чтобы использовать дашборд:

1. Перейдите в раздел **Дашборды** в боковом меню слева.
2. Откройте дашборд **Средние показатели продаж по рынку**.

На дашборде представлен набор из готовых [специальных виджетов](ru/reports/report-widget#report-widget-benchmarks) сравнения.

Дашборд можно обновлять: добавлять на него любые виджеты и группы виджетов к уже установленным, изменять формат и состав системных виджетов.

## ru/reports/benchmarks-sales#unavailableПочему инструмент может быть недоступен

**Опция «Получать доступ к отчётам по рынку» не была активна**

**Алгоритм Метрики не смог однозначно связать счетчик с доменом**

- Счетчик установлен на разных сайтах.
- На одном домене установлено несколько разных счетчиков, каждый из которых видит только часть данных. Для корректного подбора ближайших участников рынка убедитесь, что на всех страницах одного домена используется один счетчик, и дождитесь обновления данных.

**Не хватает данных**

Для подбора ближайших участников рынка на сайте должно быть минимум 10 визитов за последнюю неделю.

На сайте должна быть настроена электронная коммерция с передачей событий `detail`, `add` и `purchase`. Как настроить отправку данных, читайте в [Справке](ru/ecommerce/about#how-to).

События `detail`, `add` и `purchase` должны передаваться в достаточном объеме. Для каждого события существует минимальный порог по доле от общего числа нероботных визитов за неделю:

- 0,2 % для событий **Просмотр товара** (`detail`)
- 0,1 % для событий **Добавление товара в корзину** (`add`)
- 0,025 % для событий **Покупка** (`purchase`)

Для расчета средних показателей в группе ближайших участников рынка должно быть достаточное количество сайтов, передающих достаточное количество событий электронной коммерции.

**Мало ближайших участников рынка**

Метрика не смогла подобрать достаточное количество ближайших участников рынка для вашего сайта. Отправьте список своих ближайших участников рынка, чтобы алгоритм смог дообучиться на точных данных. В поле Домены укажите домены ближайших участников рынка.
