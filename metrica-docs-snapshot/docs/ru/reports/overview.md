# Обзор отчетов

## ru/reports/overview#groupsГруппы отчетов

Чтобы перейти к статистике, в меню выберите **Отчеты**. В боковом меню расположено облако пресетов. В нем собраны часто используемые группы отчетов, объединенные по тематикам. Например, в пресете «Кто заходит»отображаются отчеты, которые помогают определить аудиторию сайта: пол и возраст, устройства, с которых просматривали сайт, поисковые запросы, которые привели посетителей на сайт.

Чтобы найти определенный отчет, воспользуйтесь поиском: в меню выберите **Отчеты** и введите запрос в поисковой строке.

Вы можете закрепить во вкладке **Отчеты** до 5 любых отчетов. Они будут отображаться в разделе **Популярные**.

В разделе **Сохраненные на аккаунт** хранятся отчеты, которые видны только на вашем аккаунте на всех доступных вам счетчиках, а в разделе **Сохраненные на счетчик** — доступные всем пользователям определенного счетчика. Чтобы выбрать, в каком именно разделе будет отображаться отчет, укажите раздел при сохранении отчета.
