# Отчет «Adfox, параметры рекламных кампаний»

- [Какие задачи может решать отчет](ru/reports/adfox-puid#case)
- [Условия для получения отчета](ru/reports/adfox-puid#ness)
- [Структура и настройки отчета](ru/reports/adfox-puid#data)

Посмотреть отчет: **Отчеты** → **Монетизация** → **Adfox, параметры рекламных кампаний**.

## ru/reports/adfox-puid#caseКакие задачи может решать отчет

Если в рекламной кампании настроено [дополнительное таргетирование](https://yandex.ru/support/adfox-sites/targeting/puid.html), вы можете отслелить доход, который принесла каждая группа пользователей.

## ru/reports/adfox-puid#nessУсловия для получения отчета

Для просмотра отчета [включите показ отчетов по Adfox и укажите счетчик Метрики](ru/sources/adfox-settings#activate) в Adfox.

По умолчанию доступ к просмотру отчетов группы «Монетизация» ограничен. Вы можете [управлять правами доступа](ru/sources/adfox-settings#access).

## ru/reports/adfox-puid#dataСтруктура и настройки отчета

Данные в отчете объединены в группы:

- source: ru/_includes/popup/id-adfox/owner.md Владелец — пользователь с ролью **Владелец сайта** в интерфейсе Adfox. endsource: ru/_includes/popup/id-adfox/owner.md
- source: ru/_includes/popup/id-adfox/puid.md Параметр рекламной кампании (puid) — название таргетинга в настройках кампании. Например, «тип пользователя», если настроено таргетирование для авторизованных и неавторизованных пользователей. endsource: ru/_includes/popup/id-adfox/puid.md
- source: ru/_includes/popup/id-adfox/puid-value.md Значение параметра рекламной кампании — значение таргетинга, например, «авторизованный пользователь» или «неавторизованный пользователь» при настроенном параметре «тип пользователя». endsource: ru/_includes/popup/id-adfox/puid-value.md

Метрики в отчете:

- source: ru/_includes/popup/id-adfox/request.md Запросы кода Adfox — запросы кода Adfox со страниц, по которым был ответ от сервера Adfox (загрузки баннеров и загрузки по умолчанию). endsource: ru/_includes/popup/id-adfox/request.md
- source: ru/_includes/popup/id-adfox/impression.md Показы Adfox — зафиксированный системой показ рекламного баннера пользователю. endsource: ru/_includes/popup/id-adfox/impression.md
- source: ru/_includes/popup/id-adfox/rendering-impression.md Отрисовки на просмотр Adfox — cреднее количество загрузок баннеров Adfox (в том числе РСЯ) на один просмотр страницы. endsource: ru/_includes/popup/id-adfox/rendering-impression.md
- source: ru/_includes/popup/id-adfox/estimated-revenue.md Суммарный доход Adfox — расчетный суммарный доход от показов рекламы. endsource: ru/_includes/popup/id-adfox/estimated-revenue.md
- source: ru/_includes/popup/id-adfox/cpmv.md CPMV (Cost per mille viewable ads) Adfox — расчетная cтоимость одной тысячи показов. В рублях без НДС. endsource: ru/_includes/popup/id-adfox/cpmv.md
- source: ru/_includes/popup/id-adfox/revenue-visit.md Расчетный доход визита Adfox — средний расчетный доход на один визит. endsource: ru/_includes/popup/id-adfox/revenue-visit.md

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
