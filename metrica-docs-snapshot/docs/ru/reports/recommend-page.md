# Отчет «Рекомендательный виджет, страницы размещения»

- [Какие задачи может решать отчет](ru/reports/recommend-page#case)
- [Условия для получения отчета](ru/reports/recommend-page#ness)
- [Структура и настройки отчета](ru/reports/recommend-page#data)

Отчет содержит статистику по странице, на которой размещается рекомендательный виджет. В отчете учитываются визиты и посетители, которые заходили на страницу сайта с виджетом. При этом они могли не увидеть виджет или не перейти на рекомендованный материал.

Посмотреть отчет: **Отчеты** → **Монетизация** → **Рекомендательный виджет** → **Рекомендательный виджет, страницы размещения**.

## ru/reports/recommend-page#caseКакие задачи может решать отчет

Вы можете ориентироваться на метрики **Клики по рекомендациям в виджете** и **CTR виджета**.

Вы можете ориентироваться на метрики **Процент видимости виджета** и **CTR виджета**. Показатели могут различаться на разных разделах сайта в зависимости от верстки. Вы можете определить разделы с наименьшим процентом видимости — возможно, на них стоит изменить место размещения виджета.

## ru/reports/recommend-page#nessУсловия для получения отчета

Чтобы просматривать отчеты, [включите показ отчетов](ru/sources/yan-settings#activate) и укажите счетчик Метрики в интерфейсе Рекламной сети Яндекса.

По умолчанию доступ к просмотру отчетов группы «Монетизация» ограничен. Вы можете [управлять правами доступа](ru/sources/yan-settings#access).

## ru/reports/recommend-page#dataСтруктура и настройки отчета

Данные отчета сгруппированы по URL страницы сайта, на которой размещается рекомендательный виджет.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
