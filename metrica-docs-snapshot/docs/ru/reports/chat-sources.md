# Отчет «Источники чатов»

- [Какие задачи может решать отчет](ru/reports/chat-sources#case)
- [Условия для получения отчета](ru/reports/chat-sources#ness)
- [Структура и настройка отчета](ru/reports/chat-sources#data)
- [Узнайте больше](ru/reports/chat-sources#uznajte-bolshe)

Отчет поможет определить источники трафика, которые привели к чат-конверсиям, и выявить наиболее эффективные из них.

Посмотреть отчет: **Отчеты** → **Чаты** → **Источники чатов**.

## ru/reports/chat-sources#caseКакие задачи может решать отчет

Отчет покажет источники и общую информацию о чатах.

Для этого нужно задать [сегмент](ru/general/segmentation):

1. В группе условий **для людей, у которых** нажмите кнопку .
2. Выберите условие **Суммарный доход** и укажите интересующую вас сумму.

## ru/reports/chat-sources#nessУсловия для получения отчета

Чтобы получить информацию, необходимо настроить [передачу данных о чатах](ru/data/chat) в Метрику.

## ru/reports/chat-sources#dataСтруктура и настройка отчета

Данные сгруппированы по [источнику трафика](ru/sources/sources-summary#source1). Метрики, представленные в отчете, можно использовать как [условие сегментации](ru/general/segmentation) по визитам посетителей.

О том, как настроить отчет, смотрите в разделе [Настройки отчета](ru/reports/report-general#set-report).
