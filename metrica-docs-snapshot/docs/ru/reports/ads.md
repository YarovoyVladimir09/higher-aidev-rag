# Отчет «Промокампании»

- [Какие задачи может решать отчет](ru/reports/ads#case)
- [Условия для получения отчета](ru/reports/ads#ness)
- [Структура и настройка отчета](ru/reports/ads#data)
- [Узнайте больше](ru/reports/ads#uznajte-bolshe)

Отчет показывает просмотры и клики по рекламным материалам.

Посмотреть отчет: **Отчеты** → **Электронная коммерция** → **Промокампании**.

## ru/reports/ads#caseКакие задачи может решать отчет

Отчет помогает оценивать эффективность внутренних рекламных кампаний, проводимых на сайте. Например, вы можете ориентироваться на показатели **Просмотры баннера** и **Количество посетителей, кликнувших на баннер**.

## ru/reports/ads#nessУсловия для получения отчета

Для формирования отчета необходимо использовать возможности сервиса по учету и анализу данных электронной коммерции — [Ecommerce](ru/data/e-commerce). При первой передаче данных отчет станет доступен в течение нескольких часов.

## ru/reports/ads#dataСтруктура и настройка отчета

Данные в отчете сгруппированы по названию промокампании, которое вы передаете в Метрику.

О том, как настроить отчет, смотрите в разделе [Настройки отчета](ru/reports/report-general#set-report).
