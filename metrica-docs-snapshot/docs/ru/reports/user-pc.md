**Наличие блокировщиков рекламы**

Отчет о визитах посетителей, у которых установлены наиболее распространенные блокировщики рекламы. Некоторые технологии могут блокировать сам счетчик Метрики. Поэтому статистические показатели могут отличаться от реальных в меньшую сторону.

- AdBlock
- AdBlocker Lite
- AdBlocker Ultimate
- Adblock Plus
- AdGuard Антибаннер
- Ghostery
- StopAll Ads
- uBlock
- uBlock Origin
- uBlock Plus Adblocker

Информация о блокировщиках рекламы может быть полезна при анализе источников посещаемости сайта. Отчет позволяет понять, какой процент посещений из разных источников был заблокирован.

Чтобы сформировать такой отчет, перейдите в раздел **Отчеты** → **Источники** → **Источники, сводка** и добавьте метрику **Метрики** → **Технологии** → **Блокировщики рекламы**.

Иногда могут быть полезны данные об операционной системе и браузере, на которых установлены блокировщики рекламы. Для формирования такого отчета перейдите в раздел **Отчеты** → **Технологии** → **Операционные системы**. Затем добавьте группировку **Группировки** → **Технологии** → **Браузер** и метрику **Метрики** → **Технологии** → **Блокировщики рекламы**.
