# Отчет «Посещаемость»

- [Какие задачи может решать отчет](ru/reports/traffic#case)
- [Структура и настройки отчета](ru/reports/traffic#data)

Отчет отражает динамику посещаемости вашего сайта за определенный период. Помимо количественных критериев (например, число посетителей и просмотров), в отчет включены качественные показатели (время пребывания на сайте, глубина просмотра страниц и т. д.).

Посмотреть отчет: **Отчеты** → **Аудитория** → **Посещаемость**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/traffic?period=month&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/reports/traffic#caseКакие задачи может решать отчет

С помощью отчета вы можете узнать количество посетителей сайта за определенный период, а также общее число посетителей с момента установки счетчика на сайт.

Для этого [создайте и настройте цель](ru/general/goals), а затем [используйте ее](ru/reports/goals) в отчете.

Отчет поможет определить количество новых посетителей за выбранный период. Такие посетители определяются с помощью cookie браузеров.

Чем выше показатель отказов, тем меньше сайт вовлекает посетителей — они уходят в течение 15 секунд, просмотрев только одну страницу.

Настройка диапазона дат помогает выяснить, насколько изменилась посещаемость за указанный период. Началом такого периода может стать, например, дата старта акции.

## ru/reports/traffic#dataСтруктура и настройки отчета

Данные в отчете сгруппированы по дате визита посетителей.

[Как настроить отчет](ru/reports/report-general)

Обратите внимание, что для отчета «Посещаемость» недоступны следующие настройки:

- добавление и удаление [группировок и метрик](ru/reports/report-general#attr-metrics);
- [примечания на графиках](ru/reports/notes).
