# Отчет «Adfox, страницы с рекламными событиями»

- [Какие задачи может решать отчет](ru/reports/adfox-ad-event#case)
- [Условия для получения отчета](ru/reports/adfox-ad-event#ness)
- [Структура и настройки отчета](ru/reports/adfox-ad-event#data)

Посмотреть отчет: **Отчеты** → **Монетизация** → **Adfox, страницы с рекламными событиями**.

## ru/reports/adfox-ad-event#caseКакие задачи может решать отчет

Вы можете определить наиболее доходные статьи, рубрики, группы материалов с общим тегом или материалы конкретного автора, если нужные атрибуты указаны в URL. Например, `example.com/news/`.

1. В отчете выберите линейный список.
2. Введите в строку поиска атрибут из URL. Например `news`, так можно будет создать отчет с новостями.
3. Отсортируйте данные по убыванию «Суммарного дохода Adfox» — в начале списка отобразятся страницы, которые приносят наибольший доход.

Когда рекламных блоков мало, сайт может недополучать доход. Но когда рекламы слишком много, снижается вовлеченность аудитории и количество просмотренных страниц — а значит, падают просмотры рекламы и доход площадки.

Чтобы определить оптимальное количество рекламных блоков, нужно отследить, как изменение количества рекламы влияет на вовлеченность и доход.

1. Укажите на графике дату установки нового рекламного блока. Для этого кликните в любую точку на графике и [добавьте примечание](ru/reports/notes).
2. Через некоторое время, когда накопится статистика, оцените эффект от нового блока. Для этого добавьте в отчет метрику **Глубина просмотра**.
3. Сравните метрики вовлеченности (глубину просмотра и отказы), и доход до и после установки нового блока. Например, за месяц до и месяц после добавления нового блока. Выберите нужный период в календаре.

Совет

Желательно, чтобы другие факторы, влияющие на вовлеченность посетителей, по возможности оставались неизменными. Если на сайте одновременно появился новый рекламный блок и вышла серия особенно удачных материалов, нельзя будет с уверенностью сказать, как именно новый блок повлиял на глубину просмотра.

## ru/reports/adfox-ad-event#nessУсловия для получения отчета

Для просмотра отчета [включите показ отчетов по Adfox и укажите счетчик Метрики](ru/sources/adfox-settings#activate) в Adfox.

По умолчанию доступ к просмотру отчетов группы «Монетизация» ограничен. Вы можете [управлять правами доступа](ru/sources/adfox-settings#access).

## ru/reports/adfox-ad-event#dataСтруктура и настройки отчета

Отчет показывает статистику по сайту с глубиной до страницы, на которую перешел посетитель по рекламе.

Метрики в отчете:

- source: ru/_includes/popup/id-adfox/request.md Запросы кода Adfox — запросы кода Adfox со страниц, по которым был ответ от сервера Adfox (загрузки баннеров и загрузки по умолчанию). endsource: ru/_includes/popup/id-adfox/request.md
- source: ru/_includes/popup/id-adfox/impression.md Показы Adfox — зафиксированный системой показ рекламного баннера пользователю. endsource: ru/_includes/popup/id-adfox/impression.md
- source: ru/_includes/popup/id-adfox/rendering-impression.md Отрисовки на просмотр Adfox — cреднее количество загрузок баннеров Adfox (в том числе РСЯ) на один просмотр страницы. endsource: ru/_includes/popup/id-adfox/rendering-impression.md
- source: ru/_includes/popup/id-adfox/estimated-revenue.md Суммарный доход Adfox — расчетный суммарный доход от показов рекламы. endsource: ru/_includes/popup/id-adfox/estimated-revenue.md
- source: ru/_includes/popup/id-adfox/cpmv.md CPMV (Cost per mille viewable ads) Adfox — расчетная cтоимость одной тысячи показов. В рублях без НДС. endsource: ru/_includes/popup/id-adfox/cpmv.md
- source: ru/_includes/popup/id-adfox/revenue-visit.md Расчетный доход визита Adfox — средний расчетный доход на один визит. endsource: ru/_includes/popup/id-adfox/revenue-visit.md

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
