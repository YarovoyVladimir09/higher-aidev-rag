# Отчет «Adfox, загрузки по умолчанию»

- [Какие задачи может решать отчет](ru/reports/adfox-default-responses#case)
- [Условия для получения отчета](ru/reports/adfox-default-responses#ness)
- [Структура и настройки отчета](ru/reports/adfox-default-responses#data)

Посмотреть отчет: **Отчеты** → **Монетизация** → **Adfox, загрузки по умолчанию**.

## ru/reports/adfox-default-responses#caseКакие задачи может решать отчет

Вы можете оценить корректность настроек рекламной кампании. Если загрузок по умолчанию слишком много, проверьте ограничения и таргетинги. Множество ограничений и некорректно настроенные таргетинги сокращают количество доступной рекламы.

## ru/reports/adfox-default-responses#nessУсловия для получения отчета

Для просмотра отчета [включите показ отчетов по Adfox и укажите счетчик Метрики](ru/sources/adfox-settings#activate) в Adfox.

По умолчанию доступ к просмотру отчетов группы «Монетизация» ограничен. Вы можете [управлять правами доступа](ru/sources/adfox-settings#access).

## ru/reports/adfox-default-responses#dataСтруктура и настройки отчета

Данные в отчете объединены в группы:

- source: ru/_includes/popup/id-adfox/site.md Сайт — адрес сайта, с которого перешел посетитель на ваш сайт. endsource: ru/_includes/popup/id-adfox/site.md
- source: ru/_includes/popup/id-adfox/section.md Раздел — раздел сайта, с которого перешел посетитель на ваш сайт. endsource: ru/_includes/popup/id-adfox/section.md
- source: ru/_includes/popup/id-adfox/platform.md Площадка — формат рекламного блока. endsource: ru/_includes/popup/id-adfox/platform.md

Метрики в отчете:

- source: ru/_includes/popup/id-adfox/default-response.md Загрузки по умолчанию — количество запросов кода, по которым были произведены показы баннеров по умолчанию. Баннеры по умолчанию показываются в том случае, если нет для показа баннеров из коммерческих рекламных кампаний в силу настроек размещения, ограничений по количеству показов, скорости открутки, таргетирований. endsource: ru/_includes/popup/id-adfox/default-response.md
- source: ru/_includes/popup/id-adfox/default-response-share.md Доля загрузок по умолчанию Adfox — отношение числа загрузок по умолчанию к числу запросов кода Adfox. endsource: ru/_includes/popup/id-adfox/default-response-share.md
- source: ru/_includes/popup/id-adfox/request.md Запросы кода Adfox — запросы кода Adfox со страниц, по которым был ответ от сервера Adfox (загрузки баннеров и загрузки по умолчанию). endsource: ru/_includes/popup/id-adfox/request.md
- source: ru/_includes/popup/id-adfox/impression.md Показы Adfox — зафиксированный системой показ рекламного баннера пользователю. endsource: ru/_includes/popup/id-adfox/impression.md

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
