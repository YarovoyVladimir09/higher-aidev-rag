# Отчет «Рекомендательный виджет, вовлеченность»

- [Какие задачи может решать отчет](ru/reports/recommend-activ#case)
- [Условия для получения отчета](ru/reports/recommend-activ#ness)
- [Структура и настройки отчета](ru/reports/recommend-activ#data)

Отчет показывает, насколько активно посетители сайта переходят на рекомендуемые материалы.

Посмотреть отчет: **Отчеты** → **Монетизация** → **Рекомендательный виджет** → **Рекомендательный виджет, вовлеченность**.

## ru/reports/recommend-activ#caseКакие задачи может решать отчет

Вы можете ориентироваться на метрики **Глубина просмотра** и **Время на сайте**.

Вы можете сравнить, какой доход принесли вам посетители сайта, которые переходили по рекомендуемому материалу, с теми, кто не переходил. Сделать это можно, ориентируясь на метрику **Расчетный доход визита**.

## ru/reports/recommend-activ#nessУсловия для получения отчета

Чтобы просматривать отчеты, [включите показ отчетов](ru/sources/yan-settings#activate) и укажите счетчик Метрики в интерфейсе Рекламной сети Яндекса.

По умолчанию доступ к просмотру отчетов группы «Монетизация» ограничен. Вы можете [управлять правами доступа](ru/sources/yan-settings#access).
