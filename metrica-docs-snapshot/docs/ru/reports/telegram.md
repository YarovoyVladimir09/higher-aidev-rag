# Еженедельный отчет в Telegram

- [Шаг 1 — Подключение отчета](ru/reports/telegram#on)
- [Шаг 2 — Настройка отчета](ru/reports/telegram#settings)
- [Отключение отчета](ru/reports/telegram#off)

Метрика может присылать еженедельный отчет по отдельным показателям в виде сообщения в Telegram. Отчет содержит данные за период с понедельника по воскресенье и приходит по понедельникам.

Чтобы заказать отчет, вы должны быть владельцем счетчика или пользователем с правами на его [редактирование](ru/general/access). Получать одинаковый отчет будут все, у кого есть доступ к счетчику, кроме пользователей с правами [представителя](ru/general/access).

Отчет может содержать данные по следующим показателям:

- [Визиты](ru/general/glossary#visits) — последовательность действий (активность) одного [посетителя](ru/general/glossary#user-main) на сайте (на одном счетчике). Активностью посетителя считаются: просмотры страниц, переходы по внешним ссылкам, загрузки файлов и вызов функций [reachGoal](ru/objects/reachgoal), [hit](ru/objects/hit), [params](ru/objects/params-method), [extLink](ru/objects/extlink), [file](ru/objects/file), [notBounce](ru/objects/notbounce).
- [Посетители](ru/general/glossary#user-main) — пользователь интернета, который зашел на сайт в течение определенного промежутка времени.
- Глубина просмотра — количество просмотров страниц сайта в одном визите.
- Отказы — визит считается отказом при выполнении [определенных условий](ru/general/glossary#failure).
- [Корзина](ru/general/e-commerce-autogoals). Показывает, как часто посетители открывают страницу с корзиной на сайте интернет-магазина.
- [Покупка](ru/general/e-commerce-autogoals). Отражает количество заказов на сайте интернет-магазина.
- Конверсии и достижения [целей](ru/general/goals), в том числе [автоматических](ru/general/auto-goals).

## ru/reports/telegram#onШаг 1 — Подключение отчета

1. Перейдите в Метрику.
2. Перейдите на страницу **Настройки аккаунта** → **Еженедельный отчет в Telegram**.
3. Если у вас не установлен Telegram, нажмите **Установить клиент Telegram**. Если установлен — нажмите **Войти через Telegram**.
4. Укажите номер, к которому привязан ваш аккаунт в Telegram. Нажмите **Далее** — подтверждение придет в Telegram.
5. В Telegram откройте полученное сообщение и нажмите **Принять**.
6. Вернитесь в Метрику на страницу **Настройки аккаунта** → **Еженедельный отчет в Telegram** и также нажмите **Принять**.
7. Нажмите **Настроить содержание отчетов** и укажите один или несколько счетчиков, по которым хотите получать еженедельные отчеты. Если в поле **Выбрать счетчики** указано **Все, которые могу редактировать** или **Все, у которых я владелец**, добавлять и удалять счетчики нельзя. Чтобы добавить или удалить счетчики, выберите **Некоторые счетчики**. Можно выбрать до 200 счетчиков.

## ru/reports/telegram#settingsШаг 2 — Настройка отчета

Без настройки отчет будет содержать статистику по всем показателям из [списка выше](ru/reports/telegram#metrics), которые собраны счетчиком.

1. В Метрике выберите нужный счетчик.
2. Откройте **Настройка** → **Еженедельный отчет в Telegram**.
3. Выберите показатели, которые будут указаны в отчете. Чтобы получать данные о конверсиях и количестве достижений [целей](ru/general/goals), которые созданы на счетчике, включите опцию **Цели** и выберите одну или несколько целей. Данные по выбранным целям будут отражены в отчете в блоке **Достижения целей**.
4. Нажмите **Сохранить**.

## ru/reports/telegram#offОтключение отчета

1. В Метрике перейдите на страницу **Настройки аккаунта** → **Еженедельный отчет в Telegram**.
2. Чтобы отменить отчет на конкретном счетчике: Выберите пункт **Некоторые счетчики, не более 200**. Наведите курсор на счетчик, для которого хотите отписаться от отчета, и нажмите .
3. Чтобы отменить подписку, нажмите кнопку **Отменить подписку** и подтвердите решение.
