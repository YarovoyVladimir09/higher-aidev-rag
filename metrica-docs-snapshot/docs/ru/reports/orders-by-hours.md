# Отчет «Заказы по времени суток»

- [Какие задачи может решать отчет](ru/reports/orders-by-hours#case)
- [Структура и настройка отчета](ru/reports/orders-by-hours#data)

Отчет показывает, как меняется покупательское поведение на вашем сайте в зависимости от времени суток.

Для просмотра разных метрик на графике используйте кнопку . Время соответствует часовому поясу, который вы указали в настройках счетчика. Для получения более точной статистики рекомендуем использовать увеличенный интервал дат.

Посмотреть отчет: **Отчеты** → **Электронная коммерция** → **Заказы по времени суток**.

## ru/reports/orders-by-hours#dataСтруктура и настройка отчета

Данные в отчете сгруппированы по часовым интервалам в течение суток. Можно просмотреть статистику по визитам и действиям пользователя, которые начались в один из таких интервалов.

Например, группировка «10:00» объединяет данные, которые начались в период между 10:00 и 11:00.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
