# Компании‑интеграторы

- [Наши партнеры](ru/sert-integrators#integr)[Найти партнера для оказания отдельных услуг](ru/sert-integrators#individual-services)[Найти партнера для комплексной настройки веб-аналитики](ru/sert-integrators#complex)
- [Как стать партнером](ru/sert-integrators#become-partner)

Чтобы быстрее включиться в работу с Яндекс Метрикой, вы можете обратиться к нашим партнерам.

Это опытные интеграторы, которые помогут внедрить и настроить инструменты Яндекс Метрики, чтобы вы использовали сервис с максимальной эффективностью.

На этой странице вы можете найти компанию, которая поможет вам в решении следующих задач:

- [Установка счётчика](ru/general/creating-counter);
- [Настройка целей](ru/general/goals);
- [Настройка электронной коммерции](ru/ecommerce/about);
- [Загрузка данных из CRM](ru/crm/about);
- [Загрузка расходов](ru/ad/expenses);
- [Загрузка офлайн‑конверсий](ru/data/offline-conversion);
- [Отслеживание звонков](ru/data/calls)/[импорт чатов](ru/data/chat);
- [Measurement Protocol](ru/general/measurement-protocol);
- [Импорт параметров посетителей](ru/data/user-params-data);
- [Передача параметров событий/визитов](ru/data/visit-params-data);
- [Разметка сайта для контентной аналитики](ru/publishers/about).

Можно обратиться как за конкретной услугой, так и для комплексной настройки систем веб-аналитики.

Просто выберите компанию и нажмите кнопку **Оставить заявку**. Специалисты свяжутся с вами и расскажут об условиях работы.

Если вы тоже представляете компанию-интегратора и хотите стать нашим партнером, приглашаем вас присоединиться к проекту — условия ниже на странице.

[Выбрать интегратора](ru/sert-integrators#integr) [Стать интегратором](ru/sert-integrators#become-partner)

## ru/sert-integrators#become-partnerКак стать партнером

Хотите стать интегратором? Мы ценим профессионализм и стремимся к долгосрочному сотрудничеству.

Чтобы стать партнером:

1. Ознакомьтесь с [требованиями к партнерам и условиями сотрудничества](https://yandex.ru/legal/metrica_integrators_rules/ru/).
2. Подайте заявку через [форму](ru/sert-integrators#form) ниже. Форма откроется в новой вкладке.
3. Получите статус сертифицированного партнера-интегратора Яндекс Метрики.
4. Начните предоставлять услуги клиентам.

[Подать заявку](https://forms.yandex.ru/surveys/13836345.820711ed66b049d26b7b4eb217abb9618b2e07c9)
