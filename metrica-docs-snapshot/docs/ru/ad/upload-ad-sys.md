# Передача данных в CSV-файле, выгруженном из рекламного кабинета

Вы можете загружать в Метрику данные о расходах из любой рекламной системы. Чтобы передавать данные, нужно выгрузить из вашей рекламной системы CSV-файл с данными об одной или нескольких кампаниях и отредактировать его, а затем загрузить файл в Метрику — во время загрузки привести его к [нужному формату](ru/ad/data-format).

Внимание

Убедитесь, что ссылки в ваших рекламных объявлениях содержат [UTM-метки](ru/general/source-tags#utm-construct). Эти метки и их значения нужно будет передать в Метрику.

**Шаг 1 — Подготовка файла в вашей рекламной системе**

1. До выгрузки файла добавьте столбцы: С датой*, за которую вы выгружаете данные. Укажите дату в каждой строке с данными о кампании. С расходами без учета НДС* за указанный вами период. Проверьте, что в качестве разделителя используется запятая или точка. Например, 23,456 или 23.456 соответственно. С количеством кликов за указанный вами период. С валютой, в которой указаны расходы.

*Обязательные столбцы, их значения нельзя будет заполнить вручную при загрузке файла в Метрику.

1. Добавьте столбцы с UTM-метками. Если вы используете шаблон отслеживания с подстановкой параметров кампании в ссылки, добавьте столбцы с заполненными значениями для рекламной кампании, соответствующие тому, что указано в ваших UTM-метках. Например, если в UTMCampaign передается название кампании, добавьте поле, в котором содержится название кампании, а если передается идентификатор кампании, то поле, в котором указан идентификатор. Если в рекламной кампании вы указываете значения вручную, например, для всех объявлений UTMMedium=cpc, вы сможете задать значения меток в веб-интерфейсе Метрики при загрузке файла.
2. Выгрузите файл в формате CSV.

**Шаг 2 — Редактирование выгруженного файла**

Внимание

Чтобы сохранить форматирование строк и их содержимого, откройте файл в текстовом редакторе. Например, в Блокноте для ОС Windows или TextEdit для семейства операционных систем Apple.

1. Отредактируйте файл. Из файла удалите верхние строки, кроме названий столбцов, и строку «Итого».
2. Сохраните файл, не изменяя его формат.

[Пример получившегося файла](https://download.cdn.yandex.net/from/yandex.ru/support/ru/metrica/files/ad-sys-expenses.csv)

**Шаг 3 — Загрузка данных в Метрику**

1. Перейдите в Метрику на страницу **Настройка** (вкладка **Загрузка данных**).
2. В блоке **Расходы на рекламу** нажмите кнопку **Загрузить**.
3. Выберите подготовленный файл и загрузите его.
4. В появившемся окне заполните поля: Укажите значение метки UTMSource (рекламную систему, из которой был выгружен файл). Убедитесь, что регистр, в котором указано значение UTM-метки, совпадает с регистром, в котором значение указано в URL рекламного объявления. Укажите, какой столбец в файле соответствует полю **Дата**. Укажите, какой столбец в файле соответствует полю **Расходы**. Выберите тип разделителя суммы, который используется в выгруженном в шаге 1 файле — запятую или точку. Укажите, какой столбец в файле соответствует полю **Клики**. Выберите валюту, в которой указаны расходы. Если валюта не указана, то для формирования отчетов Метрика использует валюту, которая указана в настройках счетчика. Выберите другие UTM-метки и их значения из списка. Вы можете вписать одно значение для всех меток. Например, для метки UTMMedium можно указать значение [cpc](https://ru.wikipedia.org/wiki/Pay_per_click#CPC).
5. Нажмите кнопку **Загрузить данные**.

Если вы повторно загружаете файл с данными за один и тот же период, новый файл заменит ранее загруженный.
