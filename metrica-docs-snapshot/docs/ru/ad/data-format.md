# Формат передаваемых данных по расходам на рекламу

Данные о расходах на рекламу можно передать в Метрику в формате CSV.

[Спецификация формата CSV](http://www.rfc-editor.org/rfc/rfc4180.txt)

[Описание формата СSV](https://ru.wikipedia.org/wiki/CSV)

[Пример файла для загрузки данных](https://download.cdn.yandex.net/from/yandex.ru/support/ru/metrica/files/expenses.csv)

## ru/ad/data-format#polya-dlya-peredachi-dannyhПоля для передачи данных

| Название поля | Обязательно | Описание | Пример |

| Expenses | Да | Сумма, которая была потрачена на рекламу без учета НДС. | 50 000 |

| UTMSource | Да | Значение UTM-метки, которое указано в URL ссылки в рекламном объявлении. Обратите внимание на регистр, в котором указано значение метки. | instagram |
