# Передача данных в CSV-файле специального формата

Чтобы передавать данные о рекламной кампании в Метрику, сформируйте файл [специального формата](ru/ad/data-format).

Внимание

Данные Директа загружать не нужно — они передаются в Метрику автоматически. Если вы загрузите данные в файле, они будут дублироваться с переданными автоматически — отчет станет некорректным.

Передавать CSV-файл с данными можно:

1. Перейдите в Метрику на страницу **Настройка** (вкладка **Загрузка данных**).
2. В блоке **Расходы на рекламу** нажмите кнопку **Загрузить**.

[Документация к API Метрики](https://yandex.ru/dev/metrika/doc/api2/management/expenses/uploadbody-docpage/)

Если вы повторно загружаете файл с данными за один и тот же период, новый файл заменит ранее загруженный. Если в файле указан отрезок времени, то Метрика равномерно распределит в нем числовые значения (расход, количество кликов и пр.) для отображения в отчете. Таким образом, когда в отчете вы выберете дату, отобразятся числа, которые Метрика отнесла к ней.
