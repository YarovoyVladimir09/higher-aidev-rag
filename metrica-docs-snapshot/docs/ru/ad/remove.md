# Удаление данных по расходам на продвижение

Примечание

Данные Директа удалить невозможно.

Удалить загруженные данные из Метрики можно несколькими способами:

1. Перейдите в Метрику на страницу **Настройка** (вкладка **Загрузка данных**).
2. В блоке **Расходы на рекламу** нажмите кнопку **Удалить данные**.
3. Выберите способ **По дате и UTM-меткам/источникам**.
4. Чтобы удалить все данные о расходах, выберите дату или период. Чтобы удалить данные о конкретном рекламном источнике, выберите дату или период и заполните необходимые поля — `TrafficSource`, `TrafficSourceDetail` или `UTMSource` так, как значения были указаны при загрузке данных. Обратите внимание на регистр, в котором указаны значения полей.

1. Сформируйте файл в формате CSV и укажите в нем, какую именно информацию нужно удалить. **Название поля** **Обязательно** **Описание** **Пример** `Date` Да Период, за который передаются данные. Может быть день или отрезок времени. В формате [Unix Time Stamp](http://www.unixtimestamp.com/index.php) по стандарту [ISO 8601](https://ru.wikipedia.org/wiki/ISO_8601) (YYYY-MM-DD). Чтобы указать диапазон дат, используйте / 2020-02-18 2020-01-18/2020-02-18 `TrafficSource` Да*** Источник трафика первого уровня. Доступные значения описаны в [таблице](ru/ad/expenses) ad `TrafficSourceDetail` Нет Источник трафика второго уровня. Доступные значения описаны в [таблице](ru/ad/expenses) vk `UTMSource` Да*** Значение UTM-метки/источника, которое указано в URL ссылки в рекламном объявлении. Обратите внимание на регистр, в котором указано значение метки. Он должен совпадать с тем, в котором значение было указано при загрузке данных vk `UTMCampaign` Нет new `UTMMedium` Нет cpc `UTMTerm` Нет shirt-blue `UTMContent` Нет shirt * Поле `UTMSource` обязательно, если не указано поле `TrafficSource`. Примеры: Удалить данные о конкретном рекламном источнике за определенный периодНапример, чтобы удалить данные о рекламной кампании в Instagram*** за период с 1 по 15 марта, заполните файл так: Удалить все данные за периодЧтобы удалить все данные за определенный период, укажите в файле только поле `Date` с нужными датами: [Пример файла для удаления](https://download.cdn.yandex.net/from/yandex.ru/support/ru/metrica/files/expenses-delete.csv)
2. Перейдите в Метрику на страницу **Настройка** (вкладка **Загрузка данных**).
3. В блоке **Расходы на рекламу** нажмите кнопку **Удалить данные**.
4. Выберите способ **С помощью файла**.

Примечание

Если вы загрузили в Метрику данные от нескольких сервисов (`Provider`) и хотите удалить данные только некоторых из них, воспользуйтесь API. При удалении информации в веб-интерфейсе Метрики будут удалены данные от всех провайдеров за указанный период.

С помощью API можно удалить данные одним из способов:

- [прямо в запросе](https://yandex.ru/dev/metrika/doc/api2/management/expenses/uploadremovesingleline-docpage/);
- [в CSV-файле](https://yandex.ru/dev/metrika/doc/api2/management/expenses/uploadremovebody-docpage/);
- [как multipart/form-data](https://yandex.ru/dev/metrika/doc/api2/management/expenses/uploadremovemultipart-docpage/).
