# Подключение Facebook Ads для выгрузки данных о расходах

- [Создать подключение](ru/ad/facebook#how-to)
- [Удалить данные из Метрики](ru/ad/facebook#remove)
- [Отвязать счетчик Метрики от аккаунта Facebook Ads](ru/ad/facebook#decouple)
- [Вопросы и ответы](ru/ad/facebook#qanda)

Если вы размещаете рекламу на Facebook* или Instagram*, вы можете настроить регулярную [передачу данных о расходах на рекламу](ru/ad/expenses) в Яндекс Метрику. Это позволит сравнивать показатели рекламы в Facebook или Instagram с другими платными каналами.

Информация о расходах и кликах рекламной кампании передается из аккаунта Facebook* Ads в Метрику, если рекламное объявление ведет на внешний сайт. При передаче данных Метрика сверяет URL в рекламных объявлениях с адресом сайта [в настройках счетчика](ru/general/counter-general). Таким образом, выгружается информация только о рекламной кампании, которая создана для вашего сайта.

Внимание

Если конечный URL в настройках групп объявлений Facebook* Ads отличается от адреса сайта в настройках счетчика Метрики, данные не загрузятся. Убедитесь, что адреса совпадают.

Данные о расходах передаются ежедневно за 7 прошедших дней — так статистика регулярно дополняется и уточняется. Источником расходов будет указан **Переходы по рекламе** — **Facebook***. При наличии в `UtmSource` значения `instagram` — **Переходы по рекламе** — **Instagram***.

Чтобы посмотреть статистику, используйте [Отчет «Источники, расходы и ROI»](ru/sources/ad-expenses).

Данные передаются в Метрику без учета НДС в валюте, которая указана в аккаунте Facebook* Ads. Если вы передаете данные в нескольких валютах, вы можете выбрать одну из них при [настройке отчета](ru/reports/report-general#currency).

## ru/ad/facebook#how-toСоздать подключение

Если у вас несколько аккаунтов в Метрике, используйте тот, под которым вы будете работать с данными о расходах. Создать подключение можно только для одного аккаунта в Метрике. Это сделано для защиты данных. При этом вы можете создать несколько подключений для одного аккаунта в Метрике.

1. Убедитесь, что URL ваших рекламных объявлений содержат [UTM-метки](ru/general/source-tags#utm-construct). Поддерживаемые динамические параметры {{ad.name}} {{adset.id}} {{adset.name}} {{campaign.id}} {{campaign.name}} {{pad.id}} [Как добавить параметры URL в рекламу](https://www.facebook.com/business/help/1016122818401732) [Как задать динамические параметры](https://www.facebook.com/business/help/2360940870872492)
2. Перейдите в Метрику на страницу **Настройка** (вкладка **Загрузка данных**).
3. В блоке **Расходы на рекламу** (**Автоматическая загрузка расходов**) выберите **Facebook Ads***.
4. Нажмите кнопку **Подключить Facebook Ads***.
5. Выберите ваш Business Manager Account, в котором работаете с рекламной кампанией.
6. Добавьте название подключения и выберите рекламный аккаунт, из которого нужно выгружать данные. [Что делать, если нет доступных аккаунтов](ru/ad/facebook#no-eccess).
7. Нажмите кнопку **Сохранить**.

Вы можете создать подключение для нескольких счетчиков:

1. Убедитесь, что у вашего аккаунта на Яндексе есть доступ к счетчикам, для которых нужно создать подключение.
2. Создайте подключение как описано выше для одного из счетчиков.
3. Для остальных счетчиков выберите подключение, созданное в п. 2.

Чтобы изменить название подключения, перейдите в настройки подключения и укажите новое название.

## ru/ad/facebook#removeУдалить данные из Метрики

Рекомендуем удалять данные [по дате и UTM-меткам/источникам](ru/ad/remove#date-utm).

## ru/ad/facebook#decoupleОтвязать счетчик Метрики от аккаунта Facebook Ads

Перейдите в Метрику на страницу **Настройка** и удалите подключенный аккаунт Facebook* Ads.

## ru/ad/facebook#qandaВопросы и ответы

Данные загружаются за семь прошедших дней.

Узнать логин, с которого уже выполнено подключение невозможно. Это сделано для безопасности ваших данных. Рекомендуем обратиться к вашим коллегам для выяснения информации.

Вероятно, на вашем аккаунте нет доступа к рекламному кабинету на Facebook*. Проверьте, есть ли доступ к рекламному кабинету у аккаунта, под которым вы создали подключение.

Если у вас нет рекламных кампаний или нет доступов к кампаниям Facebook* Ads, создайте и настройте рекламные кампании.

Возможно, у вас есть доступ к рекламным кабинетам под другим аккаунтом Facebook*. В этом случае удалите текущее подключение и создайте новое с аккаунта, который имеет доступ к рекламному аккаунту на Facebook*.

Метрика выгружает данные о расходах раз в сутки. Таким образом, за текущий день расходы появятся в отчетах счетчика не раньше следующего дня.
