Команда Яндекс Метрики разработала официальный бесплатный плагин для установки на сайт счетчика веб-аналитики. Плагин работает на версии WordPress 5.2.9 и выше.

Возможности плагина «Яндекс Метрика»:

- Добавление новых счетчиков Метрики с включенными по умолчанию опциями: [Электронная коммерция](ru/ecommerce/about); [Вебвизор](ru/webvisor/info); [Карта кликов](ru/behavior/click-map).
- Передача [событий электронной коммерции](ru/ecommerce/data): просмотр карточки товара; добавление товара в корзину; удаление товара из корзины; покупка.
- Детализация [передаваемых данных о товаре](ru/ecommerce/data#product_data).

Для использования возможностей электронной коммерции на сайте должен быть установлен плагин для интернет-магазина [WooCommerce](https://ru.wordpress.org/plugins/woocommerce/).

## ru/ecommerce/wordpress#startНачало работы

1. Если у вас еще нет счетчика Метрики, [создайте его](ru/quick-start). Убедитесь, что адрес сайта указан правильно в настройках счетчика. Для этого перейдите в Метрику на страницу **Настройки**. Обратите внимание на поле **Адрес** — здесь должен быть указан адрес сайта, на который вы хотите установить плагин.
2. source: ru/_includes/ecommerce/enabling/id-enabling/3.md В настройках счетчика включите опцию **Электронная коммерция**. В код счетчика добавится контейнер для сбора данных `dataLayer`. endsource: ru/_includes/ecommerce/enabling/id-enabling/3.md
3. Убедитесь, что в WordPress не активирован другой аналогичный плагин, устанавливающий счетчик Метрики. Для этого перейдите на страницу **Плагины** и поищите плагин по названию «Метрика», «Metrica» или «Metrika». Если такой плагин установлен, деактивируйте его.

## ru/ecommerce/wordpress#uploadШаг 1 — Установка плагина

1. Перейдите в панель администратора WordPress и авторизуйтесь.
2. Перейдите на страницу **Плагины** и нажмите кнопку **Добавить новый**.
3. Добавьте плагин одним из способов: Через поиск С помощью файла Найдите плагин с названием «Яндекс Метрика» и нажмите кнопку **Установить**. [Скачайте установочный ZIP-архив](https://metrika-cms-plugins.s3.yandex.net/wordpress/wp-yandex-metrika.zip). Затем на странице **Добавить плагин** нажмите кнопку **Загрузить плагин**, выберите ZIP-архив и установите его.
4. Перейдите на страницу **Плагины** → **Установленные** и найдите плагин «Яндекс Метрика». Активируйте его.

## ru/ecommerce/wordpress#setШаг 2 — Настройка плагина

1. Перейдите на страницу **Плагины** → **Установленные** и найдите плагин «Яндекс Метрика».
2. Откройте настройки плагина.
3. Укажите номер счетчика, который установлен на вашем сайте. Если плагин обнаружил на сайте счетчик Метрики, то поля будут уже заполнены. Проверьте их. [Как найти номер счетчика](ru/general/tag-id)
4. По умолчанию опция **Вебвизор** включена. Она позволяет [записывать визиты посетителей](ru/webvisor/info), чтобы вы могли более полно анализировать статистику. При необходимости вы можете отключить Вебвизор в любой момент.
5. Укажите **Тип бренда**, чтобы информация о брендах ваших товаров корректно передавалась в Метрику и отображалась в отчетах. **Термин** — в поле **Таксономия или произвольное поле бренда** укажите название таксономии бренда. Как узнать таксономию брендаПерейдите в WordPress на страницу **Товары** → **Бренды** и обратите внимание на URL в адресной строке браузера — параметр `taxonomy` содержит название таксономии бренда. В примере это `example-brand`. **Произвольное поле** — в поле **Таксономия или произвольное поле бренда** укажите название поля бренда. Как узнать произвольное поле брендаПоле может быть установлено с помощью плагина, который отвечает за функционал брендов на сайте. Если на вашем сайте он есть, чтобы определить название поля, вы можете использовать документацию плагина или обратиться в службу поддержки его разработчика. Также вы можете самостоятельно изучить произвольные поля товара в базе данных, если поле предусмотрено вашей темой WordPress.
6. Сохраните изменения.

После установки и настройки плагина посмотрите лог ошибок. Вы можете задать вопросы через [форму ниже](ru/ecommerce/wordpress#form) или на сайте WordPress на странице плагина Яндекс Метрика (нажмите кнопку **Перейти в форум поддержки**).

- Устаревшая версия WordPress. Проверьте, готова ли к установке новая версия и установите ее. Для этого в панели администратора перейдите на страницу **Консоль** → **Обновления**.
- Указанная вами таксономия бренда отсутствует на сайте.
- В теме отсутствует необходимый для работы плагина хук.
- Номер счетчика содержит символы, отличные от цифр.

## ru/ecommerce/wordpress#checkШаг 3 — Проверка отправки данных

Проверьте, отправляются ли в Метрику данные:

- [электронной коммерции](ru/ecommerce/check)
- [о посещениях на сайте](ru/general/check-counter)

Данные электронной коммерции появятся в Метрике спустя несколько часов после их первой отправки. Чтобы посмотреть отчеты электронной коммерции, в Метрике откройте **Отчеты** → **Электронная коммерция**.

[Отчеты по электронной коммерции](ru/data/e-commerce-reports)

Данные о визитах и просмотрах появятся в Метрике при первых посещениях сайта после установки плагина. Чтобы посмотреть статистику, в Метрике откройте **Отчеты**. Посмотрите, как работать с отчетами в разделе [Настройка и просмотр отчета](ru/reports/report-general).

## ru/ecommerce/wordpress#updateОбновление плагина

Когда у плагина появится новая версия, сообщение об этом отобразится в панели администратора WordPress. Установить обновление можно одним из способов:

- Перейдите по ссылке из уведомления.
- Выберите плагин на странице **Плагины** → **Установленные**.
- [Скачайте обновленный ZIP-архив](https://metrika-cms-plugins.s3.yandex.net/wordpress/wp-yandex-metrika.zip). Затем на странице **Добавить плагин** нажмите кнопку **Загрузить плагин**, выберите ZIP-архив и установите его.
