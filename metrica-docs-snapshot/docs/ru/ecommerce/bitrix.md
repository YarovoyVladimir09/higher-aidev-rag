# Подключение модуля для 1С-Битрикс

Команда Яндекс Метрики разработала официальный бесплатный модуль для установки на сайт счетчика веб-аналитики. Модуль работает на версии 1С-Битрикс 18.0 и выше, поддерживает все редакции «1С-Битрикс: Управление сайтом».

Возможности модуля «Яндекс Метрика»:

- Добавление новых счетчиков Метрики с включенными по умолчанию опциями: [Электронная коммерция](ru/ecommerce/about); [Вебвизор](ru/webvisor/info); [Карта кликов](ru/behavior/click-map).
- Передача [событий электронной коммерции](ru/ecommerce/data): просмотр карточки товара; добавление товара в корзину; удаление товара из корзины; покупка.
- Детализация [передаваемых данных о товаре](ru/ecommerce/data#product_data).

В результате анализа совместно с компанией «1С-Битрикс» обнаружены и устранены потенциальные уязвимости в модуле **yandex.metrika**.

Специалисты выявили несколько проблем безопасности. Существовал риск компрометации данных, подмены запросов или внедрения вредоносного кода злоумышленниками. Все найденные уязвимости оперативно устранены.

Внесенные изменения:

- Усилена аутентификация при вызове AJAX-действий — доступ к критическим операциям защищает проверка CSRF-токена и метода запроса.
- Исключена возможность подмены идентификатора пользователя через Cookie — идентификация теперь привязана к серверной сессии.
- Устранены риски, которые связаны с небезопасной десериализацией данных и использованием потенциально опасных функций (например, extract).
- Проведена тщательная валидация и экранирование всех пользовательских данных, выводимых в JavaScript-контекст, что предотвращает межсайтовый скриптинг (XSS).
- Добавлена строгая проверка CSRF-токена при сохранении настроек модуля в административной панели.
- Исправлен метод определения IP-адреса посетителя — теперь используется штатный механизм платформы, исключающий подмену IP через HTTP-заголовки.

Все изменения повышают уровень безопасности сайтов и не влияют на стандартную функциональность Яндекс.Метрики. Обновление не требует дополнительных действий со стороны администраторов — достаточно установить актуальную версию модуля.

Рекомендуем пользователям модуля **yandex.metrika** выполнить обновление для максимальной защиты проектов.

## ru/ecommerce/bitrix#generalУстановка и настройка модуля

### ru/ecommerce/bitrix#startНачало работы

1. Если у вас еще нет счетчика Метрики, [создайте его](ru/quick-start). Убедитесь, что адрес сайта указан правильно в настройках счетчика. Для этого перейдите в Метрику на страницу **Настройки**. Обратите внимание на поле **Адрес** — здесь должен быть указан адрес сайта, на который вы хотите установить модуль.
2. source: ru/_includes/ecommerce/enabling/id-enabling/3.md В настройках счетчика включите опцию **Электронная коммерция**. В код счетчика добавится контейнер для сбора данных `dataLayer`. endsource: ru/_includes/ecommerce/enabling/id-enabling/3.md
3. Убедитесь, что в 1С-Битрикс не активирован другой аналогичный модуль, устанавливающий счетчик Метрики. Для этого в панели администратора откройте **Marketplace** → **Установленные решения** и поищите модуль по названию «Метрика», «Metrica» или «Metrika». Если такой модуль установлен, удалите его.

### ru/ecommerce/bitrix#uploadШаг 1 — Установка модуля

Перейдите в панель администратора 1С-Битрикс, авторизуйтесь и добавьте модуль одним из способов:

1. Откройте **Marketplace** → **Установленные решения**, найдите модуль с названием «Яндекс Метрика».
2. Нажмите значок и выберите **Установить**.

1. Перейдите в [1С-Битрикс: Маркетплейс](http://marketplace.1c-bitrix.ru/solutions), найдите модуль с названием «Яндекс Метрика».
2. Откройте модуль и нажмите кнопку **Установить**.

1. Скачайте установочный ZIP-архив с кодировкой [UTF8](https://metrika-cms-plugins.s3.yandex.net/1c-bitrix/yandex.metrika.utf8.zip) или [CP1251](https://metrika-cms-plugins.s3.yandex.net/1c-bitrix/yandex.metrika.cp1251.zip).
2. Перейдите в административную панель 1С-Битрикс на страницу **Контент**.
3. Выберите раздел **Файлы и папки** → **bitrix** → **modules** и откройте последнюю страницу списка модулей.
4. Нажмите кнопку **Загрузить** → **Добавить файл** и выберите ZIP-архив с модулем Яндекс Метрики.
5. Нажмите кнопку **Сохранить**. Архив загрузится в каталог `modules` на вашем сервере.
6. Распакуйте архив: найдите его в списке модулей, нажмите значок и выберите **Распаковать**. Убедитесь, что каталог `yandex.metrika` появился в списке.
7. Откройте **Marketplace** → **Установленные решения**, найдите модуль с названием «Яндекс Метрика». Нажмите значок и выберите **Установить**.

### ru/ecommerce/bitrix#setШаг 2 — Настройка модуля

1. Перейдите на страницу **Настройки** → **Настройки продукта** → **Настройки модулей** → **Яндекс Метрика**.
2. Выберите сайт.
3. Укажите номер счетчика, который установлен на вашем сайте. Если модуль обнаружил на сайте счетчик Метрики, то поля будут уже заполнены. Проверьте их. [Как найти номер счетчика](ru/general/tag-id)
4. По умолчанию опция **Вебвизор** включена. Она позволяет [записывать визиты посетителей](ru/webvisor/info), чтобы вы могли более полно анализировать статистику. При необходимости вы можете отключить Вебвизор в любой момент.
5. Сохраните изменения.

Совет

Поле **Свойство Бренда** заполнять необязательно. [Заполните его](ru/ecommerce/bitrix#brand), если хотите отслеживать в Метрике статистку по бренду товаров. Например, какой бренд наиболее популярен у покупателей.

Кроме этого, чтобы получать более подробную статистику о товарах (например, какие товары чаще просматривают посетители), [настройте событие detail](ru/ecommerce/bitrix#detail).

### ru/ecommerce/bitrix#checkШаг 3 — Проверка отправки данных

Проверьте, отправляются ли в Метрику данные:

- [электронной коммерции](ru/ecommerce/check)
- [о посещениях на сайте](ru/general/check-counter)

Данные электронной коммерции появятся в Метрике спустя несколько часов после их первой отправки. Чтобы посмотреть отчеты электронной коммерции, в Метрике откройте **Отчеты** → **Электронная коммерция**.

[Отчеты по электронной коммерции](ru/data/e-commerce-reports)

Данные о визитах и просмотрах появятся в Метрике при первых посещениях сайта после установки модуля. Чтобы посмотреть статистику, в Метрике откройте **Отчеты**. Посмотрите, как работать с отчетами в разделе [Настройка и просмотр отчета](ru/reports/report-general).

## ru/ecommerce/bitrix#funcДополнительные настройки

### ru/ecommerce/bitrix#brandКак заполнить поле «Свойство Бренд» в настройках модуля

В Метрику можно передавать информацию о брендах вашего интернет-магазина. На основе этих данных в Метрике [формируется отчет](ru/reports/popular-brands), который помогает, например, определить наиболее популярный бренд у покупателей или узнать, какой бренд приносит наибольшую прибыль.

Примечание

В шаблонах 1С-Битрикс может быть несколько каталогов товаров. В настройках модуля Метрики отображаются свойства бренда только активных каталогов. Рекомендуем заполнить все доступные поля **Свойство Бренд** для корректной передачи данных в Метрику.

Чтобы найти значение свойства:

1. Перейдите в административную панель 1С-Битрикс.
2. Перейдите в раздел **Контент** → **Типы инфоблоков** → **Каталоги** и выберите каталог.
3. Справа откройте вкладку **Свойства**.
4. В списке найдите поле, которое отвечает за бренд.
5. Укажите название поля в настройках модуля «Яндекс Метрика».

### ru/ecommerce/bitrix#detailКак передавать информацию о просмотрах товаров (свойство detail)

В Метрику можно передавать данные о просмотре товаров, чтобы отчеты по электронной коммерции содержали более подробную информацию. Например, таким образом формируется [Отчет «Популярные товары»](ru/reports/popular-goods).

Чтобы настроить события, отвечающие за просмотр товара, нужно внести изменения в код файла `element.php` шаблона компонента `bitrix:catalog` на вашем сайте.

Внимание

Путь до файла `element.php` может различаться в шаблонах разных сайтов.

1. Авторизуйтесь на сайте как администратор.
2. На вкладке **Сайт** включите **Режим правки**. Примечание Если раньше вы редактировали шаблон, переходите к п. 6 инструкции.
3. На сайте откройте карточку товара и наведите курсор на область компонента каталога — появится меню.
4. Нажмите значок , выберите каталог, а затем — **Копировать шаблон компонента**.
5. В поле **Копировать в шаблон сайта** выберите **текущий** и сохраните изменения.
6. [Найдите](ru/ecommerce/bitrix#found-element) и откройте файл `element.php`. В коде найдите строку вида: $elementId = $APPLICATION->IncludeComponent('bitrix:catalog.element', 'bootstrap_v4', $componentElementParams, $component ); Если до компонента `bitrix:catalog.element` нет `"$elementId = "`, добавьте в код переменную самостоятельно.
7. После нее добавьте `$APPLICATION->IncludeComponent("yandex.metrika:detail", "", array("PRODUCT_ID" => $elementId), $component);`. Убедитесь, что регистр переменных и названий функций кода `detail` совпадает с регистром переменных файла `element.php`. Пример кода ... $elementId = $APPLICATION->IncludeComponent('bitrix:catalog.element', 'bootstrap_v4', $componentElementParams, $component ); $APPLICATION->IncludeComponent("yandex.metrika:detail", "", array("PRODUCT_ID" => $elementId), $component); ...
8. Нажмите кнопку **Сохранить**.

1. На вкладке **Сайт** включите **Режим правки**.
2. На сайте откройте карточку товара и наведите курсор на область компонента каталога — появится меню.
3. Нажмите значок , выберите каталог, а затем — **Редактировать шаблон компонента**.
4. Убедитесь, что в открывшемся окне отображается файл `element.php`. Путь до файла указан в названии окна.

После установки и настройки модуля посмотрите лог ошибок. Для этого откройте модуль в административной панели 1С-Битрикс. Вы можете задать вопросы через [форму ниже](ru/ecommerce/bitrix#form) или на сайте 1С-Битрикс (в правом нижнем углу нажмите кнопку **Техподдержка**).

- Устаревшая версия 1С-Битрикс. Проверьте, готова ли к установке новая версия и установите ее. Для этого в панели администратора перейдите на страницу **Marketplace** → **Обновление платформы**.
- Указанное вами свойство бренда отсутствует на сайте.
- Номер счетчика содержит символы, отличные от цифр.

- Перейдите по ссылке из уведомления.
- Выберите модуль на странице **Marketplace** → **Установленные решения**.
- На странице [1С-Битрикс: Маркетплейс](https://marketplace.1c-bitrix.ru/).
