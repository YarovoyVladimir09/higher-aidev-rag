# Как подключить электронную коммерцию с помощью плагина для CMS

1. [Перейдите в Метрику](https://metrika.yandex.ru).
2. Выберите счетчик, к которому нужно подключить электронную коммерцию.
3. В настройках счетчика включите опцию **Электронная коммерция**. В код счетчика добавится контейнер для сбора данных `dataLayer`.
4. Установите плагин в вашу CMS. Cписок всех плагинов можно посмотреть в разделе **Интеграции** → **CMS**. В списке представлены решения, созданные как сторонними разработчиками, так и командой Яндекс Метрики. Для наиболее популярных CMS разработаны официальные плагины Метрики: [WordPress](ru/ecommerce/wordpress) [OpenCart](ru/ecommerce/opencart) [1С-Битрикс](ru/ecommerce/bitrix)
5. Спустя несколько часов после первой передачи данных появится статистика в Метрике. Чтобы посмотреть отчеты, в Метрике откройте **Отчеты** → **Электронная коммерция**.
