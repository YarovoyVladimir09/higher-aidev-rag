# Как подключить электронную коммерцию для Tilda

- [Как передавать данные о заказах](ru/ecommerce/tilda#order)
- [Дополнительные настройки](ru/ecommerce/tilda#extra)

## ru/ecommerce/tilda#orderКак передавать данные о заказах

1. В настройках счетчика Метрики включите опцию **Электронная коммерция**: **Настройки** → **Счетчик** → **Электронная коммерция**.
2. Переопубликуйте в Tilda все страницы сайта и данные о заказах начнут автоматически поступать в Метрику. Никаких других настроек больше не требуется.

## ru/ecommerce/tilda#extraДополнительные настройки

- Чтобы получать статистику о просмотрах товаров или услуг, подключите к блоку с карточками продуктов [Каталог товаров](https://blog.tilda.cc/catalog).
- Чтобы получать статистику о добавлении в корзину, поставьте галочку в настройках блока **ST100** → **Дополнительные настройки** → **Отправлять данные о добавлении в корзину в системы аналитики**.

Если у вас возникнут вопросы о настройке электронной коммерции, обращайтесь в [Службу поддержки](ru/troubleshooting). Специалисты Метрики помогут решить проблему.
