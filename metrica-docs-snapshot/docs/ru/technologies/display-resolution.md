# Отчет «Разрешение дисплея»

- [Какие задачи может решать отчет](ru/technologies/display-resolution#kakie-zadachi-mozhet-reshat-otchet)
- [Структура и настройки](ru/technologies/display-resolution#struktura-i-nastrojki)

Отчет содержит статистику по разрешению дисплеев устройств посетителей.

Посмотреть отчет: **Отчеты** → **Технологии** → **Разрешения дисплея**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/resolution?period=week&selected_rows=%5B%7B%22path%22%3A%5B%221366%22%5D%2C%22name%22%3A%5B%221366%22%5D%7D%2C%7B%22path%22%3A%5B%22360%22%5D%2C%22name%22%3A%5B%22360%22%5D%7D%2C%7B%22path%22%3A%5B%221600%22%5D%2C%22name%22%3A%5B%221600%22%5D%7D%2C%7B%22path%22%3A%5B%221920%22%5D%2C%22name%22%3A%5B%221920%22%5D%7D%2C%7B%22path%22%3A%5B%221280%22%5D%2C%22name%22%3A%5B%221280%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/technologies/display-resolution#kakie-zadachi-mozhet-reshat-otchetКакие задачи может решать отчет

В отчете отображены самые популярные соотношения сторон дисплеев устройств, с которых посетители заходят на сайт.

Для этого вы можете добавить группировку **Тип устройства**.

## ru/technologies/display-resolution#struktura-i-nastrojkiСтруктура и настройки

Данные в отчете сгруппированы по логической ширине и высоте дисплея.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике, за исключением [моделей атрибуции](ru/reports/attribution-model).
