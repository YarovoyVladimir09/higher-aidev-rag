# Отчет «Устройства»

- [Какие задачи может решать отчет](ru/technologies/devices#kakie-zadachi-mozhet-reshat-otchet)
- [Структура и настройки отчета](ru/technologies/devices#struktura-i-nastrojki-otcheta)

Отчет содержит статистику по моделям устройств, которые используют посетители.

Посмотреть отчет: **Отчеты** → **Технологии** → **Устройства**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/tech_devices?period=week&selected_rows=%5B%7B%22path%22%3A%5B%22desktop%22%5D%2C%22name%22%3A%5B%22%D0%9F%D0%9A%22%5D%7D%2C%7B%22path%22%3A%5B%22mobile%22%5D%2C%22name%22%3A%5B%22%D0%A1%D0%BC%D0%B0%D1%80%D1%82%D1%84%D0%BE%D0%BD%D1%8B%22%5D%7D%2C%7B%22path%22%3A%5B%22tablet%22%5D%2C%22name%22%3A%5B%22%D0%9F%D0%BB%D0%B0%D0%BD%D1%88%D0%B5%D1%82%D1%8B%22%5D%7D%2C%7B%22path%22%3A%5B%22tv%22%5D%2C%22name%22%3A%5B%22%D0%A2%D0%92%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).
