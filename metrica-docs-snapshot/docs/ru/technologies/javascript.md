# Отчет «Наличие JavaScript»

- [Какие задачи может решать отчет](ru/technologies/javascript#kakie-zadachi-mozhet-reshat-otchet)
- [Структура и настройки отчета](ru/technologies/javascript#struktura-i-nastrojki-otcheta)

В отчете отображена информация о том, включен ли JavaScript (ECMAScript) у посетителей. Если он включен, владелец сайта сможет показывать посетителю сценарии с использованием JavaScript.

Посмотреть отчет: **Отчеты** → **Технологии** → **Наличие JavaScript**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/javascript?period=week&selected_rows=%5B%7B%22path%22%3A%5B%22yes%22%5D%2C%22name%22%3A%5B%22JavaScript+%D0%B2%D0%BA%D0%BB%D1%8E%D1%87%D0%B5%D0%BD%22%5D%7D%2C%7B%22path%22%3A%5B%22no%22%5D%2C%22name%22%3A%5B%22JavaScript+%D0%BE%D1%82%D0%BA%D0%BB%D1%8E%D1%87%D0%B5%D0%BD+%D0%B8%D0%BB%D0%B8+%D0%BD%D0%B5+%D0%BF%D0%BE%D0%B4%D0%B4%D0%B5%D1%80%D0%B6%D0%B8%D0%B2%D0%B0%D0%B5%D1%82%D1%81%D1%8F%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/technologies/javascript#struktura-i-nastrojki-otchetaСтруктура и настройки отчета

Данные в отчете разделены на две группы:

- JavaScript включен;
- JavaScript отключен или не поддерживается.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике, за исключением [моделей атрибуции](ru/reports/attribution-model).
