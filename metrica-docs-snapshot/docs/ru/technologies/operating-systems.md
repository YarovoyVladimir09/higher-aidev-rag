# Отчет «Операционные системы»

- [Какие задачи может решать отчет](ru/technologies/operating-systems#kakie-zadachi-mozhet-reshat-otchet)
- [Структура и настройки отчета](ru/technologies/operating-systems#struktura-i-nastrojki-otcheta)

Отчет содержит статистику по операционным системам и их версиям, которые используют посетители.

Посмотреть отчет: **Отчеты** → **Технологии** → **Операционные системы**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/os?period=week&selected_rows=%5B%7B%22path%22%3A%5B%22100%22%5D%2C%22name%22%3A%5B%22Windows%22%5D%7D%2C%7B%22path%22%3A%5B%22108%22%5D%2C%22name%22%3A%5B%22Google+Android%22%5D%7D%2C%7B%22path%22%3A%5B%22103%22%5D%2C%22name%22%3A%5B%22Mac+OS%22%5D%7D%2C%7B%22path%22%3A%5B%22107%22%5D%2C%22name%22%3A%5B%22iOS%22%5D%7D%2C%7B%22path%22%3A%5B%22101%22%5D%2C%22name%22%3A%5B%22GNU%2FLinux%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/technologies/operating-systems#struktura-i-nastrojki-otchetaСтруктура и настройки отчета

Данные в отчете сгруппированы по операционным системам и их версиям.

Группа **Windows** включает операционную систему Windows 10 и последующие версии. Операционная система Windows 11 учитывается в отдельной группе **Windows 11**, если браузер посетителя передает информацию о пользовательском агенте (User-Agent Client Hints).

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике, за исключением [моделей атрибуции](ru/reports/attribution-model).
