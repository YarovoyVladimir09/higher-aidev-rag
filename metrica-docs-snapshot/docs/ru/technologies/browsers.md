# Отчет «Браузеры»

- [Какие задачи может решать отчет](ru/technologies/browsers#kakie-zadachi-mozhet-reshat-otchet)
- [Структура и настройки отчета](ru/technologies/browsers#struktura-i-nastrojki-otcheta)

Отчет содержит статистику по браузерам и их версиям, которые используют посетители.

Посмотреть отчет: **Отчеты** → **Технологии** → **Браузеры**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/browsers?period=week&iselected_rows=%5B%7B%22path%22%3A%5B%226%22%5D%2C%22name%22%3A%5B%22Google+Chrome%22%5D%7D%2C%7B%22path%22%3A%5B%225%22%5D%2C%22name%22%3A%5B%22MSIE%22%5D%7D%2C%7B%22path%22%3A%5B%223%22%5D%2C%22name%22%3A%5B%22Firefox%22%5D%7D%2C%7B%22path%22%3A%5B%2283%22%5D%2C%22name%22%3A%5B%22Chrome+Mobile%22%5D%7D%2C%7B%22path%22%3A%5B%2270%22%5D%2C%22name%22%3A%5B%22%D0%AF%D0%BD%D0%B4%D0%B5%D0%BA%D1%81.%D0%91%D1%80%D0%B0%D1%83%D0%B7%D0%B5%D1%80%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/technologies/browsers#struktura-i-nastrojki-otchetaСтруктура и настройки отчета

Данные в отчете сгруппированы по браузерам и их версиям, в том числе полным версиям (например, Яндекс Браузер 19.4).

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике, за исключением [моделей атрибуции](ru/reports/attribution-model).
