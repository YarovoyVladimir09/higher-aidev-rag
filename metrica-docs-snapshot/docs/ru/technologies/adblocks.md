# Отчет «Наличие блокировщиков рекламы»

- [Какие задачи может решать отчет](ru/technologies/adblocks#kakie-zadachi-mozhet-reshat-otchet)
- [Структура и настройки отчета](ru/technologies/adblocks#struktura-i-nastrojki-otcheta)

Отчет содержит информацию о визитах посетителей, у которых установлены наиболее распространенные блокировщики рекламы: Adblock, Adblock Plus, Adguard, uBlock и другие. Некоторые технологии могут блокировать сам счетчик Метрики, поэтому статистические показатели могут отличаться от реальных в меньшую сторону.

- AdBlock
- AdBlocker Lite
- AdBlocker Ultimate
- Adblock Plus
- AdGuard Антибаннер
- Ghostery
- StopAll Ads
- uBlock
- uBlock Origin
- uBlock Plus Adblocker

Посмотреть отчет: **Отчеты** → **Технологии** → **Наличие блокировщиков рекламы**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/adblock?period=week&selected_rows=%5B%7B%22path%22%3A%5B%22no%22%5D%2C%22name%22%3A%5B%22%D0%91%D0%BB%D0%BE%D0%BA%D0%B8%D1%80%D0%BE%D0%B2%D1%89%D0%B8%D0%BA+%D0%BD%D0%B5+%D0%B8%D1%81%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D1%83%D0%B5%D1%82%D1%81%D1%8F%22%5D%7D%2C%7B%22path%22%3A%5B%22yes%22%5D%2C%22name%22%3A%5B%22%D0%91%D0%BB%D0%BE%D0%BA%D0%B8%D1%80%D0%BE%D0%B2%D1%89%D0%B8%D0%BA+%D0%B8%D1%81%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D1%83%D0%B5%D1%82%D1%81%D1%8F%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

## ru/technologies/adblocks#kakie-zadachi-mozhet-reshat-otchetКакие задачи может решать отчет

Отчет покажет статистику по наличию блокировщиков рекламы в браузерах посетителей.

Информация о блокировщиках рекламы может быть полезна при анализе источников посещаемости сайта. Отчет позволяет понять, какой процент посещений из разных источников был заблокирован.

1. Перейдите в раздел **Отчеты** → **Источники** → **Источники, сводка**.
2. Добавьте метрику **Метрики** → **Технологии** → **Блокировка рекламы**.

Иногда могут быть полезны данные об операционной системе и браузере, на которых установлены блокировщики рекламы.

1. Перейдите в раздел **Отчеты** → **Технологии** → **Операционные системы**.
2. Добавьте группировку **Группировки** → **Технологии** → **Браузер** и метрику **Метрики** → **Технологии** → **Блокировка рекламы**.
