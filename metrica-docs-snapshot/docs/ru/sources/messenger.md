# Отчет «Мессенджеры»

- [Какие задачи может решать отчет](ru/sources/messenger#case)
- [Структура и настройки отчета](ru/sources/messenger#data)

Отчет содержит информацию о переходах посетителей на ваш сайт из мессенджеров.

Посмотреть отчет: **Отчеты** → **Источники** → **Мессенджеры**.

Для определения данного источника Яндекс Метрика использует [реферер](https://ru.wikipedia.org/wiki/HTTP_referer) и [UTM-метки](ru/general/source-tags#utm-construct).

[Список меток для мессенджеров](ru/sources/messenger#full-list-cut)

## ru/sources/messenger#caseКакие задачи может решать отчет

Отчет покажет, из каких мессенджеров приходят посетители на ваш сайт.

Сделать это можно, ориентируясь на показатель отказов. Чем выше показатель отказов, тем меньше сайт вовлекает посетителей — они уходят в течение 15 секунд, просмотрев только одну страницу.

## ru/sources/messenger#dataСтруктура и настройки отчета

Метрика различает следующие мессенджеры:

- Skype
- Telegram
- Viber
- WeChat
- WhatsApp

Для определения источника используйте UTM-метки:

- `utm_medium` (обязательная) со значением `messenger` (рекомендуется) или `social`.
- `utm_source`. Метка используется для определения названия мессенджера. Например, `utm_source=viber`. Если этой метки нет в URL, она указана без значения или значение не известно Метрике, то источник будет отнесен к типу **Другое, определено по меткам**. Полный список меток `skype` — для Skype; `telegram` — для Telegram; `viber` — для Viber; `wechat` — для WeChat; `whatsapp` — для WhatsApp.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
