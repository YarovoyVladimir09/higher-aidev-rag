# Подключение статистики по монетизации

- [Подключение отчетов](ru/sources/monetization#activate)
- [Просмотр статистики](ru/sources/monetization#stat)

С помощью отчетов группы «Монетизация» владельцы сайтов, участвующие в Рекламной сети Яндекса или Adfox, могут анализировать эффективность рекламы и доход от нее.

## ru/sources/monetization#activateПодключение отчетов

Для просмотра отчета [включите показ отчетов и укажите счетчик Метрики](ru/sources/yan-settings#activate) в интерфейсе Рекламной сети Яндекса.

По умолчанию доступ к просмотру отчетов группы «Монетизация» ограничен. Вы можете [управлять правами доступа](ru/sources/yan-settings#access).

Для просмотра отчета [включите показ отчетов по Adfox и укажите счетчик Метрики](ru/sources/adfox-settings#activate) в Adfox.

По умолчанию доступ к просмотру отчетов группы «Монетизация» ограничен. Вы можете [управлять правами доступа](ru/sources/adfox-settings#access).

## ru/sources/monetization#statПросмотр статистики

Чтобы посмотреть отчеты, перейдите в Метрику и выберите в меню **Отчеты** → **Монетизация**.

Подробно об отчетах:

- [Отчеты группы «Рекламная сеть Яндекса»](ru/reports/partner)
- [Отчеты группы “Adfox”](ru/reports/adfox)
