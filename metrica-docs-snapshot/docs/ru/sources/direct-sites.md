# Отчет «Директ, площадки»

- [Какие задачи может решать отчет](ru/sources/direct-sites#case)
- [Условия для получения отчета](ru/sources/direct-sites#ness)
- [Структура и настройки отчета](ru/sources/direct-sites#data)
- [Вопросы и ответы](ru/sources/direct-sites#qanda)[Узнайте больше](ru/sources/direct-sites#uznajte-bolshe)

Отчет содержит статистику по площадкам, на которых размещено ваше продвижение через Яндекс Директ. Отчет помогает оценивать качество проведения кампании, например, ориентируясь на показатель отказов.

Статистика основана на учтенных кликах — кликах, которые прошли проверку [системой защиты от фрода](https://yandex.ru/support/direct/technologies-and-services/antifraud.html) в Яндекс Директе.

Посмотреть отчет: **Отчеты** → **Источники** → **Директ, площадки**.

## ru/sources/direct-sites#caseКакие задачи может решать отчет

Отчет помогает анализировать эффективность площадок, на которых размещены ваши объявления. Это можно сделать, изучив соотношение нескольких показателей, например, количества посетителей и доли отказов. Такой анализ позволит [отключить малоэффективные тематические площадки](https://yandex.ru/support/direct/impressions/blocked-sites.html).

## ru/sources/direct-sites#nessУсловия для получения отчета

Чтобы отчеты группы «Директ» начали отображаться в Метрике, в Директе на странице **Редактирование кампании** в блоке **Счетчики Яндекс Метрики** выберите счетчик, установленный на вашем сайте. Если счетчик не привязан к кампании **Директа**, в отчетах Метрики переходы с объявлений будут отнесены к источнику «Чужие кампании».

Во все ссылки перехода по объявлениям автоматически добавится метка `yclid` с уникальным номером клика. Убедитесь, что ваш сайт корректно открывает ссылки с метками. При переходе по объявлению счетчик Метрики на вашем сайте отследит метку и свяжет визит с конкретным кликом.

## ru/sources/direct-sites#dataСтруктура и настройки отчета

Данные в отчете объединены в группы:

- Поиск. Объявления показываются в результатах поиска Яндекса.
- Сети. Объявления показываются на тематических площадках [Рекламной сети Яндекса и во внешних сетях](https://yandex.ru/support/direct/general/yan.html). Группа отображается в отчете, если в настройках стратегии показов в Яндекс Директе включены показы в сетях. [Стратегии показов](https://yandex.ru/support/direct/strategies/select-strategy.html)

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.

## ru/sources/direct-sites#qandaВопросы и ответы

Чтобы статистика отображалась корректно, в параметрах кампании в Директе заполните поле **Cчетчики Метрики**. Примерно через сутки отметка **Чужая кампания** пропадет и вы сможете увидеть детальную статистику по рекламным кампаниям.

Чтобы другие системы веб-аналитики корректно учитывали переходы по объявлениям Яндекс Директа, настройте их одним из способов:

- добавьте в ссылки объявлений [специальные метки](https://yandex.ru/support/direct/statistics/url-tags.html#url-tags__utm);
- на странице **Параметры кампании** в Яндекс Директе подключите [автоматическое добавление метки OpenStat](https://yandex.ru/support/direct/statistics/url-tags.html#url-tags__openstat-title).

Статистика Яндекс Директа показывает клики, которые не были отфильтрованы [системой защиты от фрода](https://yandex.ru/support/direct/technologies-and-services/antifraud.html) (они называются учтенными). Яндекс Метрика отображает количество визитов и по учтенным кликам с объявления (отчеты группы “Директ”), и по неучтенным (отчет [Рекламные системы](ru/reports/ad-systems)).

Строка **Яндекс: Не определено** означает, что визит, который регистрирует Яндекс Метрика, не удалось сопоставить с конкретным переходом по объявлению Яндекс Директа. Поэтому, помимо самой рекламной системы, не получилось определить остальные данные: кампанию, фразу, запрос и другие.

Причиной появления строки **Яндекс: Не определено** в источнике Яндекс Директ может служить разрыв во времени между генерацией метки `yclid` в Яндекс Директе и записью визита в Яндекс Метрике. Это может произойти в следующих случаях:

- посетитель перешел по объявлению и оставил страницу перехода открытой во вкладке браузера, а позже обновил страницу;
- посетитель перешел по ссылке из объявления, а затем переслал ее кому-то другому — повторный визит по этой ссылке также не получится связать с кликом из объявления Яндекс Директа.

Проверьте, что метка составлена правильно. UTM-метка состоит из пяти параметров в любой последовательности, разделенных символом `&`:

```
http://example.com/?utm_source=yandex&utm_medium=cpc&utm_campaign=кампания123&utm_content=объявление456&utm_term=фраза
```

Если URL страницы уже содержит параметры, метку нужно добавить через символ `&`:

```
http://example.com/?uid=1234&utm_source=yandex&utm_medium=cpc&utm_campaign=кампания123&utm_content=объявление456&utm_term=фраза
```

Стандартный отчет по меткам UTM представлен в виде дерева: `utm_source`, `utm_medium`, `utm_campaign`, `utm_content` и `utm_term`.

Если вы используете все UTM-метки, кроме `utm_content`, данные по `utm_term` не будут доступны в стандартном отчете [О группе отчетов «Метки»](ru/reports/tags). Чтобы метки начали отображаться, в отчете удалите группировку **utm_content**.

Названия параметров меток стандартизированы: `utm_source`, `utm_medium`, `utm_campaign`, `utm_content` и `utm_term`. Менять их или создавать собственные (`utm_keyword`, `utm_slovo`) нельзя, так как они не будут являться частью UTM-меток, и данные по ним не будут попадать в отчет «Метки UTM».

Например:

```
http://example.com?utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_keyword={keyword}
```

где `utm_keyword` — произвольный параметр.

В отчете «Метки UTM» отобразится информация по параметрам `utm_source`, `utm_medium` и `utm_campaign`. Информация по параметру `utm_keyword` будет доступна только в отчете **Отчеты** → **Содержание** → **По параметрам URL**.

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.

Так происходит, потому что по умолчанию отчеты строятся по модели атрибуции [Последний значимый переход](ru/reports/attribution-model#last-main). Она помогает более точно подсчитать конверсию, поскольку для выбора источника трафика учитывается история визитов посетителя.

Чтобы из отчета пропала статистика по остановленной или архивной кампании, выберите модель [Последний переход](ru/reports/attribution-model#last). Тогда для каждого визита Метрика определит источник перехода в данный момент.
