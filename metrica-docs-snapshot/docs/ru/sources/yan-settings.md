## ru/sources/yan-settings#activateКак подключить отчеты

1. В [интерфейсе Рекламной сети Яндекса](https://partner2.yandex.ru) перейдите к списку сайтов: **Реклама на сайтах** → **Сайты и блоки** → **Сайты**.
2. Напротив нужного сайта нажмите кнопку и выберите **Редактировать**.
3. На вкладке **Общие** включите опцию **Показывать отчеты по РСЯ в Метрике**.
4. В поле **Счетчики Метрики** укажите номер вашего счетчика и сохраните изменения.

2. Напротив нужного ресурса нажмите кнопку и выберите **Редактировать**.

Вам будет доступна статистика по видеоблокам [InStream](https://yandex.ru/support/partner2/video/products-instream/about.html), размещенным в плеере Яндекса, а также по InPage-блокам.

Примечание

Данные в отчетах группы «Монетизация» начинают отображаться в Яндекс Метрике в течение суток после того, как вы подключили счетчик в интерфейсе Рекламной сети Яндекса.

Вы можете пользоваться отчетами, если у вас есть [гостевой доступ](ru/general/access) на редактирование счетчика или [представительский доступ](ru/general/access). Если у вас гостевой доступ типа «Только просмотр», обратитесь к владельцу счетчика, чтобы он дал вам доступ к отчетам.

## ru/sources/yan-settings#accessКак дать доступ к отчетам другому пользователю Метрики

Внимание

Права доступа к группе отчетов «Монетизация» отображаются только для счетчиков, которые подключены в интерфейсе Рекламной сети Яндекса.

Если у пользователя есть [доступ на редактирование](ru/general/access), то ему уже доступны отчеты группы «Монетизация».

Если у пользователя тип доступа «Только просмотр», измените его:

1. Перейдите на страницу **Настройка** → **Доступ**.
2. Нажмите значок напротив нужного пользователя.
3. Выберите тип прав с доступом к группе отчетов «Монетизация». Пользователь сможет просматривать отчеты, добавлять группировки и метрики из группы «Монетизация» в другие отчеты.

Дайте пользователю специальный доступ к вашему счетчику Метрики:

1. Перейдите на страницу **Настройка** → **Доступ**.
2. Нажмите кнопку **Добавить пользователя**.
3. В появившемся окне заполните поля.
4. Выберите тип прав с доступом к группе отчетов «Монетизация». Пользователь сможет просматривать отчеты, добавлять группировки и метрики из группы «Монетизация» в другие отчеты.

## ru/sources/yan-settings#delete-accessКак отменить доступ к отчетам

Измените тип доступа пользователя к счетчику Метрики:

1. Перейдите на страницу **Настройка** → **Доступ**.
2. Нажмите значок напротив нужного пользователя.
3. Выберите тип прав «Только просмотр: без Монетизации».
