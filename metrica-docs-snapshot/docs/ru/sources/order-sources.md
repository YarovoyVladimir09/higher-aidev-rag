# Отчет «Источники заказов из CRM»

- [Какие задачи может решать отчет](ru/sources/order-sources#case)
- [Условия для получения отчета](ru/sources/order-sources#conditions)
- [Структура и настройки отчета](ru/sources/order-sources#data)

С помощью отчета вы можете определить, какие источники привлечения аудитории приносят продажи, а также оценить их прибыльность.

Статистика основана на визитах. Данные дополняются информацией о всех заказах, конверсией в заказ, оплаченных заказах, конверсией в оплату, выручкой и средним чеком.

Посмотреть отчет: **Сквозная аналитика** → **Источники заказов из CRM**.

## ru/sources/order-sources#caseКакие задачи может решать отчет

Используйте данные для дальнейшего успешного прогнозирования прибыльности сайта.

Чтобы добавить метрику «Прибыль» в отчет:

1. Нажмите кнопку **Метрики**.
2. Выберите **Заказы из CRM** → **Прибыль**.

Отчет покажет, насколько эффективен тот или иной источник заказов и сам сайт в целом. Чтобы оценить эффективность источника заказа, обратите внимание на показатели «Конверсии в заказ», «Конверсии в оплату» и «Средний чек». Чем выше показатели по этим метрикам, тем прибыльнее источник заказа.

Обратите внимание на показатель «Прибыль». Это поможет проанализировать прибыльности сайта.

Чтобы добавить метрику «Прибыль» в отчет:

1. Нажмите кнопку **Метрики**.
2. Выберите **Заказы из CRM** → **Прибыль**.

## ru/sources/order-sources#dataСтруктура и настройки отчета

Данные в отчете сгруппированы по источникам визитов, которые принесли заказы.

В отчете собираются данные по метрикам:

| Все заказы | Все переданные из CRM заказы, которые удалось привязать к визитам в Метрике. Спам-заказы не учитываются |
| --- | --- |
| Заказы в работе | Заказы со статусом «В работе», которые удалось привязать к визитам в Метрике |
| Оплаченные заказы | Заказы со статусом «Оплачен», которые удалось привязать к визитам в Метрике |
| Спам-заказы | Заказы со статусом «Спам», которые удалось привязать к визитам в Метрике |
| Отмененные заказы | Заказы со статусом «Отменен», которые удалось привязать к визитам в Метрике |
| Конверсия в заказ | Отношение всех заказов из CRM ко всем визитам на сайт за выбранный в отчете период. Показывает, какой источник трафика приносит больше всего заказов. Спам-заказы не учитываются |
| Конверсия в оплату | Отношение оплаченных заказов ко всем заказам. Если оно равно 100%, все созданные заказы были оплачены. Учитываются только те заказы, которые удалось привязать к визитам в Метрике |
| Средний чек | Отношение выручки ко всем оплаченным заказам. Учитываются только те оплаченные заказы, которые удалось привязать к визитам в Метрике |
| Выручка | Сумма средств, полученных за все заказы. Учитываются только те оплаченные заказы, которые удалось привязать к визитам в Метрике |
| Прибыль | Разница между выручкой и себестоимостью товаров. При расчете прибыли учитываются только те заказы, которые удалось привязать к визитам в Метрике |

Как рассчитываются метрики:
