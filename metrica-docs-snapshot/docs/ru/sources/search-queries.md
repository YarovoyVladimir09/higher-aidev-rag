# Отчет «Поисковые запросы»

- [Какие задачи может решать отчет](ru/sources/search-queries#case)
- [Структура и настройки отчета](ru/sources/search-queries#data)
- [Узнайте больше](ru/sources/search-queries#uznajte-bolshe)

Отчет показывает:

- фразы, по которым пользователи нашли сайт;
- поисковую систему, из которой пользователи перешли на сайт.

Чтобы открыть отчет: **Отчеты** → **Источники** → **Поисковые запросы**.

Пример смотрите на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/phrases?period=month&stateHash=5bbc94b632d435b3739a3d93).

## ru/sources/search-queries#caseКакие задачи может решать отчет

Отчет отображает список фраз, по которым пользователи нашли ссылку на сайт и перешли по ней.

Выделите [сегмент](ru/general/segmentation) с адресом определенной страницы сайта:

1. В условии **Визиты, в которых** нажмите значок .
2. Выберите **Источники** → **Последний источник** → **Поисковая система**.
3. В списке выберите поисковую систему и нажмите **Применить**.

Выделите [сегмент](ru/general/segmentation) с адресом определенной страницы сайта:

1. В условии **Визиты, в которых** нажмите значок .
2. Выберите **Поведение** → **Страница входа**.
3. Укажите адрес страницы.

В отчете отображаются только те запросы, по которым перешло более 10 пользователей в выбранном периоде.

Брендовые запросы могут занимать значительную долю общего трафика. Чтобы получить более точные данные, можно удалить запросы, содержащие название вашей компании или её слоган.

Используйте регулярное выражение `!@ваш_бренд`, где:

- `!` — отрицание условия;
- `@` — вхождение строки (регистр не учитывается).

## ru/sources/search-queries#dataСтруктура и настройки отчета

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.

Данные в отчете объединены в группы:

- Поисковая фраза — запрос, по которому пользователь нашел ссылку на сайт и перешел по ней. Поисковые фразы не отображаются в отчете, если: посещаемость за выбранный период меньше 10; добавлены группировка или сегмент, которые раскрывают анонимность посетителей (например, «Страница входа», «Возраст» и пр.); поисковая система не передает данные в [реферере](https://ru.wikipedia.org/wiki/HTTP_referer).
- Поисковая система — обобщенное название сервиса, на котором есть поиск. Например, Яндекс.

Метрика находит фразы по [рефереру](https://ru.wikipedia.org/wiki/HTTP_referer) и [cookie](https://en.wikipedia.org/wiki/HTTP_cookie) браузера и не определяет их, если:

- истек срок действия cookie (например, пользователь оставил страницу открытой на долгое время, затем обновил ее или закрыл);
- ссылка на страницу из результатов поиска перенаправляет пользователя на другой домен;
- браузер пользователя блокирует cookie.

Примечание

Cookie выставляется на домен, на который посетитель переходит из результатов поиска.
