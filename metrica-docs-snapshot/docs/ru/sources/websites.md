# Отчет «Сайты»

- [Какие задачи может решать отчет](ru/sources/websites#case)
- [Структура и настройки отчета](ru/sources/websites#data)
- [Узнайте больше](ru/sources/websites#uznajte-bolshe)

Отчет содержит информацию о ресурсах, с которых посетители переходят на ваш сайт.

Посмотреть отчет: **Отчеты** → **Источники** → **Cайты**.

Пример отчета можно увидеть на [демосчетчике Яндекс Метрики](https://metrika.yandex.ru/r/stat/sites?period=month&selected_rows=%5B%7B%22path%22%3A%5B%2215079878660006010351%22%5D%2C%22name%22%3A%5B%22https%3A%2F%2Fpassport.yandex.com%2F%22%5D%7D%2C%7B%22path%22%3A%5B%223803573083255445660%22%5D%2C%22name%22%3A%5B%22http%3A%2F%2Fworld-of-gamers.net%2F%22%5D%7D%2C%7B%22path%22%3A%5B%226603532791366781532%22%5D%2C%22name%22%3A%5B%22http%3A%2F%2Fs13.ru%2F%22%5D%7D%2C%7B%22path%22%3A%5B%223939223905403167447%22%5D%2C%22name%22%3A%5B%22http%3A%2F%2Fnetler.ru%2F%22%5D%7D%2C%7B%22path%22%3A%5B%227091127064952598246%22%5D%2C%22name%22%3A%5B%22https%3A%2F%2Fyandex.ru%2F%22%5D%7D%5D&confidence=%7B%22enabled%22%3Afalse%2C%22confidenceLevel%22%3A0.95%2C%22maxDeviation%22%3A0.05%7D).

Для определения данного источника Яндекс Метрика использует [реферер](https://ru.wikipedia.org/wiki/HTTP_referer).

Если вы хотите использовать ваш собственный реферер, добавьте в ссылку, которую размещаете на другом сайте, параметр [utm_referrer](ru/general/source-tags#utm-referrer). Тогда в отчете «Сайты» в качестве источника перехода отобразится значение параметра.

Чтобы уточнить источник перехода, добавьте в ссылку [UTM-метку](ru/general/source-tags#utm-construct)`utm_medium=referral`.

## ru/sources/websites#caseКакие задачи может решать отчет

Отчет покажет, с каких сайтов посетители приходят на ваш сайт.

Для этого нужно выделить [сегмент](ru/general/segmentation) с адресом определенной страницы сайта:

1. В группе условий **Визиты, в которых** нажмите значок .
2. Выберите условие **Поведение** → **Страница входа**.
3. В поле укажите адрес страницы.

## ru/sources/websites#dataСтруктура и настройки отчета

В отчете адрес каждого ссылающегося сайта представлен в виде уровней. Может отображаться до четырех уровней в зависимости от структуры сайта. Например, `https://example.com/1/2/3/page.html` — это страница, на которой стоит ссылка на ваш сайт.

- Внешний реферер ур. 1 — домен сайта, например `https://example.com`.
- Внешний реферер ур. 2 — например, `https://example.com/1/`.
- Внешний реферер ур. 3 — например, `https://example.com/1/2/`.
- Внешний реферер ур. 4 — например, `https://example.com/1/2/3/`.
- Внешний реферер (Внешний реферер ур. 5) — полный адрес ссылающейся страницы, например `https://example.com/1/2/3/page.html`. Каждый уровень является ссылкой, ведущей на сайт-источник.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
