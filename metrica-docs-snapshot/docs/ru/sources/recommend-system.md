# Отчет «Рекомендательные системы»

- [Какие задачи может решать отчет](ru/sources/recommend-system#case)
- [Структура и настройки отчета](ru/sources/recommend-system#data)

Отчет содержит информацию о переходах посетителей на ваш сайт из рекомендательных систем (ленты новостей, тематических статей и т. д.).

Примечание

В отчет не включаются данные по обменным сетям и агрегаторам новостей (Новости, Рамблер/новости, Google News).

Посмотреть отчет: **Отчеты** → **Источники** → **Рекомендательные системы**.

Для определения данного источника Яндекс Метрика использует [реферер](https://ru.wikipedia.org/wiki/HTTP_referer) и [UTM-метки](ru/general/source-tags).

## ru/sources/recommend-system#caseКакие задачи может решать отчет

Отчет покажет, из каких рекомендательных систем приходят посетители на ваш сайт.

Сделать это можно, ориентируясь на показатель отказов. Чем выше показатель отказов, тем меньше сайт вовлекает посетителей — они уходят в течение 15 секунд, просмотрев только одну страницу.

## ru/sources/recommend-system#dataСтруктура и настройки отчета

Метрика различает следующие системы:

- Дзен
- Мир тесен
- Рамблер
- Flipboard
- Google Discover (не учитываются переходы, совершенные на устройствах с операционной системой iOS)
- Opera Personal News
- Pulse (Mail.ru)
- Sony News Suite
- Toutiao

Остальные системы при маркировке метками попадут в раздел **Другая рекомендательная система: определено по меткам**.

Отчет поддерживает [все настройки](ru/reports/report-general), доступные в Яндекс Метрике.
