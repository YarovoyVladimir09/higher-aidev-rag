# Информативные страницы с описаниями товаров

Как в магазине у каждого товара есть свое место, так и на сайте у каждого продукта должна быть отдельная страница.

Знакомство с товаром в интернете происходит с помощью фотографий и текстового описания. Чтобы пользователь мог лучше рассмотреть товар, разместите несколько его фотографий в разных ракурсах. Учтите, что все они должны быть хорошего качества. А чтобы посетитель не чувствовал недостатка информации о товаре, предоставьте ему подробное описание. Также советуем разместить на странице с описанием товара отзывы тех, кто его уже купил. Это может повлиять на решение посетителя сделать заказ.

Познакомьте пользователя с ассортиментом вашего магазина с помощью блока «Похожие товары». Если просматриваемый товар по какой-либо причине пользователю не подойдет, он сможет выбрать аналогичный в вашем же магазине. Блок «Вместе с этим покупают» расскажет посетителю, что будет полезно при использовании этого товара и привлечет внимание клиентов к другим категориям продуктов.

Чтобы клиенту было проще сделать покупку, поместите кнопку [Купить](ru/important/buy-button) рядом с каждым товаром.

Товар с ценой продается лучше, чем товар, стоимость которого нужно узнавать дополнительно. Поэтому мы рекомендуем указать [цену](ru/important/price) рядом с описанием и фотографиями.

Примечание

Чтобы определить, какое количество пользователей из Рекламной сети Яндекса заказывают товар на вашем сайте, задайте в Яндекс Метрике цель — посещение страницы с подтверждением заказа.

Отчет [Вебвизор](ru/webvisor/info) покажет вам в формате видео, как посетители передвигаются по вашему сайту, и вы легко выявите ошибки в навигации.
