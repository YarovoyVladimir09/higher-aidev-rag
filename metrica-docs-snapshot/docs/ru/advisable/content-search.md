# Качественный поиск по содержимому

В обычном магазине у посетителей есть два способа найти товар: самостоятельно по указателям или с помощью продавца-консультанта. Посетители интернет-магазинов часто предпочитают сразу получить нужную информацию. Чтобы у них была такая возможность, вы можете сделать поиск по сайту. Важно, чтобы результаты поиска точно соответствовали запросу. В противном случае, если пользователь не найдет имеющийся в наличии товар, он решит, что его просто нет.

Рекомендуем добавить возможность сравнения и сортировки результатов поиска (например, по цене, популярности, новизне и т. д.). В этом случае посетителю будет легче выбрать.

Если товаров много и у них есть четкие характеристики, можно сделать расширенный поиск. Посетитель сможет быстро получить список товаров, полностью удовлетворяющих его требованиям, а значит — приблизиться к покупке.

Примечание

В отчетах Яндекс Метрики вы можете узнать, сколько посетителей пользуется поиском на вашем сайте. [Карта кликов](ru/behavior/click-map) покажет популярность строки поиска относительно других элементов страницы.
