# Простая форма заказа

В обычном магазине не нужно заполнять никаких форм (если это не кредит), а в интернет-магазине заполнить форму заказа необходимо. При этом заполнение формы заказа — последний шаг при покупке товара. Не делайте его сложным, не оттягивайте момент покупки.

Форма заказа должна быть максимально простой. Рекомендуем спрашивать только существенную для заказа информацию. Например, при доставке — телефон или e-mail и адрес заказчика, а при самовывозе — только телефон или e-mail.
