# Структурированные тексты

Много читать человек готов, когда открывает «Войну и мир», а не когда заходит на продающий сайт. Среди большого количества сведений посетитель может не увидеть нужных и уйти на другой ресурс. Поэтому размещайте на сайте только важную и интересную информацию.

Если вашему сайту необходимо много больших текстов, их лучше разбить на логические части и снабдить подзаголовками. Хорошо структурированную информацию воспринимать гораздо легче.

Примечание

Проанализировать поведение пользователей на страницах с большими текстовыми блоками можно с помощью отчета Яндекс Метрики [Вебвизор](ru/webvisor/info).
