# Грамотные тексты

В обычном магазине посетитель может увидеть товар воочию и подержать его в руках. При заказе в интернет-магазине знакомство с товаром происходит с помощью описания и фотографии.

Не допускайте, чтобы в описании товара встречались орфографические, грамматические и пунктуационные ошибки. В противном случае посетитель может отказаться от покупки, поскольку грамотность у многих ассоциируется с компетентностью.
