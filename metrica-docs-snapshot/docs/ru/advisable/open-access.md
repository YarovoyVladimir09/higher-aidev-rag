# Отсутствие регистрации при входе

Регистрация при входе на сайт может отпугнуть часть пользователей. Одни не захотят раскрывать свои личные данные, другим будет просто лень ее проходить. Регистрация отсеивает неопытных, подозрительных и знающих об альтернативе пользователей, а также оттягивает момент активных действий на сайте. Не требуйте от посетителя пройти регистрацию, пока он не определился с выбором и не подошел к формированию заказа. Если это возможно, сделайте регистрацию необязательной.

Если регистрация при входе на сайт для вас важна, сократите ее форму до минимума. Просите предоставить только ту информацию, без которой вы не можете обойтись: адрес электронной почты (он же логин) и пароль для входа. Более подробно рассказать о себе посетитель сможет в «Личном кабинете». Если необходимость каких-либо данных неочевидна, кратко поясните, зачем они вам нужны.

Примечание

Определить соотношение авторизованных и неавторизованных пользователей на вашем сайте, а также проанализировать различия в их поведении, поможет отчет Метрики [Параметры визитов](ru/reports/visit-params). Отчет [Страницы выхода](ru/content/exit-pages) показывает количество выходов со страницы регистрации.
