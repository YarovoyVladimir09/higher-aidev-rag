# addFileExtension

Важно

Для работы с JavaScript API необходимы навыки работы с HTML и JavaScript. Если вы не обладаете такими навыками, обратитесь к разработчику или вебмастеру вашего сайта.

Отслеживание загрузки файлов с заданными расширениями.

```
ym(XXXXXXXX, 'addFileExtension', extensions);
```

| Параметр | Значение по умолчанию | Тип | Описание |
| --- | --- | --- | --- |
| extensions * | — | String | String[] | Расширение имени файла, заданное в виде строки или список расширений, указанный в виде массива строк |

* Обязательный параметр.

По умолчанию поддерживаются следующие расширения:

| 3GP 7Z AAC AVI APK CSV DJVU DOCX EXE | FLAC FLV GZ KEY MIDI MKA MKV MP3 MP4 | MPEG MOV MSI OGG PDF PKG PPS PPT PPTX | RAR RTF TXT WAV WMA WMV WMF XLSX ZIP |
| --- | --- | --- | --- |

# Пример

```
ym(XXXXXXXX, 'init', {});
ym(XXXXXXXX, 'addFileExtension', 'lzh'); // Добавить одно расширение
ym(XXXXXXXX, 'addFileExtension', ['lha', 'iff', 'ico']); // Добавить несколько расширений
```
