# setUserID

Важно

Для работы с JavaScript API необходимы навыки работы с HTML и JavaScript. Если вы не обладаете такими навыками, обратитесь к разработчику или вебмастеру вашего сайта.

Передача идентификатора посетителя сайта, заданного владельцем сайта.

```
ym(XXXXXXXX, 'setUserID', "12345");
```

где

- `XXXXXXXX` — номер вашего счетчика;
- `12345` — строковое значение.

Собственные идентификаторы будут привязаны к *ClientID* только для тех посетителей сайта, во время посещений которых был вызван метод `setUserID`.
