# enableAll

Внимание

Метод устарел. Поддерживается в режиме обратной совместимости, но может быть исключен в произвольный момент времени. Настоятельно не рекомендуется к применению.

Все данные, сбор и отправка которых регулируется данным методом, отслеживаются по умолчанию.

Для отключения отслеживания определённых данных используйте параметры [clickmap](ru/code/counter-initialize#param-clickmap), [trackLinks](ru/code/counter-initialize#param-trackLinks) и [webvisor](ru/code/counter-initialize#param-webvisor) при инициализации счётчика.

```
ym(XXXXXXXX, 'enableAll');
```

Включение сбора и отправки следующей информации:

- Данные о кликах для формирования [Карты кликов](ru/behavior/click-map). Аналогично использованию [clickmap](ru/objects/clickmap)(true).
- Данные о переходах по внешним ссылкам и загрузках файлов. Аналогично использованию [trackLinks](ru/objects/tracklinks)(true). Используются при формировании [Карты ссылок](ru/behavior/link-map), в отчётах [Внешние переходы](ru/content/external-links) и [Загрузки файлов](ru/content/file-downloads).

# Пример

```
ym(XXXXXXXX, 'init', {});
ym(XXXXXXXX, 'enableAll');
```
