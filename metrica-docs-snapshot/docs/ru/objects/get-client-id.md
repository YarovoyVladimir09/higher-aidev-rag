# getClientID

Получение идентификатора посетителя сайта, заданного Яндекс Метрикой.

Важно

Для работы с JavaScript API необходимы навыки работы с HTML и JavaScript. Если вы не обладаете такими навыками, обратитесь к разработчику или вебмастеру вашего сайта.

```
ym(XXXXXXXX, 'getClientID', function(clientID) {
  <тело функции>
});
```

Формат ответа:

```
"12345"
```

где

- `XXXXXXXX` — номер вашего счетчика;
- `12345` — строковое значение.

```
ym(XXXXXXXX, 'getClientID', function(clientID) {
  document.getElementById('clientID').value = clientID;
});
```

```
var yaID;
ym(XXXXXXXX, 'getClientID', function(clientID) {
  yaID = clientID});
```

В переменную `yaID` будет записано значение *ClientID*.
