# trackLinks

Внимание

Метод устарел. Поддерживается в режиме обратной совместимости, но может быть исключен в произвольный момент времени. Настоятельно не рекомендуется к применению.

Для управления отслеживанием перехода по внешним ссылкам используйте параметр [trackLinks](ru/code/counter-initialize#param-trackLinks) при инициализации счетчика.

Установка признака отслеживания внешних ссылок и ссылок на загрузку файлов.

Собранные данные используются при формировании [Карты ссылок](ru/behavior/link-map), в отчетах [Внешние переходы](ru/content/external-links) и [Загрузки файлов](ru/content/file-downloads).

```
ym(XXXXXXXX, 'trackLinks', enabled);
```

| Параметр | Тип | Значение по умолчанию | Описание |
| --- | --- | --- | --- |
| enabled * | true | Boolean | Включение/отключение отслеживания внешних ссылок и ссылок на загрузку файлов. Пример javascript ym(XXXXXXXX, 'trackLinks', false); |

* Обязательный параметр.

Отключить отслеживание информации о переходах по определенным внешним ссылкам можно с помощью HTML-класса [ym-disable-tracklink](ru/code/html-markup#class-ym-disable-tracklink).

Пометить внутреннюю ссылку как внешнюю можно с помощью класса [ym-external-link](ru/code/html-markup#class-ym-external-link).
