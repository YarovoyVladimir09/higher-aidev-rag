# params

Важно

Для работы с JavaScript API необходимы навыки работы с HTML и JavaScript. Если вы не обладаете такими навыками, обратитесь к разработчику или вебмастеру вашего сайта.

Передача произвольных [параметров визита](ru/data/visit-params-data).

Примечание

Часть названий полей зарезервирована для [передачи данных электронной коммерции](ru/data/e-commerce). Не используйте эти названия для передачи параметров визитов. Не передавайте свои параметры с зарезервированными.

```
ym(XXXXXXXX, 'params', parameters);
```

| Параметр | Значение по умолчанию | Тип | Описание |  |
| --- | --- | --- | --- | --- |
| parameters * | — | Object | Array | Параметры визита . Пример передачи объекта: var myParams = { test : { myParam : 123 }}; ym ( XXXXXXXX , 'params' , { params : myParams}); Пример передачи массива: var myParamsArray = [{ test : { myParam : 123 }}, { test : { myParam : 456 }}]; ym ( XXXXXXXX , 'params' , { params : myParamsArray}); |

* Обязательный параметр.
