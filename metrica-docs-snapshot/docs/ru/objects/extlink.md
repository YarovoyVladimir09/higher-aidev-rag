# extLink

Важно

Для работы с JavaScript API необходимы навыки работы с HTML и JavaScript. Если вы не обладаете такими навыками, обратитесь к разработчику или вебмастеру вашего сайта.

Отправка информации о переходе по внешней ссылке.

Собранные данные используются при формировании [Карты ссылок](ru/behavior/link-map) и отчета [Внешние переходы](ru/content/external-links).

```
ym(XXXXXXXX, 'extLink', url[, options]);
```

| Параметр | Значение по умолчанию | Тип | Описание |
| --- | --- | --- | --- |
| url * | — | String | URL страницы, на которую произошел переход |
| options | — | Object |  |
| Поля объекта options |  |  |  |
| options.callback | Тип: Function | — | Callback-функция, вызываемая после отправки данных о загрузке файла |
| options.ctx | — | Object | Контекст, доступный в callback-функции по ключевому слову this |
| options.params | — | Object | Параметры визита |
| options.title | document.title | String | Заголовок текущей страницы |
| Поля объекта params : |  |  |  |
| order_price | — | Double | Доход по цели . Вы можете указать цену как в валюте, так и в условных единицах |
| currency | — | String | Используйте это поле, если хотите передать цену цели в валюте. Метрика распознает трехбуквенный код валюты по ISO 4217 . Если передается другая валюта, будут отправлены нулевые значения вместо валюты и суммы |

* Обязательный параметр.

# Пример

```
ym(XXXXXXXX, 'init', {});

//...

ym(XXXXXXXX, 'extLink', 'https://yandex.com');
```

## ru/objects/extlink#priceДоход по цели

Если переход по внешней ссылке является одной из установленных на сайте целей, вы можете [передать в параметрах метода доход](ru/general/price-goal).

Пример:

```
var goalParams =
{
   order_price: 1000.35,
   currency: "RUB"
};
ym(XXXXXXXX, 'extLink', 'https://yandex.com', goalParams)
```
