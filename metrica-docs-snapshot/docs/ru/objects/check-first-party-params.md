# Проверка передачи данных для расширенных настроек отслеживания

После отправки данных с помощью метода [firstPartyParams](ru/objects/first-party-params) или [firstPartyParamsHashed](ru/objects/first-party-params-hash) (с возможностью самостоятельного хеширования данных) убедитесь, что данные передаются в Метрику правильно.

1. В браузере откройте страницу сайта.
2. В адресной строке браузера добавьте к адресу страницы параметр `_ym_debug=2` и загрузите страницу. http://example.com/?_ym_debug=2
3. Вызовите консоль браузера с помощью сочетания клавиш **Ctrl** + **Shift** + **J** (**⌥** + **⌘** + **J** для семейства операционных систем Apple).
4. На странице сайта заполните контактную информацию.

Если передача данных настроена правильно, в консоли отобразится информация в захешированном виде, например:

[Написать в чат](https://yandex.ru/chat/#/user/036e6a02-3620-9cdc-4c5e-a34667a7379e?utm_source=spravka)

Обратите внимание: служба поддержки не обзванивает пользователей. Не следуйте указаниям людей, которые вам звонят и представляются службой поддержки Яндекс Метрики.
