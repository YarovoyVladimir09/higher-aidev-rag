# hit

Внимание

Сигнатура устарела. Поддерживается в режиме обратной совместимости, но может быть исключена в произвольный момент времени. Настоятельно не рекомендуется к применению. Используйте [hit (url[, options])](ru/objects/hit).

Отправка данных о просмотрах вручную для AJAX- и Flash-сайтов.

```
ym(XXXXXXXX, 'hit', url, [title[, referer[, params]]]);
```

| Параметр | Значение по умолчанию | Тип | Описание |
| --- | --- | --- | --- |
| url * | — | String | URL текущей страницы |
| title | document.title | String | Заголовок страницы |
| referer | — | String | URL страницы, с которой посетитель загрузил содержимое текущей страницы |
| params | — |  | Параметры визита |

* Обязательный параметр.

Параметры `url` и `referer` допускают использование URL-путей, без указания схемы (протокола) и хоста.

В этом случае, если путь начинается с символа `/`, URL считается заданным от корня хоста.

```
ym(XXXXXXXX, 'hit', '/contacts');
```

В противном случае путь считается заданным относительно текущей страницы.

```
ym(XXXXXXXX, 'hit', 'contacts', 'Контактная информация');
```

# Пример

```
ym(XXXXXXXX, 'init', {});
//...
ym(XXXXXXXX, 'hit', '#!contacts', 'Контактная информация', 'http://example.com/#!main');
```
