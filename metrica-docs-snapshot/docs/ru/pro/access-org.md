# Управление доступами к личному кабинету

- [Как выдать доступ к личному кабинету](ru/pro/access-org#add)
- [Как отозвать доступ к личному кабинету](ru/pro/access-org#remove)

Для совместной работы с Метрикой Про вы можете выдать сотрудникам доступ к личному кабинету. Доступ позволяет просматривать статистику и управлять счетчиками в пакете Про.

При подключении пакета Про доступ на редактирование данных в личном кабинете получают:

- Владелец организации — логин, который был выбран при [подключении пакета](ru/pro/account). Владельца организации нельзя удалить или ограничить его доступ к личному кабинету.
- Владелец агентства-партнера, через которого вы подключили Метрику Про.

Доступы могут быть нескольких типов:

- **Редактирование** — пользователь сможет управлять [счетчиками в пакете Про](ru/pro/access), доступами к личному кабинету и [трансферами](ru/uploading-data/cloud#quick-start).
- **Просмотр** — пользователь сможет просматривать общую статистику по счетчикам организации, список сотрудников организации и [трансферов](ru/uploading-data/cloud#quick-start).

Примечание

Доступы к личному кабинету не влияют на [доступы к счетчикам](ru/pro/access), добавленным в Про.

## ru/pro/access-org#addКак выдать доступ к личному кабинету

1. Перейдите в Метрику.
2. Перейдите на страницу **Кабинет PRO**.
3. Перейдите на страницу **Сотрудники**.
4. Нажмите кнопку **Настроить доступы**.
5. В окне **Доступы к организации**: Через запятую перечислите логины сотрудников, для которых нужен доступ. Для этого сотрудники должны быть [зарегистрированы](https://passport.yandex.ru/passport?mode=register) на Яндексе и иметь Яндекс ID. Выберите тип доступа: **Редактирование**. **Просмотр**.
6. Нажмите кнопку **Сохранить**.

## ru/pro/access-org#removeКак отозвать доступ к личному кабинету

1. Перейдите в Метрику.
2. Перейдите на страницу **Кабинет PRO**.
3. Перейдите на страницу **Сотрудники**.
4. Нажмите кнопку **Настроить доступы**.
5. В окне **Доступы к личному кабинету организации**: Через запятую перечислите логины сотрудников, для которых нужен доступ. Для этого сотрудники должны быть [зарегистрированы](https://passport.yandex.ru/passport?mode=register) на Яндексе и иметь Яндекс ID. Нажмите **Забрать права**.
6. Нажмите кнопку **Сохранить**.
