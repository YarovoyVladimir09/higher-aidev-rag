# Мониторинг расходования квот

Статистика помогает узнать, как расходуются квоты на счетчиках, добавленных в пакет Про.

Вы можете следить за следующими показателями:

- [хиты](ru/pro/price#hit) за месяц;
- количество запросов в API отчетов в веб-интерфейсе;
- количество запросов в API отчетов непосредственно;
- объем запросов к Logs API.

Чтобы посмотреть статистику:

1. Перейдите в Метрику.
2. Перейдите на страницу **Кабинет PRO**.
3. На главной странице **Личного кабинета** вы можете следить за расходом квот в блоке **Доступы** и с помощью графика.

В таблице можно проверить:

- У кого есть [доступ к счетчикам](ru/pro/access), максимальный выданный тип доступа (просмотр, аналитика или редактирование) и источник доступа (прямой или представитель).
- Расход квот на конкретный счетчик в целом и в разрезе по конкретным пользователям (для просмотра статистики по пользователям нужно кликнуть на название счетчика в колонке **Счётчики**).

Также в таблице доступны:

- поиск (кнопка **Найти**) по логину, названию или номеру счетчику, адресу сайта;
- сортировка (по клику на название столбца) в столбцах **Обращения к API** и **Объем логов**;
- выбор периода мониторинга квот (максимальная продолжительность периода — 31 день). Выбор сохраняется при переключении между счетчиками и пользователями.

График показывает количество хитов в динамике за месяц суммарно по всем счётчикам. Месяц, за который нужны данные, можно выбрать.
