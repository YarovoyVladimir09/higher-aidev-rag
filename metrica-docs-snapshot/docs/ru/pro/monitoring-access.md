# Мониторинг доступов к счетчикам

- [Посмотреть список пользователей](ru/pro/monitoring-access#look)
- [Управлять доступами к счетчикам](ru/pro/monitoring-access#manage)

[Личный кабинет организации](ru/pro/account) позволяет:

- выдавать или забирать доступ к счетчикам и менять роли;
- контролировать потребление квот на запросы к API отчетов;
- контролировать объем запрошенных логов Logs API;
- отслеживать активность пользователей в интерфейсе Метрики.

В разделе с пользователями и доступами для каждого пользователя отображается:

- список счетчиков, к которым он имеет доступ;
- его роли на счетчиках;
- в каком объеме пользователь обращался к API отчетов и Logs API каждого счетчика за текущие сутки.

## ru/pro/monitoring-access#lookПосмотреть список пользователей

1. Перейдите в [Личный кабинет организации](ru/pro/account).
2. Над таблицей со списком счетчиков выберите вкладку **Пользователи**. Вы увидите список пользователей, которые имеют доступ к счетчикам из тарифа Метрика Про.
3. Чтобы увидеть доступные пользователю счетчики, слева от его логина нажмите .

В таблице отображаются:

- Логин пользователя.
- **Обращения к API • интерфейс** — количество запросов, сделанных пользователем к API за выбранный период по конкретному интерфейсу.
- **Обращения к API • прямые** — количество запросов, сделанных пользователем к API за выбранный период напрямую.
- **Объем логов Logs API • Гб** — объем запрошенных пользователям логов Logs API за выбранный период.
- Доступные пользователю счетчики.
- Источник доступа (прямой или представитель, а также объем прав — просмотр, аналитика или редактирование).

## ru/pro/monitoring-access#manageУправлять доступами к счетчикам

Внимание

Вы можете управлять доступом к счетчику, если имеете доступ к редактированию этого счетчика.

Управлять представительскими доступами может только пользователь, который выдал роль.

1. Перейдите в [Личный кабинет организации](ru/pro/account).
2. Над таблицей со списком счетчиков выберите вкладку **Пользователи**. Откроется окно настройки доступов, где нужно будет: указать названия счетчиков; указать через запятую логины пользователей, которым нужно изменить тип доступа.
3. Укажите тип прав. Чтобы отозвать все права, выберите **Забрать права**.
4. Нажмите **Сохранить**. Для выбранных пользователей будут изменены или отозваны права.
