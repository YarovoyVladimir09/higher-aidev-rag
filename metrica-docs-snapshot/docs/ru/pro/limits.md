# Ограничения на передачу данных

- [Дашборды](ru/pro/limits#dashboard)
- [Настройки и навигация](ru/pro/limits#settings)

В Метрике Про есть ограничения на количество передаваемых данных, чтобы инструменты сервиса были максимально доступны.

|  | Ограничение | Примечание |
| --- | --- | --- |
| Количество целей | До 400 в одном визите | — |
| Oбъем целей | До 131 072 байт в одном визите | — |
| Количество элементов в массиве EPurchase.ID | До 512 в одном визите | — |
