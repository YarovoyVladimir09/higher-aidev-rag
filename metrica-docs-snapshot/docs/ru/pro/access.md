# Централизованное управление доступами к счетчикам Метрики

При использовании Метрики Про вы можете настраивать доступы нескольким пользователям к [нескольким счетчикам вашей организации](ru/pro/add-tag).

- Владелец организации — логин, который вы [выбираете при подключении пакета Про](ru/pro/account).
- Пользователь с доступом на редактирование счетчика.

Доступы могут быть нескольких типов:

- **Редактирование** — пользователь сможет управлять счетчиком, изменять его настройки и доступы.
- **Аналитика** — пользователь сможет создавать на счетчике цели и сегменты, но не сможет изменять настройки и доступы.
- **Только просмотр** — пользователь сможет просматривать отчеты, настройки и доступы к счетчику.

Примечание

Доступы к счетчикам в пакете Про не влияют на [доступы к личному кабинету](ru/pro/access-org).

Чтобы настроить доступы:

1. Перейдите в Метрику.
2. Перейдите на страницу **Кабинет PRO**.
3. В блоке **Доступы** нажмите кнопку **Настроить доступы**.
4. В окне **Права доступа к счетчикам**: Укажите один или несколько счетчиков Метрики. Выберите тип доступа. Через запятую перечислите логины сотрудников, для которых нужен доступ. Для этого сотрудники должны быть [зарегистрированы](https://passport.yandex.ru/passport?mode=register) на Яндексе и иметь Яндекс ID. Укажите, как нужно изменить доступы: **Редактирование**; **Аналитика**; **Просмотр**.
5. Нажмите кнопку **Сохранить**.

- У вас нет прав на редактирование счетчика.
- Счетчик [не добавлен в пакет Про](ru/pro/add-tag).
- Указанный логин не зарегистрирован на Яндексе.

Внимание

Вы не можете управлять представительскими доступами. Изменить их может только пользователь, который выдал роль.

## ru/pro/access#removeКак отозвать доступ к счетчику

Пользователь потеряет доступ к отчетам и настройкам счетчика. Доступ можно выдать повторно.

1. Перейдите в Метрику.
2. Перейдите на страницу **Кабинет PRO**.
3. В блоке **Доступы** нажмите кнопку **Настроить доступы**.
4. В окне **Права доступа к счетчикам**: Укажите один или несколько счетчиков Метрики. Через запятую перечислите логины сотрудников, для которых нужен доступ. Для этого сотрудники должны быть [зарегистрированы](https://passport.yandex.ru/passport?mode=register) на Яндексе и иметь Яндекс ID. Выберите **Забрать права**.
5. Нажмите кнопку **Сохранить**.
