# Просмотр трансферов и удаление счетчика из трансфера

На странице **Интеграции с Облаком** представлены выгрузки двух типов: **Стриминговая загрузка** и **Выгрузка архивных данных**. Для выгрузки архивных данных указан процент завершения выгрузки для каждой из таблиц. Выгрузка архивных данных за продолжительный период может занимать несколько дней и более.

В столбце **Обновлено** для каждой выгрузки показаны время запуска и завершения выгрузки. Если время завершения не указано, значит выгрузка активна.

Примечание

Доступ в личный кабинет **Интеграции с Облаком** имеют [сотрудники](ru/pro/access-org), у которых есть доступ к организации.

Чтобы посмотреть, на каких из счетчиков организации активны трансферы, и при необходимости их отключить:

1. Перейдите в Метрику.
2. Перейдите на страницу **Кабинет PRO**.
3. Перейдите на страницу **Интеграции с Облаком**.
4. Для настройки и просмотра детальных параметров выбранной загрузки нажмите → **Перейти в облако**.
5. Чтобы отключить счетчик, в строке трансфера нажмите значок и выберите **Удалить счётчики из трансфера**. Активная выгрузка архивных данных и потоковая передача остановятся.

Примечание

Управлять трансферами может владелец, сотрудник с ролью **Редактирование** и инициатор выгрузки.
