## ru/pro/price#qaВопросы и ответы

*Хит* — это событие, которое учитывается Метрикой. Такими событиями являются:

- *просмотры*
- достижение любой цели, созданной на счетчике;
- отправка параметров визитов.

Чтобы посмотреть количество хитов на счетчике:

1. Перейдите в настройки счетчика.
2. На вкладке **Счетчик** в правом верхнем углу нажмите **Информация по Метрике Про**.

Отобразится количество хитов на счетчике за предыдущий календарный месяц.

У Метрики Про есть отдельный личный кабинет, в который вы можете добавить счетчики основного аккаунта.

Каждый счетчик добавляется отдельно. Ограничений на число счетчиков в пакете нет.

Тарификация рассчитывается по сумме хитов на счетчиках, добавленных в Метрику Про.

[Личный кабинет организации](ru/pro/account)

В пакет Метрики Про можно добавить неограниченное количество счетчиков.
