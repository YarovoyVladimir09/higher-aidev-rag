# Управление счетчиками организации

Чтобы начать пользоваться возможностями Метрики Про, добавьте счетчик в личном кабинете. Рекомендуем добавлять все счетчики вашей организации в пакет Про — так вам будет удобнее управлять ими.

После добавления счетчика [хиты](ru/pro/price#hit) с него будут учитываться при [расчете стоимости пакета Про](ru/pro/price).

Счетчики, владельцем которых является логин-владелец организации. Этот логин вы [выбираете при подключении пакета Про](ru/pro/account).

- Владелец организации — логин, который вы [выбираете при подключении пакета Про](ru/pro/account).
- Пользователь с [доступом на редактирование в организации](ru/pro/access-org).

Чтобы добавить счетчик:

1. Перейдите в Метрику.
2. Перейдите на страницу **Кабинет PRO**.
3. Нажмите кнопку **Добавить счетчики**.
4. В окне **Добавление счетчиков** укажите счетчики, которые хотите добавить в личный кабинет.
5. Нажмите кнопку **Добавить**.

- Владелец счетчика не является владельцем организации.
- У вас нет прав на добавление счетчика в организацию (есть только [доступ на просмотр в организации](ru/pro/access-org)).

## ru/pro/add-tag#isklyuchenie-schetchika-iz-paketa-proИсключение счетчика из пакета Про

Счетчик можно исключить из пакета, если на нем нет активных трансферов, а также количество целей и сегментов не превышает стандартную квоту.

При исключении счетчика:

- Квоты будут возвращены к стандартным.
- Счетчик нельзя будет подключить к трансферу.
- Хиты со счетчика перестанут учитываться при расчете стоимости тарифа.
- Включится семплирование данных.
- Вы не сможете выгружать данные отчетов Метрики для медийной рекламы через API, если в рекламодателе нет целей с других счетчиков, добавленных в пакет Про.

Чтобы удалить счетчик из пакета, в списке счетчиков нажмите значок  и выберите **Исключить из PRO**.

- На счетчике есть активные трансферы.
- На счетчике превышены стандартные квоты по целям и сегментам.
- У вас нет прав на удаление счетчика (есть только [доступ на чтение в организации](ru/pro/access-org)).
