# Легко читаемые шрифты

При выборе шрифта руководствуйтесь тем, насколько удобно будет посетителю читать текст. Не надо его чрезмерно украшать. Выделяйте только те слова, на которых важно акцентировать внимание.

Также помните, что слова, написанные полужирным шрифтом, видны при первом же взгляде на текст. А курсив заметен, только когда до него дочитаешь.
