# RAG-система для документации Яндекс Метрики

Практическое задание по созданию RAG (Retrieval-Augmented Generation) pipeline для поддержки пользователей Яндекс Метрики.

## Что нужно сделать

Реализуйте функцию `ask(question: str) -> dict` в файле `src/rag_pipeline.py`, которая:
1. Индексирует документацию Яндекс Метрики
2. Находит релевантные фрагменты по запросу пользователя
3. Генерирует ответ с помощью LLM на основе найденных документов

## Установка

1. Создайте виртуальное окружение и активируйте его:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Настройте переменные окружения с вашими ключами от Yandex Foundation Models:
   ```bash
   export LLM_API_KEY="ваш_ключ_из_ai_studio"
   export LLM_BASE_URL="https://llm.api.cloud.yandex.net/v1"
   export LLM_MODEL="gpt://<идентификатор_каталога>/gpt-oss-20b/latest"
   ```

## Запуск тестов

```bash
pytest -q
```

Открытые тесты проверяют:
- **P1**: Вопрос про Вебвизор
- **P2**: Вопрос про установку счётчика  
- **P3**: 5 вопросов из GOLDEN_QA с проверкой precision@3 ≥ 0.4

## Требования к решению

Функция `ask` должна возвращать словарь с ключами:
- `answer: str` — текст ответа модели (≥ 10 символов)
- `sources: list[str]` — список путей к файлам-источникам (до 3 штук)
- `cost_rub: float` — стоимость запроса в рублях

### RAG Pipeline (4 этапа)

1. **Indexing** — подготовка корпуса:
   - Прочитать все `*.md` файлы из `metrica-docs-snapshot/docs`
   - Разрезать на фрагменты ~4000 символов
   - Создать BM25 индекс

2. **Retrieval** — поиск top-3:
   - BM25 поиск по токенам запроса
   - Бонус за совпадение токенов в метаданных (путь, заголовок)
   - Дедупликация по путям

3. **Augmentation** — сборка промпта:
   - Пронумеровать фрагменты [1], [2], [3]
   - Указать путь для каждого
   - Добавить вопрос пользователя

4. **Generation** — вызов модели:
   - OpenAI-совместимый клиент
   - Извлечь ответ
   - Посчитать стоимость: `(prompt_tokens + completion_tokens) / 1000 × 0.1 ₽`

## Важно

- **Не пишите хардкод** под конкретные вопросы
- Используйте **общие алгоритмы**, которые работают для любых документов
- Chunking уже сделан на этапе индексации — берите полный текст найденных фрагментов
